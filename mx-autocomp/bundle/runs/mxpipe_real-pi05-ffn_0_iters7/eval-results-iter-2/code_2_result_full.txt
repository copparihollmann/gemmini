Plan: ### Optimization Plan

The goal is to apply **Strategy 10**: *"Hoist the MVIN A tile loading loop out of the inner J-block ($j_0$) loop, storing activation tiles in a dedicated scratchpad region to reuse them across all column blocks of B."*

#### Analysis of the Inefficiency
In the original baseline program, both the activation tile loading loop (`A_in` matrix via `gemmini_extended_mvin`) and the activation scale-factor staging/loading are placed inside the inner $j_0$ loop. Because the matrix $A$ tiles only depend on the row index $i_0$, they are completely invariant with respect to the column block index $j_0$. Repeating these loads on every single $j_0$ step results in redundant off-chip memory DMA traffic, DRAM-bandwidth saturation, and unnecessary CPU staging overhead.

#### Restructuring Plan
1. **Hoist Scale Staging for $A$**: Copy the per-group scale factors of $A$ (`A_scales_row`) and issue `gemmini_mx_load_scales` (with `sel=0` for activations) only once at the beginning of each $i_0$ loop iteration.
2. **Hoist MVIN of $A$**: Issue the `gemmini_config_ld` (with A's stride) and load the $A$ tiles into the scratchpad at `a_base` before entering the inner $j_0$ loop. Since $A$ is mapped to rows $0 \dots 2047$ (based on $4 \times 32 \times 16 = 2048$ rows maximum) and $B$ grows downward from the top of the scratchpad ($8192 - 2048 = 6144$), there is no memory overlap. The loaded tiles of $A$ remain resident in the scratchpad and are reused across all $j_0$ column iterations.
3. **Preserve Inner Loop Flow**: Keep the column-specific configurations, $B$ scale/tile loads, execution of the systolic compute, and shared memory readout inside the $j_0$ loop.

void solution(void) {
  // Configured once outside the loop since configuration fields are stateful and persist
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

    int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;

    // Hoisted CPU stage: copy only A's scales for this row block once per i0 block
    for (int g = 0; g < MATMUL_K / 32; g++) {
      memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
    }

    // Hoisted scale load: stream A's scales into mx_scale_a_mem
    gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);

    int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
    uint32_t a_base = 0;

    gemmini_config_ld(MATMUL_K * sizeof(elem_t)); // A rows: stride K (full block-aligned tiles)

      for (int k = 0; k < tiles_K; k++) {
        gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                              a_base + (i * tiles_K + k) * DIM, DIM, DIM);
      }
    }

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last N block: compute only the real cols, pad the rest.
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      // Copy only B's scales for this column block
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }

      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      gemmini_flush(0);
      gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

      // Load B scales
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      gemmini_config_ld(MATMUL_N * sizeof(elem_t)); // B rows: stride N

                                b_base + (k * tiles + j) * DIM, DIM, DIM);
        }

      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
