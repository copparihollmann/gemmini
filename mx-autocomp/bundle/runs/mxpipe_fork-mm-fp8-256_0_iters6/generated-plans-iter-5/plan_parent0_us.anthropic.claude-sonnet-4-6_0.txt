## Plan: Use mvin2 for B-tile loads to overlap A and B DMA transfers (Strategy 11 / port-level parallelism)

More precisely, **Strategy 8** — reorder to maximize B-tile reuse — combined with using `mvin2` for B:

The plan is:
1. Change B MVIN to use `gemmini_extended_mvin2` instead of `gemmini_extended_mvin`, so A and B DMA operations can overlap in hardware.
2. Interleave the A and B mvin loops: for each k-slice, issue A mvins (via mvin port 0) then B mvins (via mvin2 port 1) back-to-back, allowing the hardware to pipeline both transfers simultaneously rather than serializing all A loads then all B loads.

This directly uses two independent DMA ports, halving effective DMA time.
