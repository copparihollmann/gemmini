1. Configure the LD stride for port 1 (A) using `gemmini_config_ld(MATMUL_K * sizeof(elem_t))` — unchanged.
2. Configure the LD stride for port 2 (B) using `gemmini_extended3_config_ld(MATMUL_N * sizeof(elem_t), SCALE_IDENTITY, false, 1)` — this sets id=1 for mvin2.
3. 5. The iteration structure: loop over `k`, and within each `k`, issue `i`-batched A tiles and `j`-batched B tiles, interleaving port-1 and port-2 commands.
