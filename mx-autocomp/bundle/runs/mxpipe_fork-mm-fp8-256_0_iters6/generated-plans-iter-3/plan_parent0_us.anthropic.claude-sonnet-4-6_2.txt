## Analysis

Looking at the original code, I can identify the key inefficiency targeted by **strategy 4: use `mvin2`/`mvin3` ports to parallelize A and B tile loads into scratchpad simultaneously**.

Currently, the code loads all A tiles first (using `gemmini_extended_mvin`), then loads all B tiles (also using `gemmini_extended_mvin`) in two separate sequential loops. These are serialized — the B loads cannot begin until all A loads complete.

The hardware provides three independent DMA ports:
- `gemmini_extended_mvin` — port 0 (used for A)
- `gemmini_extended_mvin2` — port 1 (used for B)
- `gemmini_extended_mvin3` — port 2 (used for D/bias)

By using `gemmini_extended_mvin` for A tiles and `gemmini_extended_mvin2` for B tiles **in an interleaved loop**, the hardware can issue both DMA transfers concurrently, overlapping A and B loads and reducing total data movement latency.

## Plan

1. **Merge the two separate A-load and B-load loops into a single unified loop** that iterates over all `(i, k)` A-tile indices and all `(k, j)` B-tile indices together.

2. **Keep `gemmini_extended_mvin` for A tiles** (port 0) and **switch B tile loads to `gemmini_extended_mvin2`** (port 1). This allows the hardware DMA engine to service both ports in parallel.

3. **Issue one `gemmini_config_ld` for each port before the unified loop**: the first `gemmini_config_ld` (id=0, default) sets stride `MATMUL_K * sizeof(elem_t)` for A, and a second `gemmini_extended3_config_ld(..., id=1)` sets stride `MATMUL_N * sizeof(elem_t)` for B's port.

4. **Interleave the mvin and mvin2 calls** within the same loop body so that for each iteration step, an A-tile load and a B-tile load are both issued before the hardware stalls, maximizing overlap.

5. **Remove the dead code** (commented-out printf statements, commented-out mvout loops, commented-out SMEM debug accesses) that adds instruction cache pressure with no benefit — this is a minor cleanup aligned with strategy 6 but is a natural side effect of the rewrite.

6. **Preserve all correctness constraints**: scratchpad layout (`a_base=0`, `b_base = BANK_NUM*BANK_ROWS - tiles_K*tiles_J*DIM`), tile addressing (`a_base + (i*tiles_K+k)*DIM` and `b_base + (k*tiles_J+j)*DIM`), and the programming model sequence remain unchanged.

The total number of mvin commands stays the same; only their temporal interleaving changes, allowing DMA port 0 (A) and DMA port 1 (B) to transfer simultaneously rather than sequentially.

```c
void solution(void) {

  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

#ifdef SPIKE_SIM
  gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
  gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);
#else
  load_scale_factors((volatile uint64_t *) GEMMINI_SF_MEM_A, (uint8_t *) &A_scales_row, MATMUL_M, MATMUL_K);
  load_scale_factors((volatile uint64_t *) GEMMINI_SF_MEM_B, (uint8_t *) &B_scales_col, MATMUL_N, MATMUL_K);
#endif

  // Configure port 0 (mvin) for A: stride = full row width of A in bytes
  gemmini_config_ld(MATMUL_K * sizeof(elem_t));

  // Configure port 1 (mvin2) for B: stride = full row width of B in bytes
  gemmini_extended3_config_ld(MATMUL_N * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 1);

  // Total A tiles = tiles_I * tiles_K, total B tiles = tiles_K * tiles_J
  // Interleave mvin (port 0, A) and mvin2 (port 1, B) to overlap DMA transfers
  int total_a = tiles_I * tiles_K;
  int total_b = tiles_K * tiles_J;
  int total = total_a > total_b ? total_a : total_b;

  for (int t = 0; t < total; t++) {
    // Issue A tile load on port 0 if within bounds
    if (t < total_a) {
      int i = t / tiles_K;
      int k = t % tiles_K;
      elem_t *dram_ptr = ((elem_t*)A_in) + i * DIM * MATMUL_K + k * DIM;
      uint32_t sp_addr = a_base + (i * tiles_K + k) * DIM;
      gemmini_extended_mvin((void *) dram_ptr, sp_addr, DIM, DIM);
    }

    // Issue B tile load on port 1 if within bounds
    if (t < total_b) {
      int k = t / tiles_J;
      int j = t % tiles_J;
      elem_t *dram_ptr = ((elem_t*)B_in) + k * DIM * MATMUL_N + j * DIM;
      uint32_t sp_addr = b_base + (k * tiles_J + j) * DIM;
      gemmini_extended_mvin2((void *) dram_ptr, sp_addr, DIM, DIM);
    }
  }

  int SPAD_DEST = 0;

  gemmini_config_st(DIM * sizeof(elem_t));
  gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, 1);

  gemmini_loop_ws_spad(
      tiles_I, tiles_J, tiles_K,
      0, 0, 0,
      a_base,
      BANK_NUM * BANK_ROWS,
      0,
      SPAD_DEST,
      false, false,
      false, false, false,
      NO_ACTIVATION,
      0, 0,
      false,
      0x38);

  gemmini_fence();

#ifdef SPIKE_SIM
  gemmini_mx_read_smem(&C_hw[0][0], SPAD_DEST * 16, MATMUL_M * MATMUL_N);
#else
  for (int i = 0; i < tiles_J*tiles_I*2; i++) {
      gemmini_mvout((void*)((uint64_t*) C_hw + i*2*DIM), SPAD_DEST + i*DIM);
  }
  gemmini_fence();
#endif

}
```
