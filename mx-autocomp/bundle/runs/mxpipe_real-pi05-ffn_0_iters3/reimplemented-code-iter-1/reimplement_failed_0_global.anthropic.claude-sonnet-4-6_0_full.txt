Looking at the failing code, I need to identify the bugs:

1. **B matrix mvin uses wrong port** - B should use `gemmini_extended_mvin2` (mvin2 port), not `gemmini_extended_mvin` (mvin port). Using the same port for both A and B causes conflicts.

2. **B matrix scratchpad layout is wrong** - The B layout formula `(k * tiles + j) * DIM` should be `(j * tiles_K + k) * DIM` to match the documented layout `b_base + (j*tiles_K + k)*DIM`.

3. **mvin B uses wrong DRAM stride** - B is stored column-major in DRAM as `B_in[k*DIM][j0*BLK + j*DIM]` with stride `MATMUL_N`. The config_ld stride for B should be `MATMUL_N * sizeof(elem_t)` (already correct), but mvin2 should be used.

4. **gemmini_flush should not be inside the tile loop** - it resets state unnecessarily and wastes cycles. But more critically it may reset state needed between steps.

5. **smem read offset** - The `SPAD_DEST * 16 + r * BLK` for partial rows needs to account for the full BLK width row stride in smem, which should be `SPAD_DEST * 16 + r * BLK` (BLK elements per row in smem). This looks correct.

6. **scale_factors** - The `gemmini_mxquant_config_mvout` receives `scale_factors` but based on the workflow it should point to the output scale memory. The A_s/B_s buffers are the input scales loaded via `gemmini_mx_load_scales`. The `scale_dram` in `gemmini_mxquant_config_mvout` is for output requantization - this needs to be a valid DRAM address for output scales.

The main correctness bugs are: wrong mvin port for B, wrong B scratchpad indexing formula, and the flush placement.

void solution(void) {
  for (int i0 = 0; i0 < BLOCKS_M; i0++)
    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      // Pack scales for this (i0, j0) block
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }

      int tiles   = BLK / DIM;
      int tiles_K = MATMUL_K / DIM;

      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;

      int pad_i = BLK - mrows;
      int pad_j = BLK - ncols;

      // Step 1: configure execution
      gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY,
          1, 1, 0, 0, false, 0, 0, 3, 0);

      // Step 2: load scale factors (sel=0 for A, sel=1 for B)
      gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      // Step 4a: mvin A tiles using mvin port (port 0), stride = MATMUL_K bytes
      gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 0);
      for (int i = 0; i < tiles; i++)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin(
              (void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
              a_base + (i * tiles_K + k) * DIM,
              DIM, DIM);

      // Step 4b: mvin B tiles using mvin2 port (port 1), stride = MATMUL_N bytes
      // B layout in scratchpad: b_base + (j * tiles_K + k) * DIM
      gemmini_extended3_config_ld(MATMUL_N * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 1);
      for (int j = 0; j < tiles; j++)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin2(
              (void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
              b_base + (j * tiles_K + k) * DIM,
              DIM, DIM);

      // Step 5: configure requantized mvout
      gemmini_extended_config_st(BLK_OUTC * sizeof(out_t), 0, ACC_SCALE_IDENTITY);
      gemmini_mxquant_config_mvout((uint64_t)scale_factors,
          tiles, tiles, tiles_K,
          0, 0, 1);

      // Step 6: compute the weight-stationary tiled matmul
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0,
          a_base, BANK_NUM * BANK_ROWS, 0, SPAD_DEST,
          false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Step 7: drain BF16 results from mx_smem to DRAM
      if (ncols == BLK) {
        gemmini_mx_read_smem(
            &C_hw[i0 * BLK][(j0 * BLK) / BF16_PER_WORD],
            SPAD_DEST * 16,
            mrows * ncols);
      } else {
        for (int r = 0; r < mrows; r++)
          gemmini_mx_read_smem(
              &C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
              SPAD_DEST * 16 + r * BLK,
              ncols);
      }
      gemmini_fence();
    }
}
