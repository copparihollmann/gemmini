## Problem Identified

In the original code, A is loaded using `gemmini_extended_mvin` (port `k_MVIN`) and B is loaded using the **same** `gemmini_extended_mvin` (also `k_MVIN`). Both A and B compete for the same DMA port. The architecture exposes **three independent mvin ports**: `mvin` (k_MVIN), `mvin2` (k_MVIN2), and `mvin3` (k_MVIN3). By issuing all A tile loads on `mvin` and all B tile loads on `mvin2`, the two DMA streams become independent and can execute concurrently in hardware, overlapping A and B transfers.

The reference pattern `matmul_ws_mx_generic.c` uses explicit fences between every tile (which is worse), while `autocomp_baseline_sol0.c` also uses a single mvin port for both A and B.

## Plan

1. **Keep A tile loads on `gemmini_extended_mvin`** (port `k_MVIN`) — no change to the A mvin loop structure.

2. **Switch B tile loads from `gemmini_extended_mvin` to `gemmini_extended_mvin2`** (port `k_MVIN2`). This requires a separate `gemmini_config_ld`-equivalent for port 2, which is `gemmini_extended3_config_ld` with `id=1` (mvin2 uses loader ID 1). Specifically, use:
   ```c
   gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 1);
   ```
   before the B mvin loop, and:
   ```c
   gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 0);
   ```
   before the A mvin loop (explicitly configuring loader ID 0).

3. **Issue all A mvins first (on port 0), then all B mvins (on port 1) without any intervening fence.** The hardware scoreboard tracks which scratchpad rows each DMA write targets and which compute reads depend on; since A rows (`a_base` region) and B rows (`b_base` region) are in non-overlapping scratchpad address ranges, both DMA channels can proceed simultaneously without hazards.

4. **No other changes** — the `gemmini_loop_ws_spad` invocation, `gemmini_mxquant_config_mvout`, `gemmini_mx_read_smem`, and `gemmini_fence` remain identical.

This directly addresses the inefficiency: instead of serializing all A and B DMA transfers through a single port sequentially, the two independent mvin ports pipeline their transfers concurrently, reducing total DMA time for the 96-tile load phase.
