Wait — looking more carefully at the A layout: `a_base + (i*TILES_K + k)*DIM`. For fixed `i`, as `k` goes 0..TILES_K-1, the addresses are `A_BASE + i*TILES_K*DIM + k*DIM` — these **are** contiguous. So the **k-inner loop for fixed i** gives contiguous scratchpad rows.

The current loop is k-outer, i-inner, which breaks contiguity. **Strategy 15** says: coalesce all A-dimension tile mvins for a fixed `i` (iterating over k) into a single wide mvin with `rows = TILES_K * DIM, cols = DIM`, since for fixed `i`, tiles at `k=0..TILES_K-1` are contiguous in the scratchpad.

Similarly for B: for fixed `j`, as `k` goes 0..TILES_K-1, the addresses `B_BASE + j*TILES_K*DIM + k*DIM` are also contiguous. So B tiles for fixed `j` can be coalesced into a single wide mvin2.

This reduces the number of mvin/mvin2 instructions from `TILES_I*TILES_K + TILES_J*TILES_K` down to `TILES_I + TILES_J`, dramatically reducing instruction dispatch overhead.

## Plan

**Switch from k-outer, i/j-inner loops to i-outer (k-inner for A) and j-outer (k-inner for B) loops, then coalesce all k-dimension tiles for each fixed i (or j) into a single wide mvin call.**

Specifically:

1. **Restructure the A mvin loop**: Instead of `for k { for i { mvin 1 tile } }`, do `for i { mvin TILES_K tiles at once }`. For fixed `i`, the DRAM pointer starts at `((elem_t*)A_in) + i*DIM*MATMUL_K + 0*DIM` and the scratchpad address is `A_BASE + i*TILES_K*DIM`. If TILES_K > 4, we need to chunk. But if TILES_K ≤ 4, a single call works.

   More precisely: split into chunks of `min(TILES_K, MAX_BLOCK_LEN)` = up to 4 consecutive DIM-row tiles per mvin. This reduces instruction count by up to 4×.

2. **Restructure the B mvin2 loop**: Similarly, for fixed `j`, issue `ceil(TILES_K / MAX_BLOCK_LEN)` calls with `rows = min(chunk, TILES_K - k_start) * DIM`.

3. **The DRAM stride** (`gemmini_extended3_config_ld` stride) must equal `MATMUL_K * sizeof(elem_t)` so that successive DIM-row blocks step by one row of DIM-wide tiles in DRAM. This is already correctly set.

4. **Keep the rest of the code unchanged** (config_ex, load_scales, config_st, mxquant_config_mvout, loop_ws_spad, mx_read_smem, fence).
