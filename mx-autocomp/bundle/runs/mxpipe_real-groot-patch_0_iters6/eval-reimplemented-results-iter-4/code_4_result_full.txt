### Current Problem

In the original code, the loop structure is:
```

    mvin A tiles (for this i0)
    mvin B tiles (for this j0)   ← B is loaded fresh every (i0, j0) iteration

    readout
```

B tiles depend only on `j0` (they index into `B_in` based on `j0*BLK` column offset and `k*DIM` row offset), **not on `i0`**. Yet they are re-loaded for every `i0` iteration. With `BLOCKS_M` iterations of the outer loop, B is loaded `BLOCKS_M` times more than necessary.

### The Fix

Restructure to hoist B mvin outside the i0 loop:
```
for j0 in BLOCKS_N:
  mvin B tiles once (they don't change with i0)
  for i0 in BLOCKS_M:
    mvin A tiles
    compute
    readout
```

### Scratchpad Layout Verification

- `tiles = BLK/DIM`, `tiles_K = MATMUL_K/DIM`
- `b_base = BANK_NUM*BANK_ROWS - tiles*tiles_K*DIM` (fixed, top of scratchpad)
- A tiles: `tiles_I=tiles` rows of A × `tiles_K` K-tiles × `DIM` = `tiles * tiles_K * DIM` rows
- B tiles occupy: `tiles * tiles_K * DIM` rows at top

Since B doesn't change with `i0`, after the j0-loop hoists B loading, B remains resident in scratchpad across all i0 iterations. A is re-loaded per i0 (as it changes with i0). void solution(void) {
  // config_ex is invariant across all tiles — issue once before all loops
  gemmini_flush(0);
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY,
                               1, 1, 0, 0, false, 0, 0, 3, 0);

  int tiles   = BLK / DIM;
  int tiles_K = MATMUL_K / DIM;
  uint32_t a_base = 0;
  uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
  int SPAD_DEST = 128;

  // j0 is now the outer loop: B tiles are loaded once per j0 and reused
  // across all i0 iterations (B does not depend on i0).
  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    int ncols = REAL_N - j0 * BLK;
    if (ncols > BLK) ncols = BLK;
    if (ncols <= 0) continue;

    // --- Hoist B scale staging and load outside i0 loop ---
    for (int g = 0; g < MATMUL_K / 32; g++)
      memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);

    // --- Hoist B tile mvin outside i0 loop ---
    // Use mvin2 port for B so it is independent of A mvin port.
    gemmini_config_ld(MATMUL_N * sizeof(elem_t));      // B row stride = N
    for (int j = 0; j < tiles; j++)
      for (int k = 0; k < tiles_K; k++)
        gemmini_extended_mvin2(
          (void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
          b_base + (k * tiles + j) * DIM, DIM, DIM);

    // i0 is now inner: A tiles and A scales change with i0
    for (int i0 = 0; i0 < BLOCKS_M; i0++) {
      int mrows = REAL_M - i0 * BLK;
      if (mrows > BLK) mrows = BLK;
      if (mrows <= 0) continue;

      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // Stage A scales (depend on i0)
      for (int g = 0; g < MATMUL_K / 32; g++)
        memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);

      // Load A scales then B scales (programming model: both before compute)
      gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      // Load A tiles (depend on i0)
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));    // A row stride = K
      for (int i = 0; i < tiles; i++)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin(
            (void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
            a_base + (i * tiles_K + k) * DIM, DIM, DIM);

      // Configure output and compute
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors,
                                   tiles, tiles, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0,
                           a_base, BANK_NUM * BANK_ROWS, 0, SPAD_DEST,
                           false, false, false, false, false,
                           NO_ACTIVATION, 0, 0, false, 0x38);

      // Drain results from mx_smem to DRAM
      for (int r = 0; r < mrows; r++)
        gemmini_mx_read_smem(
          &C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
          SPAD_DEST * 16 + r * BLK, ncols);
      gemmini_fence();
    }
  }
