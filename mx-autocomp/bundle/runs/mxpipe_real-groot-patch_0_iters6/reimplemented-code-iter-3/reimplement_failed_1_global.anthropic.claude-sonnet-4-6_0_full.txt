2. **B matrix layout in scratchpad is wrong**: B tiles should be at `b_base + (j*tiles_K + k)*DIM` but the code uses `b_base + (k * tiles + j) * DIM`. The correct formula per the spec is `b_base + (j*tiles_K + k)*DIM`.

3. **`gemmini_mx_read_smem` offset calculation**: The smem offset should be `SPAD_DEST * 16 + r * BLK` but `BLK` here is in elements, need to verify units. This seems correct if BLK is the number of columns.

4. **`gemmini_config_ld` for B**: The stride for B should be `MATMUL_N * sizeof(elem_t)` since B is stored row-major with MATMUL_N columns. This is what the code does, so that's correct.
