## Analysis of the Current Code

Looking at the current code, the key inefficiency I'll target is **strategy 8: precompute A and B DRAM base addresses for each (i0,j0) block outside the inner mvin loops**.

### Current Inefficiency

In the inner mvin loops, the code repeatedly computes complex address expressions:

```c
// A mvin inner loop:
(void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM)

// B mvin inner loop:
(void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM))
```

For A: `i0 * BLK * MATMUL_K` is recomputed for every `(i, k)` pair inside the loop — that's `tiles * tiles_K` times per outer block. The `i * DIM * MATMUL_K` part is also recomputed for every `k` in the inner loop.

For B: `j0 * BLK` is recomputed for every `(j, k)` pair inside the loop.

### Plan

**For the A mvin loop:**
- Hoist `A_block_base = (elem_t*)A_in + i0 * BLK * MATMUL_K` outside both loops (invariant in the i0/j0 block)
- Hoist `A_row_base = A_block_base + i * DIM * MATMUL_K` outside the inner `k` loop (invariant per `i`)
- Inner loop then becomes: `A_row_base + k * DIM`

**For the B mvin loop:**
- Hoist `B_block_base = (elem_t*)B_in + j0 * BLK` outside both loops (invariant in the i0/j0 block)
- Hoist `B_col_base = B_block_base + k * DIM * MATMUL_N` outside the inner `j` loop (invariant per `k`)
- Inner loop then becomes: `B_col_base + j * DIM`

This eliminates repeated multiplications (`i0 * BLK * MATMUL_K`, `i * DIM * MATMUL_K`, `j0 * BLK`, `k * DIM * MATMUL_N`) from the hot inner loops, replacing them with a single pointer addition per iteration.

### Rewritten Code

```c
void solution(void) {
  for (int i0 = 0; i0 < BLOCKS_M; i0++)
   for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }

      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // Precompute DRAM base pointers for A and B blocks — hoist i0*BLK*MATMUL_K
      // and j0*BLK multiplications outside all mvin loops.
      elem_t *A_block_base = (elem_t*)A_in + (i0 * BLK) * MATMUL_K;
      elem_t *B_block_base = (elem_t*)B_in + (j0 * BLK);

      gemmini_flush(0);
      gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
      gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      gemmini_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++) {
        // Hoist i*DIM*MATMUL_K outside the k loop
        elem_t *A_row_base = A_block_base + i * DIM * MATMUL_K;
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin((void*)(A_row_base + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, DIM, DIM);
      }

      gemmini_config_ld(MATMUL_N * sizeof(elem_t));
      for (int k = 0; k < tiles_K; k++) {
        // Hoist k*DIM*MATMUL_N outside the j loop
        elem_t *B_row_base = B_block_base + k * DIM * MATMUL_N;
        for (int j = 0; j < tiles; j++)
          gemmini_extended_mvin((void*)(B_row_base + j * DIM),
                                b_base + (k * tiles + j) * DIM, DIM, DIM);
      }

      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      for (int r = 0; r < mrows; r++)
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      gemmini_fence();
    }
}
```
