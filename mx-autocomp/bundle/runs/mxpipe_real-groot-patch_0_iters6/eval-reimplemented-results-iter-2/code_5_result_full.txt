### Why This Improves Performance

- `gemmini_flush(0)` is a **full pipeline drain** — it waits for all pending accelerator operations to complete before returning. - Together these changes remove `O(BLOCKS_M × BLOCKS_N)` pipeline-draining and redundant config instructions, reducing total cycle count proportionally to the number of tile blocks.

        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);

      uint32_t a_base = 0;
