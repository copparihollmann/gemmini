## Analysis of the Current Code

Looking at the baseline code, I can identify the following structure:
- `gemmini_mxquant_config_mvout` is called with `lut_update_granularity=1`
- The format uses `uselut=0` (no LUT is used, since it's fp8 e4m3 → BF16 output)
- `tiles_I = 64/16 = 4`, `tiles_J = 128/16 = 8`, `tiles_K = 128/16 = 8`

## Selected Strategy: #12 — Set `lut_update_granularity` to maximum value when `uselut=0`

### Why This Applies

The current code calls:
```c
gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, 1);
```

The `lut_update_granularity` (G) is set to `1`, which means the requantizer refreshes its output LUT after **every single tile** during the fused `gemmini_loop_ws_spad` execution. This causes maximum LUT-refresh overhead.

However, `gemmini_extended3_config_ex` is called with `uselut=0`, meaning **no LUT is in use**. The format is fp8 e4m3 inputs → BF16 output (out_mx_fmt=3), which does not require LUT-based requantization. Since there is no LUT to refresh, every LUT-refresh cycle inside the fused loop is pure wasted overhead.

Strategy #12 says: set `lut_update_granularity` to its maximum value (e.g., `tiles_K` or higher) when `uselut=0` to eliminate all requantizer LUT-refresh cycles.

### Plan

Change the `gemmini_mxquant_config_mvout` call from:
```c
gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, 1);
```
to:
```c
gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, tiles_I * tiles_J * tiles_K);
```

Setting G to `tiles_I * tiles_J * tiles_K = 4 * 8 * 8 = 256` means the LUT refresh is scheduled at most once for the entire fused loop (and effectively never triggered during normal execution), eliminating all per-tile LUT-refresh stalls inside `gemmini_loop_ws_spad`. Since `uselut=0`, the LUT content is irrelevant to correctness, so this is safe.

### Rewritten Code

```c
void solution(void) {
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
  gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
  gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);

  // Load A tiles: use mvin port 1, stride = K cols
  // A[i][k] tile at DRAM: A_in + i*DIM*MATMUL_K + k*DIM
  // Spad: a_base + (i*tiles_K + k)*DIM
  // Batch up to MAX_BLOCK_LEN=4 consecutive k tiles per i row
  gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 0);
  for (int i = 0; i < tiles_I; i++) {
    int k = 0;
    while (k < tiles_K) {
      int batch = tiles_K - k;
      if (batch > MAX_BLOCK_LEN) batch = MAX_BLOCK_LEN;
      gemmini_extended_mvin(
        (void*)(((elem_t*)A_in) + i * DIM * MATMUL_K + k * DIM),
        a_base + (i * tiles_K + k) * DIM,
        batch * DIM, DIM);
      k += batch;
    }
  }

  // Load B tiles: use mvin port 2 (mvin2), stride = N cols
  // B[k][j] tile at DRAM: B_in + k*DIM*MATMUL_N + j*DIM
  // Spad: b_base + (k*tiles_J + j)*DIM
  // Batch up to MAX_BLOCK_LEN=4 consecutive j tiles per k row
  gemmini_extended3_config_ld(MATMUL_N * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 1);
  for (int k = 0; k < tiles_K; k++) {
    int j = 0;
    while (j < tiles_J) {
      int batch = tiles_J - j;
      if (batch > MAX_BLOCK_LEN) batch = MAX_BLOCK_LEN;
      gemmini_extended_mvin2(
        (void*)(((elem_t*)B_in) + k * DIM * MATMUL_N + j * DIM),
        b_base + (k * tiles_J + j) * DIM,
        batch * DIM, DIM);
      j += batch;
    }
  }

  gemmini_config_st(OUT_COLS * sizeof(out_t));
  // uselut=0: no LUT is needed; set lut_update_granularity to maximum to
  // eliminate all requantizer LUT-refresh cycles inside the fused loop.
  gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, tiles_I * tiles_J * tiles_K);
  gemmini_loop_ws_spad(tiles_I, tiles_J, tiles_K, 0, 0, 0,
                       a_base, BANK_NUM * BANK_ROWS, 0,
                       SPAD_DEST, false, false, false, false, false,
                       NO_ACTIVATION, 0, 0, false, 0x38);
  gemmini_mx_read_smem(&C_hw[0][0], SPAD_DEST * 16, MATMUL_M * MATMUL_N);
  gemmini_fence();
}
```
