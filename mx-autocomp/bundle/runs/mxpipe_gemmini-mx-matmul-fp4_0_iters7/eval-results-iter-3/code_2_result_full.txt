2. **Redundant DRAM Loads**: In a weight-stationary dataflow, the weight matrix $B$ is stationary. In the baseline, $B$ is loaded inside the same scope as $A$. 1. **Outer-Loop Tiling**:
   - Set $t_i = 2$, $t_j = 8$ (full width), and $t_k = 16$.

3. **Restructured Block Loop**:
