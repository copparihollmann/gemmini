## Strategy: Replace the Innermost `dx` Loop with `memcpy` (Strategy 11)

**How it works:** For each fixed `(pi, pj, c, dy)`, the `dx` loop copies `CONV_KSZ` consecutive bytes from `&X_in[c][pi*CONV_KSZ + dy][pj*CONV_KSZ + 0]` into `&A_buf[pi*PATCHES_X + pj][c*CONV_KSZ*CONV_KSZ + dy*CONV_KSZ + 0]`. Both pointers are contiguous in memory for the `dx` stride, so a single `memcpy(dst, src, CONV_KSZ * sizeof(elem_t))` replaces the entire scalar loop. This reduces loop overhead, enables the C compiler to emit vectorized memory copy (SIMD), and improves cache line utilization by issuing wider stores.
