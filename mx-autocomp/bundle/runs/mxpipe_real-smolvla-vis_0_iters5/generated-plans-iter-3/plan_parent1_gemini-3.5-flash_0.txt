### Optimization Plan

The current implementation suffers from significant instruction-dispatch overhead because it reads output rows from the MX shared memory (`smem`) individually. For a block size of `BLK` (e.g., 64), the program issues `BLK` separate, small `gemmini_mx_read_smem` calls per tile. Each call incurs the overhead of executing a RoCC instruction.

To address this inefficiency, we will apply **Strategy 3: Single contiguous SMEM read with CPU unpacking**.

#### Implementation Steps:
1. **Define a Contiguous Temporary Buffer**: Declare a `static out_t temp_buf[BLK][BLK_OUTC]` to temporarily hold the entire block read from shared memory. This prevents stack overflow and avoids dynamic memory allocation overhead.
2. **Coalesce SMEM Reads**: Replace the loops of row-by-row `gemmini_mx_read_smem` calls with a single `gemmini_mx_read_smem` invocation. Since each row in shared memory is aligned to `BLK` words, we can read the entire 2D grid of size `mrows * BLK` in one command.
3. **Synchronize Once**: Place a single `gemmini_fence()` immediately after the coalesced read to ensure that the DMA transfer completes before the host reads from the temporary buffer.
4. **Perform CPU Unpacking**: Use a fast CPU loop to copy the relevant segments from `temp_buf` into the final strided destination `C_hw`.

---

### Optimized Code

```c
void solution(void) {
  int tiles   = BLK / DIM;
  int tiles_K = MATMUL_K / DIM;
  int GK      = MATMUL_K / 32;

  uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
  uint32_t a_base = 0;
  int SPAD_DEST = 128;

  static uint8_t A_scales_T[BLOCKS_M][A_S_BYTES];
  static uint8_t B_scales_T[BLOCKS_N][B_S_BYTES];
  
  // Temporary buffer to stage contiguous SMEM reads
  static out_t temp_buf[BLK][BLK_OUTC];

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int g = 0; g < GK; g++) {
      memcpy(&A_scales_T[i0][g * BLK],
             &A_scales_row[g][i0 * BLK],
             BLK);
    }
  }

  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    for (int g = 0; g < GK; g++) {
      memcpy(&B_scales_T[j0][g * BLK],
             &B_scales_col[g][j0 * BLK],
             BLK);
    }
  }

  // Hoist the configuration outside all loops as the parameters are invariant
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY,
                              1, 1, 0, 0, false, 0, 0, 3, 0);

  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    int ncols = REAL_N - j0 * BLK;
    if (ncols > BLK) ncols = BLK;
    if (ncols <= 0) continue;

    // Mvin B tiles once per j0
    gemmini_config_ld(MATMUL_N * sizeof(elem_t));
    for (int j = 0; j < tiles; j++)
      for (int k = 0; k < tiles_K; k++)
        gemmini_extended_mvin(
          (void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
          b_base + (k * tiles + j) * DIM, DIM, DIM);

    for (int i0 = 0; i0 < BLOCKS_M; i0++) {
      int mrows = REAL_M - i0 * BLK;
      if (mrows > BLK) mrows = BLK;
      if (mrows <= 0) continue;

      gemmini_flush(0);

      // Load A and B scales
      gemmini_mx_load_scales((uint64_t)A_scales_T[i0], A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)B_scales_T[j0], B_S_BYTES, 1);

      // Mvin A tiles
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin(
            (void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
            a_base + (i * tiles_K + k) * DIM, DIM, DIM);

      // Configure requantized mvout
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors,
                                   tiles, tiles, tiles_K, 0, 0, 1);

      // Dispatch: fast interior path vs slow boundary path
      if (i0 < BLOCKS_M - 1 && j0 < BLOCKS_N - 1) {
        // Fast interior: pad_i = 0, pad_j = 0, mrows = BLK, ncols = BLK
        gemmini_loop_ws_spad(tiles, tiles, tiles_K, 0, 0, 0,
                             a_base, BANK_NUM * BANK_ROWS, 0, SPAD_DEST,
                             false, false, false, false, false,
                             NO_ACTIVATION, 0, 0, false, 0x38);

        // Read the entire tile contiguously in one transaction
        gemmini_mx_read_smem(temp_buf, SPAD_DEST * 16, BLK * BLK);
        gemmini_fence();

        // CPU unpacks the contiguous buffer into the strided C_hw
        for (int r = 0; r < BLK; r++) {
          for (int c = 0; c < BLK_OUTC; c++) {
            C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD + c] = temp_buf[r][c];
          }
        }
      } else {
        // Slow boundary path: handle partial tiles
        int pad_i = BLK - mrows;
        int pad_j = BLK - ncols;

        gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0,
                             a_base, BANK_NUM * BANK_ROWS, 0, SPAD_DEST,
                             false, false, false, false, false,
                             NO_ACTIVATION, 0, 0, false, 0x38);

        // Read the exact active block height (mrows * BLK) contiguously
        gemmini_mx_read_smem(temp_buf, SPAD_DEST * 16, mrows * BLK);
        gemmini_fence();

        // CPU unpacks the active boundaries into C_hw
        int ncols_out = ncols / BF16_PER_WORD;
        for (int r = 0; r < mrows; r++) {
          for (int c = 0; c < ncols_out; c++) {
            C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD + c] = temp_buf[r][c];
          }
        }
      }
    }
  }
}
```
