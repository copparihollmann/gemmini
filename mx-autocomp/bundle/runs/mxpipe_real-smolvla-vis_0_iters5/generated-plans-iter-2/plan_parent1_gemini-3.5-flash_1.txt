An elegant optimization plan to improve the execution performance of the target kernel by avoiding redundant configuration and scale reloading.

### Optimization Plan

1. **Analyze LUT and Format Invariance**:
   The current kernel operates on FP8 (`act_mx_fmt=0`, `wgt_mx_fmt=0`, `out_mx_fmt=3`, `uselut=0`), which does not utilize lookup tables (LUTs). Therefore, `gemmini_mx_load_lut` is not present in the original loop. 
   
2. **Apply Hoisting to Invariant Operations**:
   To address the spirit of the hoisting strategy (avoiding redundant state changes and DRAM transfers), we can hoist other completely invariant operations:
   - **Hoist Execution Configuration**: The `gemmini_extended3_config_ex` call is completely format-invariant across all tiles. We hoist it out of both the `j0` and `i0` loops to the beginning of the function, avoiding redundant configuration overhead.
   - **Hoist B Scale Loading**: The B scale factor load `gemmini_mx_load_scales(..., 1)` depends entirely on the outer loop index `j0` (representing column blocks) and is invariant to the inner loop index `i0` (representing row blocks). We hoist this load out of the `i0` loop into the `j0` loop. This reduces the number of B scale DRAM transfers from $BLOCKS\_N \times BLOCKS\_M$ down to just $BLOCKS\_N$.

3. **Preserve Sequence and Semantics**:
   The hardware requires the sequence: `gemmini_extended3_config_ex` $\rightarrow$ `gemmini_mx_load_scales` $\rightarrow$ `mvin` $\rightarrow$ `gemmini_mxquant_config_mvout` $\rightarrow$ `gemmini_loop_ws_spad` $\rightarrow$ `gemmini_mx_read_smem` $\rightarrow$ `gemmini_fence()`. By placing the hoisted configuration at the start, and loading scales before the compute stage, the state is correctly prepared and sequential correctness is preserved.

void solution(void) {
  int tiles   = BLK / DIM;
  int tiles_K = MATMUL_K / DIM;
  int GK      = MATMUL_K / 32;

  uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
  uint32_t a_base = 0;
  int SPAD_DEST = 128;

  // Static buffers for pre-transposed scale factors
  static uint8_t A_scales_T[BLOCKS_M][A_S_BYTES];
  static uint8_t B_scales_T[BLOCKS_N][B_S_BYTES];
  
  // One-time initialization flag
  static int initialized = 0;
  if (!initialized) {
    // Transpose A scales: from [GK][ROWS] to [BLOCKS_M][GK*BLK]
    for (int i0 = 0; i0 < BLOCKS_M; i0++) {
      for (int g = 0; g < GK; g++) {
        memcpy(&A_scales_T[i0][g * BLK],
               &A_scales_row[g][i0 * BLK],
               BLK);
      }
    }

    // Transpose B scales: from [GK][COLS] to [BLOCKS_N][GK*BLK]
    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      for (int g = 0; g < GK; g++) {
        memcpy(&B_scales_T[j0][g * BLK],
               &B_scales_col[g][j0 * BLK],
               BLK);
      }
    }
    initialized = 1;
  }

  // Flush and configure execution unit once globally (format-invariant)
  gemmini_flush(0);
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY,
                              1, 1, 0, 0, false, 0, 0, 3, 0);

  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    int ncols = REAL_N - j0 * BLK;
    if (ncols > BLK) ncols = BLK;
    if (ncols <= 0) continue;

    // Hoist B scale factors load to the outer loop (independent of i0)
    gemmini_mx_load_scales((uint64_t)B_scales_T[j0], B_S_BYTES, 1);

    // Load B tiles into scratchpad once per j0
    gemmini_config_ld(MATMUL_N * sizeof(elem_t));
    for (int j = 0; j < tiles; j++)
      for (int k = 0; k < tiles_K; k++)
        gemmini_extended_mvin(
          (void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
          b_base + (k * tiles + j) * DIM, DIM, DIM);

    for (int i0 = 0; i0 < BLOCKS_M; i0++) {
      int mrows = REAL_M - i0 * BLK;
      if (mrows > BLK) mrows = BLK;
      if (mrows <= 0) continue;

      // Load A scale factors (depends on i0)
      gemmini_mx_load_scales((uint64_t)A_scales_T[i0], A_S_BYTES, 0);

      // Load A tiles into scratchpad
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin(
            (void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
            a_base + (i * tiles_K + k) * DIM, DIM, DIM);

      // Configure output requantization
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors,
                                   tiles, tiles, tiles_K, 0, 0, 1);

      // Dispatch optimized paths based on boundary conditions
      if (i0 < BLOCKS_M - 1 && j0 < BLOCKS_N - 1) {
        // Fast path: full tiles, no padding
        gemmini_loop_ws_spad(tiles, tiles, tiles_K, 0, 0, 0,
                             a_base, BANK_NUM * BANK_ROWS, 0, SPAD_DEST,
                             false, false, false, false, false,
                             NO_ACTIVATION, 0, 0, false, 0x38);

        for (int r = 0; r < BLK; r++)
          gemmini_mx_read_smem(
            &C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
            SPAD_DEST * 16 + r * BLK, BLK);

        gemmini_fence();
      } else {
        // Boundary path: handle partial tiles with padding
        int pad_i = BLK - mrows;
        int pad_j = BLK - ncols;

        gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0,
                             a_base, BANK_NUM * BANK_ROWS, 0, SPAD_DEST,
                             false, false, false, false, false,
                             NO_ACTIVATION, 0, 0, false, 0x38);

        for (int r = 0; r < mrows; r++)
          gemmini_mx_read_smem(
            &C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
            SPAD_DEST * 16 + r * BLK, ncols);

        gemmini_fence();
      }
    }
  }
}
