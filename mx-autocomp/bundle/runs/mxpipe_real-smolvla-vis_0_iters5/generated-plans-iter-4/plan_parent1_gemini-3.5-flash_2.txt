An elegant and highly effective optimization strategy to dramatically reduce the execution time of this kernel is **Scratchpad Space-Partitioned Pre-loading and MVIN Amortization**.

### Optimization Plan

1. **Space-Partitioned Scratchpad Pre-loading**: Since the scratchpad size is 256KB (8192 rows) and our total tile footprint for all $I$ and $J$ blocks of $A$ and $B$ combined is extremely small (only 2048 rows), we can partition the scratchpad space to hold **all** $A$ and $B$ blocks simultaneously. 
   - Each $A$ block $i_0$ is assigned a private region starting at `a_base_i0 = i0 * tiles * tiles_K * DIM`.
   - Each $B$ block $j_0$ is assigned a private region growing downward from `b_end_j0 = BANK_NUM * BANK_ROWS - j0 * tiles * tiles_K * DIM`.
   - This allows us to load all $A$ and $B$ tiles into the scratchpad **exactly once** at the start of the function, completely eliminating all `gemmini_extended_mvin` calls from the inner loops.

2. **Single-MVIN Column-Batching for $B$**: Instead of performing individual `tiles * tiles_K` `mvin` calls for each $B$ block, we batch along the $K$ dimension. Since a column of tiles is contiguous in the scratchpad, we can load an entire block of size `DIM` by `tiles_K * DIM` using a **single `gemmini_extended_mvin` call** per column segment, reducing the number of $B$ MVIN operations by $4\times$.

3. **Requantization Config Hoisting**: The `gemmini_mxquant_config_mvout` and stride configurations are invariant across all loop iterations. We hoist them entirely out of the execution loops to eliminate redundant instruction issues.

4. **Unified Boundary Read Padding**: We merge the interior and boundary paths into a single clean pipeline. By padding the `gemmini_mx_read_smem` column count to `BLK` (which is a multiple of 16, and thus aligned to 64-bit boundaries), we ensure high-bandwidth contiguous DMA bursts for all reads while simplifying host control overhead.

### Optimized Code

```c
void solution(void) {
  int tiles   = BLK / DIM;
  int tiles_K = MATMUL_K / DIM;
  int GK      = MATMUL_K / 32;

  uint32_t a_base = 0;
  int SPAD_DEST = 128;

  static uint8_t A_scales_T[BLOCKS_M][A_S_BYTES];
  static uint8_t B_scales_T[BLOCKS_N][B_S_BYTES];

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int g = 0; g < GK; g++) {
      memcpy(&A_scales_T[i0][g * BLK],
             &A_scales_row[g][i0 * BLK],
             BLK);
    }
  }

  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    for (int g = 0; g < GK; g++) {
      memcpy(&B_scales_T[j0][g * BLK],
             &B_scales_col[g][j0 * BLK],
             BLK);
    }
  }

  // 1. Hoist the configuration outside all loops
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY,
                              1, 1, 0, 0, false, 0, 0, 3, 0);

  // 2. Pre-load all B blocks into partitioned high scratchpad memory
  gemmini_config_ld(MATMUL_N * sizeof(elem_t));
  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    uint32_t b_end = BANK_NUM * BANK_ROWS - j0 * tiles * tiles_K * DIM;
    uint32_t b_base_j0 = b_end - tiles * tiles_K * DIM;
    for (int j = 0; j < tiles; j++) {
      gemmini_extended_mvin(
        (void*)(((elem_t*)B_in) + j0 * BLK + j * DIM),
        b_base_j0 + j * tiles_K * DIM,
        DIM,
        tiles_K * DIM
      );
    }
  }

  // 3. Pre-load all A blocks into partitioned low scratchpad memory
  gemmini_config_ld(MATMUL_K * sizeof(elem_t));
  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    uint32_t a_base_i0 = a_base + i0 * tiles * tiles_K * DIM;
    for (int i = 0; i < tiles; i++) {
      for (int k = 0; k < tiles_K; k++) {
        gemmini_extended_mvin(
          (void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
          a_base_i0 + (i * tiles_K + k) * DIM,
          DIM,
          DIM
        );
      }
    }
  }

  // 4. Hoist invariant requantized mvout configurations out of loops
  gemmini_config_st(BLK_OUTC * sizeof(out_t));
  gemmini_mxquant_config_mvout((uint64_t)scale_factors,
                               tiles, tiles, tiles_K, 0, 0, 1);

  // 5. Execution loops (No MVIN latency during compute!)
  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    int ncols = REAL_N - j0 * BLK;
    if (ncols > BLK) ncols = BLK;
    if (ncols <= 0) continue;

    uint32_t b_end_j0 = BANK_NUM * BANK_ROWS - j0 * tiles * tiles_K * DIM;

    for (int i0 = 0; i0 < BLOCKS_M; i0++) {
      int mrows = REAL_M - i0 * BLK;
      if (mrows > BLK) mrows = BLK;
      if (mrows <= 0) continue;

      uint32_t a_base_i0 = a_base + i0 * tiles * tiles_K * DIM;

      gemmini_flush(0);

      // Load A and B scales
      gemmini_mx_load_scales((uint64_t)A_scales_T[i0], A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)B_scales_T[j0], B_S_BYTES, 1);

      int pad_i = BLK - mrows;
      int pad_j = BLK - ncols;

      // Compute weight-stationary tiled matmul over pre-loaded scratchpad
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0,
                           a_base_i0, b_end_j0, 0, SPAD_DEST,
                           false, false, false, false, false,
                           NO_ACTIVATION, 0, 0, false, 0x38);

      // Fast contiguous DMA read (padded to BLK columns)
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(
          &C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
          SPAD_DEST * 16 + r * BLK, BLK);
      }

      gemmini_fence();
    }
  }
}
```
