# Strategy Plan: Host-CPU Scale Packing Elimination

To address the major performance bottleneck of host-CPU data staging in the inner loops, we will implement **Strategy 5: Host-CPU Scale Packing Elimination**. 

### Inefficiency Analysis
In the baseline implementation, the scale factors for each tile are packed on the host CPU inside the nested `i0` and `j0` loops using a series of `memcpy` operations:
```c
for (int g = 0; g < MATMUL_K / 32; g++) {
  memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
  memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
}
```
Since these `memcpy` calls run on the host CPU for every single outer tile, they introduce substantial scalar overhead and prevent the accelerator from running at peak throughput.

### Optimization Plan
1. **Pre-allocated Contiguous Buffers**: We will define two static, 32-byte aligned buffers, `A_scales_packed` and `B_scales_packed`, to hold the fully packed scale factors for all blocks of M and N.
2. **One-Time Pre-Formatting**: Before entering the nested computation loops, we will perform a one-time copy of all scale factors from the testbench matrices (`A_scales_row` and `B_scales_col`) into our contiguous buffers. This hoists all CPU copy overhead out of the critical path.
3. **Direct Scale Streaming**: Inside the `i0` and `j0` loops, we will completely eliminate the host-CPU `memcpy` calls. Instead, we will stream the scale factors directly from our pre-formatted DRAM buffers using `gemmini_mx_load_scales` with the appropriate block offset.

---

# Optimized Code

```c
#include <stdint.h>
#include <string.h>
#include "include/gemmini_testutils.h"
#include "include/matmul_fp8_64x64.h"

// AUTO-GENERATED outer-tiled MX matmul optimized via Host-CPU Scale Packing Elimination.
void solution(void) {
  // Static buffers to hold the pre-formatted contiguous scale factors.
  static uint8_t A_scales_packed[BLOCKS_M][MATMUL_K / 32][BLK] __attribute__((aligned(32)));
  static uint8_t B_scales_packed[BLOCKS_N][MATMUL_K / 32][BLK] __attribute__((aligned(32)));

  // 1. One-time host-CPU scale packing (hoisted out of the nested hot loops)
  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      memcpy(&A_scales_packed[i0][g][0], &A_scales_row[g][i0 * BLK], BLK);
    }
  }
  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      memcpy(&B_scales_packed[j0][g][0], &B_scales_col[g][j0 * BLK], BLK);
    }
  }

  // Pre-configure the execution once, outside the main loops.
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY,
                              /*C_stride*/1, /*A_stride*/1,
                              /*A_transpose*/0, /*B_transpose*/0,
                              /*set_only_strides*/false,
                              /*act_mx_fmt*/0, /*wgt_mx_fmt*/0, /*out_mx_fmt*/3,
                              /*uselut*/0);

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last M/N block: compute only the real rows/cols, pad the rest.
      int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // Flush Gemmini state before loading new block scales
      gemmini_flush(0);

      // 2. Direct streaming of pre-packed scales (completely avoiding CPU memcpy in the loop)
      gemmini_mx_load_scales((uint64_t)&A_scales_packed[i0][0][0], A_S_BYTES, 0);  // sel=0 for activation scales
      gemmini_mx_load_scales((uint64_t)&B_scales_packed[j0][0][0], B_S_BYTES, 1);  // sel=1 for weight scales

      // MVIN A tiles into scratchpad
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));      // A rows: stride K
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin(
              (void *)(((elem_t *)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
              a_base + (i * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      // MVIN B tiles into scratchpad (placed at top of spad)
      gemmini_config_ld(MATMUL_N * sizeof(elem_t));      // B rows: stride N
      for (int j = 0; j < tiles; j++) {                  // B[k][j0*BLK+j] -> slot (k*tiles + j)
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin(
              (void *)(((elem_t *)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
              b_base + (k * tiles + j) * DIM, DIM, DIM);
        }
      }

      // Configure output and requantization
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors,
                                   tiles, tiles, tiles_K,
                                   /*scale_act_sel*/0, /*scale_w_sel*/0,
                                   /*lut_update_granularity*/1);

      // Execute weight-stationary matmul on scratchpad data
      gemmini_loop_ws_spad(tiles, tiles, tiles_K,
                           pad_i, pad_j, 0,
                           a_base, BANK_NUM * BANK_ROWS, 0, SPAD_DEST,
                           false, false, false, false, false,
                           NO_ACTIVATION, 0, 0, false, 0x38);

      // Drain BF16 output from shared memory to DRAM
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }

      // Wait until all outputs have been written
      gemmini_fence();
    }
  }
}
```
