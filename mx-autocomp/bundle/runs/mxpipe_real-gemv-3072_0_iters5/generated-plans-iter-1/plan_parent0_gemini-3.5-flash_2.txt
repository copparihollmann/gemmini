An elegant and highly effective optimization strategy for this code is **Strategy 4: Compile configuration sequences as non-inlined functions**.

### Method Explanation
The inline assembly macros used to interface with the Gemmini coprocessor (`gemmini_extended3_config_ex`, `gemmini_extended_mvin`, `gemmini_loop_ws_spad`, etc.) expand into multiple instructions that load registers and issue the RoCC custom instructions. When these macros are used directly inside nested loops, the compiler is forced to emit a large amount of inline assembly code repeatedly. This leads to:
1. **Host-Side Instruction Cache (I-Cache) Thrashing**: The generated binary grows excessively, and the host processor experiences more instruction cache misses.
2. **Register Spilling**: The inline assembly constraints increase register pressure on the compiler, causing the compiler to spill variables to the stack and insert redundant load/store instructions.

By encapsulating these repetitive instruction-building macros into standalone, non-inlined helper functions using `__attribute__((noinline))`, we force the compiler to generate clean function calls. The custom instructions are compiled once, minimizing binary size, relieving register pressure, and dramatically reducing host-side CPU overhead.

### Optimization Plan
1. **Define Non-Inlined Helper Functions**: Create helper functions marked with `__attribute__((noinline))` for:
   - Config-ex configuration (`helper_config_ex`)
   - MX scale loading (`helper_mx_load_scales`)
   - Config-ld configuration (`helper_config_ld`)
   - Scratchpad data movement via mvin (`helper_extended_mvin`)
   - Config-st configuration (`helper_config_st`)
   - Output quantization setup (`helper_mxquant_config_mvout`)
   - Fused weight-stationary execution (`helper_loop_ws_spad`)
   - Shared memory readout (`helper_mx_read_smem`)
2. **Refactor `solution`**: Replace direct inline macro invocations in `solution()` with corresponding helper function calls, passing necessary arguments.
3. **Verify Program Correctness**: Ensure the instruction sequence, scratchpad addresses, and control registers remain functionally identical to the original implementation.

// Optimized solution entry point
void solution(void) {
  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last M/N block calculation
      int mrows = REAL_M - i0 * BLK; 
      if (mrows > BLK) mrows = BLK; 
      if (mrows <= 0) continue;
      
      int ncols = REAL_N - j0 * BLK; 
      if (ncols > BLK) ncols = BLK; 
      if (ncols <= 0) continue;
      
      // Stage only the tiny per-32-group scales
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }
      
      int tiles = BLK / DIM;
      int tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows;
      int pad_j = BLK - ncols;
      
      gemmini_flush(0);
      
      // Configuration through non-inlined wrappers
      helper_config_ex();
      helper_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);
      helper_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);
      
      // Load matrix A tiles
      helper_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          void *dram_ptr = (void *)(((elem_t *)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM);
          uint32_t spad_addr = a_base + (i * tiles_K + k) * DIM;
          helper_extended_mvin(dram_ptr, spad_addr, DIM, DIM);
        }
      }
      
      // Load matrix B tiles
      helper_config_ld(MATMUL_N * sizeof(elem_t));
      for (int j = 0; j < tiles; j++) {
        for (int k = 0; k < tiles_K; k++) {
          void *dram_ptr = (void *)(((elem_t *)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM));
          uint32_t spad_addr = b_base + (k * tiles + j) * DIM;
          helper_extended_mvin(dram_ptr, spad_addr, DIM, DIM);
        }
      }
      
      // Configure writeback and scale factors
      helper_config_st(BLK_OUTC * sizeof(out_t));
      helper_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K);
      
      // Perform computing
      helper_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, a_base, BANK_NUM * BANK_ROWS, SPAD_DEST);
      
      // Read output using non-inlined wrapper
      for (int r = 0; r < mrows; r++) {
        void *dram_dest = &C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD];
        uint32_t smem_offset = SPAD_DEST * 16 + r * BLK;
        helper_mx_read_smem(dram_dest, smem_offset, ncols);
      }
      
      gemmini_fence();
    }
  }
}
