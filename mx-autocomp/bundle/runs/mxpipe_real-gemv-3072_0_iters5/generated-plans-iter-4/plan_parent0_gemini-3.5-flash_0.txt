### Optimization Strategy: Hoisting Weight Tile and Scale Loading to the Outer Loop for Stationary Scratchpad/Scale Reuse

In the baseline program, the nested loops are structured such that the activation dimension $I$ (indexed by `i0`) is the outer loop, and the weight dimension $J$ (indexed by `j0`) is the inner loop. Within the innermost loop, both the activation tile $A$, the weight tile $B$, and their respective scale factors ($A\_scales$ and $B\_scales$) are re-loaded from DRAM every single iteration. 

Since Gemmini's scratchpad memory is physically partitioned to allow operand $A$ and operand $B$ to occupy non-overlapping address spaces ($a\_base$ starts at $0$, and $b\_base$ grows downward from the top of the scratchpad), we can keep the weight tile $B$ and its scales stationary in the hardware. 

By swapping the loop order—making the weight dimension `j0` the outer loop and the activation dimension `i0` the inner loop—we can:
1. **Hoist the loading of $B$ tiles and $B$ scale factors out of the inner loop.** The $B$ tiles are loaded into the scratchpad only once per `j0` step and remain stationary.
2. **Reuse the loaded weights across all `i0` iterations.** Rather than transferring the same $B$ tiles $\text{BLOCKS\_M} \times \text{BLOCKS\_N}$ times, they are transferred only $\text{BLOCKS\_N}$ times, reducing the total weight DMA volume by a factor of $\text{BLOCKS\_M}$.
3. **Amortize scale loading overhead.** The $B$-side column scales are written into Gemmini's persistent `mx_scale_b_mem` once per outer loop iteration and are not overwritten by the inner loop's $A$-side scale updates (which go to `mx_scale_a_mem`).

### Optimized Code

```c
// AUTO-GENERATED outer-tiled MX matmul optimized solution.
void solution(void) {
  // Global config setup
  gemmini_flush(0);
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

  // Outer loop over weight blocks (J dimension)
  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    int ncols = REAL_N - j0 * BLK; 
    if (ncols > BLK) ncols = BLK; 
    if (ncols <= 0) continue;

    int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
    uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;

    // 1. Hoist and stage weight scale factors once per j0
    for (int g = 0; g < MATMUL_K / 32; g++) {
      memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
    }
    gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

    // 2. Hoist and MVIN weight (B) tiles once per j0
    gemmini_config_ld(MATMUL_N * sizeof(elem_t)); // B rows: stride N
    for (int j = 0; j < tiles; j++) { // B[k][j0*BLK+j] -> slot (k*tiles + j)
      for (int k = 0; k < tiles_K; k++) {
        gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                              b_base + (k * tiles + j) * DIM, DIM, DIM);
      }
    }

    // Inner loop over activation blocks (I dimension)
    for (int i0 = 0; i0 < BLOCKS_M; i0++) {
      int mrows = REAL_M - i0 * BLK; 
      if (mrows > BLK) mrows = BLK; 
      if (mrows <= 0) continue;

      uint32_t a_base = 0;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // 3. Stage and load activation scale factors for this i0
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
      }
      gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);

      // 4. MVIN activation (A) tiles for this i0
      gemmini_config_ld(MATMUL_K * sizeof(elem_t)); // A rows: stride K
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      // 5. Configure output strides and requantizer
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);

      // 6. Run compute using skips=0x38 to bypass redundant DRAM preloads of stationary weights
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // 7. Drain the BF16 packed outputs to host memory
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
```
