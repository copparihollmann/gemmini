An elegant and highly effective optimization strategy for this hardware is **DMA Transfer Coalescing (Contiguous Multi-Tile MVIN)**.

### Strategy Explanation

In the baseline implementation, the inputs $A$ and $B$ are loaded into the scratchpad tile-by-tile using nested loops. For $A$, this performs `tiles * tiles_K` individual `gemmini_extended_mvin` calls. For $B$, it similarly performs `tiles * tiles_K` calls. Each individual `mvin` call of a $16 \times 16$ tile carries non-trivial host-to-coprocessor instruction issue overhead and DMA startup latency. 

Since $A$ is stored in row-major layout in DRAM, and its scratchpad destination layout `a_base + (i * tiles_K + k) * DIM` is contiguous across the inner $K$ dimension, we can coalesce the entire horizontal dimension of the block into a single, wide DMA transfer. For each row-block $i$, we can load all $K$ tiles simultaneously using a single `mvin` instruction of width `tiles_K * DIM` columns and height `DIM` rows. This reduces the number of $A$ `mvin` instructions from `tiles * tiles_K` to just `tiles`.

Similarly, for $B$, the destination layout in the scratchpad is `b_base + (k * tiles + j) * DIM`. By looping over $k$ on the outer loop and coalescing the horizontal $j$ dimension, we can load a contiguous chunk of `tiles * DIM` columns with a single `mvin` call. This reduces the number of $B$ `mvin` instructions from `tiles * tiles_K` to `tiles_K`.

This optimization dramatically decreases the number of RoCC instructions issued by the host CPU and leverages the maximum bandwidth of the Gemmini DMA controller by streaming larger contiguous blocks of data.

### Optimized Code

```c
// Optimized MX matmul using DMA Transfer Coalescing.
void solution(void) {
  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last M/N block: compute only the real rows/cols, pad the rest.
      int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      // Stage only the tiny per-32-group scales
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }

      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      gemmini_flush(0);
      gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
      gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      // Coalesced MVIN for A: Load entire row-blocks contiguously across K
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));      // A rows: stride K
      for (int i = 0; i < tiles; i++) {
        gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K),
                              a_base + (i * tiles_K) * DIM, 
                              tiles_K * DIM, 
                              DIM);
      }

      // Coalesced MVIN for B: Load entire row-blocks contiguously across J (N-dimension)
      gemmini_config_ld(MATMUL_N * sizeof(elem_t));      // B rows: stride N
      for (int k = 0; k < tiles_K; k++) {
        gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + j0 * BLK),
                              b_base + (k * tiles) * DIM, 
                              tiles * DIM, 
                              DIM);
      }

      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Accelerator-centric readout
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
```
