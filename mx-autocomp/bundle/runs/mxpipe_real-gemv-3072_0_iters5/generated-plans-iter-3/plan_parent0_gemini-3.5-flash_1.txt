An elegant and highly effective optimization plan to improve the performance of the weight-stationary MX matmul.

### Optimization Plan

1. **Hoist Global Configurations (Strategy 2: Eliminate Redundant Computation)**
   The baseline program calls `gemmini_flush(0)` and `gemmini_extended3_config_ex` inside the innermost execution block. Since the MX execution format, strides, dataflow mode (weight-stationary), and transpose settings do not change across iterations of `i0` and `j0`, we can hoist these configuration instructions completely outside the outer loops. This eliminates redundant RoCC configuration overhead for every execution tile.

2. **Single-Command Multi-Row MVIN Loading for B (Strategy 6 & Rule 12)**
   In the baseline program, B is loaded tile-by-tile using a nested loop over `j` and `k`, resulting in `tiles_I * tiles_K` separate `mvin` instructions. 
   Rule 12 requires that B tiles be indexed in the scratchpad as `b_base + (j * tiles_K + k) * DIM`. Under this exact layout, for any fixed column-tile index `j`, the $K$-dimension tiles (`k = 0` to `tiles_K - 1`) are arranged **completely contiguously** in the scratchpad. 
   We can exploit this property by replacing the inner loop over `k` with a single larger `gemmini_extended_mvin` call of size `DIM` (columns) by `tiles_K * DIM` (rows) with a DRAM stride of `MATMUL_N`. This collapses the loading of all $K$-tiles for a column-tile `j` into a single DMA instruction, drastically reducing RISC-V CPU instruction overhead and allowing the hardware DMA engine to maximize DRAM burst efficiency.

### Optimized Code

```c
// Optimized tiled MX matmul (1x1024x3072).
void solution(void) {
  // Hoist global configurations outside the execution loops
  gemmini_flush(0);
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last M/N block: compute only the real rows/cols, pad the rest.
      int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      // Stage only the tiny per-32-group scales
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }

      int tiles = BLK / DIM;
      int tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows;
      int pad_j = BLK - ncols;

      // Load scale factors
      gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      // MVIN A: Strided straight from DRAM row-by-row
      gemmini_config_ld(MATMUL_K * sizeof(elem_t)); // A rows: stride K
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      // MVIN B: Single-command multi-row loading exploiting contiguous scratchpad layout
      gemmini_config_ld(MATMUL_N * sizeof(elem_t)); // B rows: stride N
      for (int j = 0; j < tiles; j++) {
        void *dram_ptr = (void*)(((elem_t*)B_in) + (j0 * BLK + j * DIM));
        uint32_t sp_addr = b_base + (j * tiles_K) * DIM;
        gemmini_extended_mvin(dram_ptr, sp_addr, DIM, tiles_K * DIM);
      }

      // Configure store + MX requantizer for the mvout
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);

      // Execute weight-stationary tiled loop
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Readout packed results row-by-row
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
```
