### Optimization Plan: Hoisting Invariant Configurations and LUT Management

1. **Analyze LUT Usage and Format Invariance**:
   The current kernel performs an FP8 E4M3 matrix multiplication with `uselut=0` (as configured by the last argument of `gemmini_extended3_config_ex`). Since `uselut` is disabled, the hardware does not require any Lookup Tables (LUTs) to decode FP6 values, and thus no `gemmini_mx_load_lut` call is present in the inner loop.

2. **Hoist Invariant Configurations (Following Strategy 1)**:
   Although `gemmini_mx_load_lut` is not actively used in this specific FP8 configuration, the underlying performance bottleneck of redundant configuration re-issuing still applies to the format configuration itself. 
   
   Currently, `gemmini_extended3_config_ex` is called inside the innermost `j0` loop. Because the execution parameters (dataflow, shifts, scales, strides, and formats) are completely static and invariant across all blocks, configuring the execution unit on every tile iteration is redundant and introduces unnecessary instruction overhead.

3. **Refactoring Steps**:
   - Hoist the invariant configuration call `gemmini_extended3_config_ex` out of the nested loops to the very beginning of the `solution` function.
   - If this kernel were modified in the future to use a LUT-based format (such as FP6 with `uselut=1`), the corresponding `gemmini_mx_load_lut` call would similarly be placed right after this hoisted configuration call, completely outside the `i0` and `j0` loops, ensuring it is only loaded once.

void solution(void) {
  // Hoist invariant execution configuration outside of all loops
  gemmini_flush(0);
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

  // If uselut was enabled (e.g., uselut=1), gemmini_mx_load_lut would be called here:
  // gemmini_mx_load_lut((uint64_t)lut_dram, num_luts, sel);

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;

    // A scales only depend on i0: copy once per i0, reuse across all j0.
    for (int g = 0; g < MATMUL_K / 32; g++)
      memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      // B scales depend on j0: copy once per (i0,j0).
      for (int g = 0; g < MATMUL_K / 32; g++)
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);

      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);
      
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, DIM, DIM);
                                
      gemmini_config_ld(MATMUL_N * sizeof(elem_t));
      for (int j = 0; j < tiles; j++)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                                b_base + (k * tiles + j) * DIM, DIM, DIM);
                                
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
                           
      for (int r = 0; r < mrows; r++)
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      gemmini_fence();
    }
  }
}
