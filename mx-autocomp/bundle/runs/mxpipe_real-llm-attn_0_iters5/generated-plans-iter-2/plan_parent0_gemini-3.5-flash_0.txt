An elegant and highly effective strategy to optimize this program is **Zero-Copy Scale Factor Hoisting**.

### Strategy Explanation: Zero-Copy Scale Factor Hoisting

In the baseline implementation, the host CPU performs multiple nested `memcpy` operations to stage scale factors into temporary contiguous buffers (`A_s` and `B_s`) before streaming them to the accelerator via `gemmini_mx_load_scales`. Because host-CPU-to-DRAM memory copy overhead is often the primary bottleneck on Gemmini systems, this approach introduces significant latency.

Furthermore, the scale factors are redundantly re-loaded via RoCC commands inside the tiling loops on every single iteration, wasting command queue bandwidth and adding instruction dispatch latency.

**How Zero-Copy Scale Factor Hoisting works:**
1. **Hoists Scale Loading to the Outer Scope:** We load the entire scale factor matrices (`A_scales_row` and `B_scales_col`) into the on-chip scale-factor SRAM once at the very beginning of the program.
2. **Eliminates Host-Side `memcpy`:** We pass the addresses of the original scale arrays (`&A_scales_row` and `&B_scales_col`) directly to the `gemmini_mx_load_scales` instruction. The hardware scale-factor memory is large enough to easily house the full scale matrices, and the accelerator's internal DMA will stream them directly from their source DRAM locations.
3. **Saves Instruction Overhead:** We completely eliminate the redundant `gemmini_mx_load_scales` calls from the inner tiling loop, reducing execution time and CPU-coprocessor synchronization overhead.

### Optimized Code

```c
void solution(void) {
  // Hoist invariant configuration outside all loops
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

  // Load the ENTIRE scale factor matrices directly from their source DRAM locations.
  // This utilizes the hardware DMA to stream scales directly into the scale memories (sel 0 = A, sel 1 = B),
  // completely eliminating host-CPU memcpy staging and redundant inner-loop scale loads.
  gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
  gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    int mrows = REAL_M - i0 * BLK; 
    if (mrows > BLK) mrows = BLK; 
    if (mrows <= 0) continue;

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int ncols = REAL_N - j0 * BLK; 
      if (ncols > BLK) ncols = BLK; 
      if (ncols <= 0) continue;

      int tiles = BLK / DIM;
      int tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows;
      int pad_j = BLK - ncols;

      gemmini_flush(0);

      // MVIN A tiles directly from strided source
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      // MVIN B tiles directly from strided source
      gemmini_config_ld(MATMUL_N * sizeof(elem_t));
      for (int j = 0; j < tiles; j++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                                b_base + (k * tiles + j) * DIM, DIM, DIM);
        }
      }

      // Configure store and requantizer
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);

      // Fused WS compute loop over scratchpad
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Read output from shared memory
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
```
