### Optimization Plan

Our goal is to apply **Strategy 5** to eliminate the significant overhead of CPU data staging (`memcpy` of scale factor sub-blocks) and scale-factor DRAM loads inside the tiled loops. 

In the original code, block-specific scale factors are copied on the CPU using `memcpy` into `A_s` and `B_s` buffers before being loaded into Gemmini's scale memory inside the nested loops. This is highly inefficient because:
1. The CPU host staging (`memcpy`) dominates execution time.
2. Loading scale factors repeatedly inside the inner loops introduces redundant memory transactions.

Since scale-factor memory in Gemmini persists until overwritten, and the hardware can index into loaded scale-factor matrices automatically based on the active tile coordinates, we can load the **entire** scale-factor matrices (`A_scales_row` and `B_scales_col`) once at the very start of the program.

#### Steps:
1. **Hoist Configuration and Scale Loading:** Move `gemmini_extended3_config_ex` and both `gemmini_mx_load_scales` calls (for activation/A scales with `sel=0` and weight/B scales with `sel=1`) to the very beginning of the `solution` function, outside of all loops.
2. **Direct Scale Memory Load:** Load the entire `A_scales_row` and `B_scales_col` matrices directly from their DRAM addresses using `sizeof(A_scales_row)` and `sizeof(B_scales_col)` to specify the size.
3. **Eliminate CPU Staging:** Remove the `memcpy` loops and sub-buffers `A_s` and `B_s`, entirely avoiding CPU-side scale copying.
4. **Remove Inner Loop Scale Loading:** Remove the redundant `gemmini_mx_load_scales` calls from inside the nested `i0` and `j0` loops.

---

### Optimized Code

```c
void solution(void) {
  // Flush Gemmini cache/pipeline
  gemmini_flush(0);

  // 1. Configure Gemmini for weight-stationary MX mode
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

  // 2. Pre-load the entire scale factor matrices of both A and B at the start
  gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
  gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // MVIN A tiles directly from source DRAM
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      // MVIN B tiles directly from source DRAM
      gemmini_config_ld(MATMUL_N * sizeof(elem_t));
      for (int j = 0; j < tiles; j++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                                b_base + (k * tiles + j) * DIM, DIM, DIM);
        }
      }

      // Configure requantization bounds and output scale memory destination
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);

      // Execute fused WS tiled loop
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Drain results from shared memory
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
```
