An elegant and highly effective optimization strategy that is distinct from the listed strategies is **Activation Tile Hoisting with Coalesced Loop-Swapped DRAM Transfers**.

### Explanation of the Strategy

1. **Activation Scale and Tile Hoisting:**
   In the original code, the input activation $A$ tiles and their corresponding scale factors are reloaded from DRAM inside the inner `j0` loop. Since these operands only depend on the row block index `i0`, reloading them on every iteration of `j0` incurs redundant DRAM bandwidth and RoCC instruction queue overhead. By hoisting the loading of $A$ scales (`gemmini_mx_load_scales` with `sel=0`) and the $A$ tile `mvin` loop into the outer `i0` loop, we reuse the activations across all column blocks of $B$. This reduces the DRAM transfer volume for activations by a factor of `BLOCKS_N`.

2. **Loop-Swapped B-Tile Coalescing:**
   The original B tile `mvin` loop iterates with `k` as the inner loop. Because B tiles are laid out in the scratchpad with a stride of `tiles * DIM`, consecutive iterations of `k` target non-contiguous destination addresses in the scratchpad. By swapping the `j` and `k` loops so that `j` is the innermost loop, both the source DRAM addresses and the destination scratchpad addresses become completely contiguous. This allows us to coalesce up to `MAX_BLOCK_LEN = 4` consecutive tiles into a single wide `gemmini_extended_mvin` instruction, reducing coprocessor instruction pressure by up to 4×.

---

### Optimized Code

```c
void solution(void) {
  int tiles = BLK / DIM;
  int tiles_K = MATMUL_K / DIM;
  uint32_t a_base = 0;

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;

    // A scales only depend on i0: copy once per i0, reuse across all j0.
    for (int g = 0; g < MATMUL_K / 32; g++)
      memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);

    // Hoist configuration, A scales, and A tiles out of the J-loop
    gemmini_flush(0);
    gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
    gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);

    gemmini_config_ld(MATMUL_K * sizeof(elem_t));
    for (int i = 0; i < tiles; i++) {
      for (int k = 0; k < tiles_K; k += 4) {
        int len = (tiles_K - k < 4) ? (tiles_K - k) : 4;
        gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                              a_base + (i * tiles_K + k) * DIM, len * DIM, DIM);
      }
    }

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      // B scales depend on j0: copy once per (i0,j0).
      for (int g = 0; g < MATMUL_K / 32; g++)
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);

      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      // Coalesce B transfers using loop-swapped contiguous loading
      gemmini_config_ld(MATMUL_N * sizeof(elem_t));
      for (int k = 0; k < tiles_K; k++) {
        for (int j = 0; j < tiles; j += 4) {
          int len = (tiles - j < 4) ? (tiles - j) : 4;
          gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                                b_base + (k * tiles + j) * DIM, len * DIM, DIM);
        }
      }

      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
      
      for (int r = 0; r < mrows; r++)
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      gemmini_fence();
    }
  }
}
```
