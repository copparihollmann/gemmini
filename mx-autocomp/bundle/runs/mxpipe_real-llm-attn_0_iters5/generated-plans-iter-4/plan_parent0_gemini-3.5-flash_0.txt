An elegant and highly effective optimization plan to address the inefficiencies in the provided code is **loop reordering and restructuring** (Strategy 2).

### Inefficiency Analysis
In the original implementation, the outer loop is `i0` (M-dimension blocks) and the inner loop is `j0` (N-dimension blocks). Within the inner `j0` loop, the program:
1. Reloads the B scale factors from DRAM to host memory (`memcpy`) and then to the scale memory (`gemmini_mx_load_scales`).
2. Reloads the B matrix tiles from DRAM into the scratchpad (`gemmini_extended_mvin`).

Because the B matrix blocks and their scale factors only depend on `j0`, reloading them inside the inner `j0` loop means they are redundantly transferred from DRAM $BLOCKS\_M$ times. Since off-chip DRAM bandwidth is a major bottleneck on MX-Gemmini, this redundancy introduces significant execution latency.

### Optimization Plan: Loop Reordering and Restructuring
We will swap the loop nesting order so that the `j0` loop becomes the outer loop and the `i0` loop becomes the inner loop. 

By making `j0` the outer loop:
1. **Scale Factor Reuse:** We only copy and load the weight scale factors (`B_scales_col` to `B_s` and `gemmini_mx_load_scales` with `sel=1`) once per `j0` iteration, instead of $BLOCKS\_M \times BLOCKS\_N$ times.
2. **Scratchpad Tile Reuse:** We load the B matrix tiles into the scratchpad (`b_base`) once per `j0` iteration. Since the B tiles remain resident at the top of the scratchpad, we reuse them across all iterations of the inner `i0` loop.
3. **Inner Loop Reduction:** Inside the inner `i0` loop, we only need to load the A scale factors, load the A tiles, configure the output, compute, and read back the results.

### Optimized Code

```c
void solution(void) {
  // Hoist invariant configuration outside all loops
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

  int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
  uint32_t a_base = 0;
  uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
  int SPAD_DEST = 128;

  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

    // B scales depend on j0: copy and load once per j0
    for (int g = 0; g < MATMUL_K / 32; g++)
      memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);

    gemmini_flush(0);
    gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

    // MVIN B: load B tiles once per j0 and cache them in the high scratchpad region
    gemmini_config_ld(MATMUL_N * sizeof(elem_t));
    for (int j = 0; j < tiles; j++) {
      for (int k = 0; k < tiles_K; k++) {
        gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                              b_base + (k * tiles + j) * DIM, DIM, DIM);
      }
    }

    for (int i0 = 0; i0 < BLOCKS_M; i0++) {
      int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;

      // A scales only depend on i0: copy and load inside the inner loop
      for (int g = 0; g < MATMUL_K / 32; g++)
        memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);

      gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);

      // MVIN A: load A tiles into the low scratchpad region
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);

      // Compute weight-stationary tiled matmul using the cached B tiles and newly loaded A tiles
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
```
