**Key insight**: `gemmini_mx_read_smem` with `num_bf16 = mrows * ncols` reads `mrows * ncols` contiguous BF16 values from smem into a **contiguous** DRAM region. The smem is indeed contiguous (row stride = `BLK`, total = `mrows * BLK` words with padding). We can read the entire `mrows * BLK` smem block into a **temporary contiguous staging buffer**, then do a single strided copy to `C_hw` — but that reintroduces CPU work.
