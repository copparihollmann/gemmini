An elegant and highly effective way to optimize this kernel is to target the **CPU/host data staging overhead** and **DMA instruction count** (applying strategy 2: "Other methods not listed here"). 

### Optimization Plan:
1. **Hoist Scale Staging Outside Execution Loops**: In the baseline code, `A_scales_row` and `B_scales_col` are staged via `memcpy` *inside* the nested `i0` and `j0` loops. Since `A_scales_row` only depends on `i0` and `B_scales_col` only depends on `j0`, we can pre-stage all scale factors at the very beginning of `solution()`. This reduces the scale factor `memcpy` invocations by **16×**, moving almost all host overhead out of the execution loop.
2. **Optimize Scratchpad MVIN with Block Loading**:
   - For **A**: The baseline loads single `DIM`×`DIM` tiles in a loop. Since both DRAM and scratchpad are contiguous along the `K` dimension, we can load 4 tiles (`MAX_BLOCK_LEN = 4`) in a single `gemmini_extended_mvin` command by setting `cols = 4 * DIM`. This reduces the number of MVIN instructions for `A_in` by **4×**.
   - For **B**: Similarly, by transposing the inner loop order of B loading, we can load the entire row of 4 B-tiles (width = `tiles * DIM`) contiguously in a single `mvin` command. This reduces the B MVIN instructions by **4×**.

### Optimized Code:

```c
// AUTO-GENERATED outer-tiled MX matmul baseline (1x1024x1024) - Optimized Phase 3
void solution(void) {
  // Define unique scale factor staging buffers for each block to avoid write-after-read races
  // when gemmini_fence() is deferred to the end of the full batch.
  static uint8_t A_s_pool[BLOCKS_M][MATMUL_K / 32][BLK];
  static uint8_t B_s_pool[BLOCKS_N][MATMUL_K / 32][BLK];

  // Pre-stage A scales (independent of j0, hoisted out of execution loops)
  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      memcpy(&A_s_pool[i0][g][0], &A_scales_row[g][i0 * BLK], BLK);
    }
  }

  // Pre-stage B scales (independent of i0, hoisted out of execution loops)
  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      memcpy(&B_s_pool[j0][g][0], &B_scales_col[g][j0 * BLK], BLK);
    }
  }

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last M/N block: compute only the real rows/cols, pad the rest.
      int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      gemmini_flush(0);
      gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
      gemmini_mx_load_scales((uint64_t)A_s_pool[i0], A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)B_s_pool[j0], B_S_BYTES, 1);

      gemmini_config_ld(MATMUL_K * sizeof(elem_t));      // A rows: stride K (full block-aligned tiles)
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k += 4) {
          // Block load up to 4 consecutive K-tiles at once
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, 4 * DIM, DIM);
        }
      }

      gemmini_config_ld(MATMUL_N * sizeof(elem_t));      // B rows: stride N
      for (int k = 0; k < tiles_K; k++) {
        // Block load 4 contiguous columns of B at once to fully optimize B layout loading
        gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK)),
                              b_base + (k * tiles) * DIM, tiles * DIM, DIM);
      }

      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Accelerator-centric readout: per-row hardware DMA from smem straight into the
      // bf16-packed row-major output (block-internal smem row stride is BLK).
      for (int r = 0; r < mrows; r++)
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
    }
  }

  // Defer synchronization to after the entire batch has been successfully queued.
  gemmini_fence();
}
```
