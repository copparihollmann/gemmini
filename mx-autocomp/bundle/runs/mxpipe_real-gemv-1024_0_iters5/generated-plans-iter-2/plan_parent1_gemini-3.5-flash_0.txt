### Optimization Plan

We will apply **Strategy 6: Interleaving A and B MVIN Instructions** to optimize the memory-loading phase of the tiled matrix multiplication.

#### Inefficiency Analysis
In the baseline implementation, all tiles of matrix $A$ are loaded sequentially into the scratchpad via `gemmini_extended_mvin`, followed by all tiles of matrix $B$. This sequential load pattern creates long-duration traffic on a subset of scratchpad banks, leaving other bank access paths idle and leading to memory-subsystem bottlenecks. 

#### Optimization Strategy
1. **Dual Stride Configuration**: Instead of sequentially re-configuring the load stride for $A$ and then $B$ using `gemmini_config_ld`, we will configure both load channels simultaneously. Gemmini supports independent load address configurations via the `id` parameter in `gemmini_extended3_config_ld` (where `id = 0` corresponds to `mvin` for $A$, and `id = 1` corresponds to `mvin2` for $B$).
2. **Interleaved MVIN Loop**: We will merge the nested loops for loading $A$ and $B$. We will iterate through the reduction dimension $K$ and tile index `step` (which acts as $I$ for $A$ and $J$ for $B$), issuing interleaved `gemmini_extended_mvin` (for $A$) and `gemmini_extended_mvin2` (for $B$) calls. 
3. **Hardware Sequence Compliance**: We will strictly maintain the programming model sequence: `config_ex` $\rightarrow$ `load_scales` $\rightarrow$ configure strides 0 & 1 $\rightarrow$ interleaved `mvin`/`mvin2` $\rightarrow$ `config_st` / `config_mvout` $\rightarrow$ `loop_ws_spad` $\rightarrow$ `read_smem` $\rightarrow$ `fence`.

// AUTO-GENERATED outer-tiled MX matmul baseline (1x1024x1024).
void solution(void) {
  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last M/N block: compute only the real rows/cols, pad the rest.
      int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;
      
      // Stage only the tiny per-32-group scales; A/B data is mvin'd DIRECTLY
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }
      
      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      gemmini_flush(0);
      
      // 1. Configure execution format and dataflow
      gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
      
      // 2. Load scale factors
      gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);
      
      // 3. Configure distinct load strides for channel 0 (A) and channel 1 (B)
      gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), 1.0, false, 0);
      gemmini_extended3_config_ld(MATMUL_N * sizeof(elem_t), 1.0, false, 1);

      // 4. Load A and B tiles with interleaved MVIN instructions to exploit bank-level concurrency
      for (int k = 0; k < tiles_K; k++) {
        for (int step = 0; step < tiles; step++) {
          // Load A tile (step, k) using mvin (id=0)
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + step * DIM) * MATMUL_K + k * DIM),
                                a_base + (step * tiles_K + k) * DIM, DIM, DIM);
          
          // Load B tile (k, step) using mvin2 (id=1)
          gemmini_extended_mvin2((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + step * DIM)),
                                 b_base + (k * tiles + step) * DIM, DIM, DIM);
        }
      }

      // 5. Configure store and requantizer parameters
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      
      // 6. Fused hardware compute loop
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
      
      // 7. Readout results from shared memory
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
