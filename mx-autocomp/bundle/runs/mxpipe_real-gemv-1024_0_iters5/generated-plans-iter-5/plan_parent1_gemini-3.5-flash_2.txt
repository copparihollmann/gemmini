An elegant and highly effective optimization strategy to reduce execution time is **Hoisting of Activation Scale Factor Loading (Loop-Invariant Code Motion)**.

### Strategy Explanation: Hoisting Activation Scale Loading

In the baseline implementation, the activation scale factors (`A_scales_row`) and weight scale factors (`B_scales_col`) are staged and loaded via `gemmini_mx_load_scales` inside the innermost `j0` loop.

However, the activation scales for matrix A only depend on the row index `i0` and the reduction dimension block `g`. They are completely independent of the column index `j0`. 
By keeping the activation scale loading inside the `j0` loop:
1. The CPU redundantly copies the exact same activation scales `BLOCKS_N` times using `memcpy`.
2. The host processor issues redundant RoCC instructions (`gemmini_mx_load_scales` with `sel=0`) to the coprocessor `BLOCKS_N` times.

Since the Gemmini scale memory (`mx_scale_a_mem`) persists in the hardware state until explicitly overwritten, we can **hoist the staging and loading of the A-side scale factors out of the `j0` loop into the outer `i0` loop**. 

This reduces the total number of activation scale factor loads by a factor of `BLOCKS_N` (e.g., if `BLOCKS_N = 16`, we eliminate 15 out of 16 loads for every row block). This drastically cuts down on both host CPU overhead and RoCC instruction latency. We also hoist `gemmini_extended3_config_ex` to the very top to avoid redundant configurations.

---

### Optimized Code

```c
// AUTO-GENERATED outer-tiled MX matmul baseline (1x1024x1024) - Optimized Phase 5
void solution(void) {
  // Define unique scale factor staging buffers for B to avoid write-after-read races
  static uint8_t B_s_pool[BLOCKS_M][BLOCKS_N][MATMUL_K / 32][BLK];
  // Staging buffer for A scales hoisted to the outer loop level
  static uint8_t A_s_temp[MATMUL_K / 32][BLK];

  // 1. Configure MX FP8 weight-stationary mode once at the beginning
  gemmini_flush(0);
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    // Partial last M block: compute only the real rows, pad the rest.
    int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;

    // 2. Stage and load activation (A) scale factors once per row block i0
    for (int g = 0; g < MATMUL_K / 32; g++) {
      memcpy(&A_s_temp[g][0], &A_scales_row[g][i0 * BLK], BLK);
    }
    gemmini_mx_load_scales((uint64_t)A_s_temp, A_S_BYTES, 0);

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      // 3. Stage and load weight (B) scale factors inside the column block loop j0
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&B_s_pool[i0][j0][g][0], &B_scales_col[g][j0 * BLK], BLK);
      }
      gemmini_mx_load_scales((uint64_t)B_s_pool[i0][j0], B_S_BYTES, 1);

      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // 4. MVIN A tiles
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      // 5. MVIN B tiles
      gemmini_config_ld(MATMUL_N * sizeof(elem_t));
      for (int j = 0; j < tiles; j++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                                b_base + (k * tiles + j) * DIM, DIM, DIM);
        }
      }

      // 6. Configure requantizer and execute hardware loop
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // 7. Read out results from shared memory
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
    }
  }

  // Defer synchronization to the very end of the batch
  gemmini_fence();
}
```
