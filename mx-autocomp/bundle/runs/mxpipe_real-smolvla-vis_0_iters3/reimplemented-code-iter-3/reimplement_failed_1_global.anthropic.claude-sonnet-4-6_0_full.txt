3. **Scale loading selectors**: `sel=0` for A scales, `sel=1` for B scales — this looks correct in the original.

4. **`gemmini_mxquant_config_mvout` scale_dram**: The `scale_factors` pointer needs to be valid and the layout must match `scale_dram + m*N_blocks + bi`. The current code passes `scale_factors` but it's unclear what that points to.

6. **B spad index in loop_ws_spad**: The `B` parameter should be `b_base + tiles_K * tiles * DIM` = `BANK_NUM * BANK_ROWS` (the end address), which is what's passed. But let me re-examine the B layout formula.

      for (int g = 0; g < MATMUL_K / 32; g++) {

      int tiles_K = MATMUL_K / DIM;

      int pad_j = BLK - ncols;

      gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 0);

    }
}
