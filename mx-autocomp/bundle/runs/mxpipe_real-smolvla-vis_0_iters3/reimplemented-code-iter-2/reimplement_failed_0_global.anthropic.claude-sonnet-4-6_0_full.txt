Looking at the failing code, I need to identify the bugs:

1. **B tile layout is wrong**: The B mvin uses `gemmini_extended_mvin` (port 0/mvin) instead of `gemmini_extended_mvin2` (port 1/mvin2) for B tiles. More critically, the B spad address formula `b_base + (k * tiles + j) * DIM` should be `b_base + (j * tiles_K + k) * DIM` to match the documented layout.

2. **mvin B uses wrong port**: B tiles should use `mvin2` not `mvin` to use the separate DMA port.

3. **gemmini_mx_read_smem offset calculation**: `SPAD_DEST * 16 + r * BLK` — the smem offset is in BF16 words. Each row of a tile-block is `BLK` elements wide. The offset for row `r` within smem should be `SPAD_DEST * 16 + r * BLK` which looks correct if SPAD_DEST*16 gives word offset and r*BLK steps by row. But `num_bf16` should be `ncols` elements which is correct.

4. **scale_factors pointer**: The `gemmini_mxquant_config_mvout` needs the full scale array base — the hardware uses `scale_dram + m*N_blocks + bi` indexing internally. We should pass the base of A scales or a combined scale. Looking at the docs more carefully, `scale_dram` in `gemmini_mxquant_config_mvout` is for output scale factors.

5. **B spad layout**: `b_base + (j * tiles_K + k) * DIM` is the correct formula per the architecture docs.

6. **mvin2 for B**: Must use `gemmini_extended_mvin2` for B tiles.

void solution(void) {
  gemmini_flush(0);
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY,
      1, 1, 0, 0, false, 0, 0, 3, 0);

  int tiles   = BLK / DIM;
  int tiles_K = MATMUL_K / DIM;
  uint32_t a_base   = 0;
  uint32_t b_base   = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
  int      SPAD_DEST = 0;

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    int mrows = REAL_M - i0 * BLK;
    if (mrows > BLK) mrows = BLK;
    if (mrows <= 0)  continue;

    int pad_i = BLK - mrows;

    gemmini_mx_load_scales(
        (uint64_t)(&A_scales_row[0][i0 * BLK]),
        A_S_BYTES, 0);

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int ncols = REAL_N - j0 * BLK;
      if (ncols > BLK) ncols = BLK;
      if (ncols <= 0)  continue;

      int pad_j = BLK - ncols;

      gemmini_mx_load_scales(
          (uint64_t)(&B_scales_col[0][j0 * BLK]),
          B_S_BYTES, 1);

      // ---- MVIN A tiles (mvin port 0) ----
      gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 0);
      for (int i = 0; i < tiles; i++)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin(
            (void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
            a_base + (i * tiles_K + k) * DIM,
            DIM, DIM);

      // ---- MVIN B tiles (mvin2 port 1) ----
      gemmini_extended3_config_ld(MATMUL_N * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 1);
      for (int j = 0; j < tiles; j++)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin2(
            (void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
            b_base + (j * tiles_K + k) * DIM,
            DIM, DIM);

      // ---- Configure requantized mvout ----
      gemmini_extended_config_st(BLK_OUTC * sizeof(out_t), 0, ACC_SCALE_IDENTITY);
      gemmini_mxquant_config_mvout(
          (uint64_t)scale_factors,
          tiles, tiles, tiles_K,
          0, 0, 1);

      // ---- Fused hardware matmul ----
      gemmini_loop_ws_spad(tiles, tiles, tiles_K,
                           pad_i, pad_j, 0,
                           a_base, BANK_NUM * BANK_ROWS, 0, SPAD_DEST,
                           false, false, false, false, false,
                           NO_ACTIVATION, 0, 0, false, 0x38);

      // ---- Drain BF16 results from mx_smem to DRAM ----
      for (int r = 0; r < mrows; r++)
        gemmini_mx_read_smem(
          &C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
          SPAD_DEST * 16 + r * BLK,
          ncols);

      gemmini_fence();
    }
  }
}
