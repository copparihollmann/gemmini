### Inefficiency Analysis
In the baseline kernel, the address calculations for moving A and B tiles from DRAM to the Gemmini scratchpad are performed from scratch in every iteration of the nested loops:
* **For Matrix A:** `((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM` and `a_base + (i * tiles_K + k) * DIM`
* **For Matrix B:** `((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)` and `b_base + (k * tiles + j) * DIM`

These expressions contain several multiplications (`* MATMUL_K`, `* MATMUL_N`, `* tiles`, and `* DIM`) and additions executed on the host CPU. Because Gemmini relies on the host CPU to generate and dispatch RoCC commands, this heavy address-computation overhead stalls the instruction pipeline, keeping the systolic array underutilized and increasing latency. 

---

### Optimization Plan

We will eliminate all multi-dimensional index multiplications inside the loops by maintaining running pointers and scratchpad offsets, transforming them into simple, cheap additions:

1. **Optimize Matrix A Loading (`i` and `k` loops):**
   * Before the `i` loop, calculate the base pointer for the active block of A: `elem_t *a_block_ptr = ((elem_t*)A_in) + (i0 * BLK) * MATMUL_K;`
   * Keep a running scratchpad address variable `sp_addr_a` initialized to `a_base`.
   * For each iteration of `i`, define a running DRAM pointer `a_ptr_k = a_block_ptr`. 
   * In the inner `k` loop, dispatch the `mvin` using `a_ptr_k` and `sp_addr_a`. Then, increment `a_ptr_k` by `DIM` and `sp_addr_a` by `DIM`.
   * At the end of each `i` iteration, increment `a_block_ptr` by `DIM * MATMUL_K` to advance to the next row of tiles.

2. **Optimize Matrix B Loading (`j` and `k` loops):**
   * Before the `j` loop, calculate the base column pointer for the active block of B: `elem_t *b_block_ptr = ((elem_t*)B_in) + (j0 * BLK);`
   * Inside the `j` loop, calculate the start of the current column tile: `elem_t *b_ptr_k = b_block_ptr + j * DIM;`

   * Increment `sp_addr_b` by `tiles * DIM` to target the next corresponding tile slot in the scratchpad.
