### Optimization Plan: Hoist Invariant Scale Factor Loads (Strategy 6)

#### Analysis of Inefficiencies
In the baseline implementation, both the activation row scales (`A_scales_row` copied to `A_s`) and the weight column scales (`B_scales_col` copied to `B_s`) are staged via `memcpy` and loaded into scale memory using `gemmini_mx_load_scales` inside the innermost `j0` loop. 

However:
1. `A_scales_row` is indexed by row blocks `i0` and the group dimension `g`. It has no dependency on the column block `j0`. 
2. Scale-factor memory in the Gemmini hardware is persistent until explicitly overwritten. 
3. Transferring the activation scales on every iteration of the `j0` loop causes redundant DRAM-to-hardware transfers, which is highly inefficient.

#### Optimization Strategy
We will apply **Strategy 6**: **Hoist the loading of invariant scale factors out of the inner loop**.
1. We will move the preparation (the `memcpy` loop for `A_s`) and the scale-factor load (`gemmini_mx_load_scales` for `sel=0`) of activation row scales from the inner `j0` loop into the outer `i0` loop.
2. The config instruction `gemmini_extended3_config_ex` will also be hoisted to the `i0` loop to establish the execution and format parameters prior to loading the scales.
3. Within the inner `j0` loop, we only prepare and load the weight column scales (`B_s` with `sel=1`), which change across column iterations. This significantly reduces redundant host-to-device memory traffic and amortizes the overhead of `gemmini_mx_load_scales`.

---

### Optimized Code

```c
void solution(void) {
  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;

    // 1. Prepare activation scale factors for the row block (invariant to j0)
    for (int g = 0; g < MATMUL_K / 32; g++) {
      memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
    }

    // 2. Configure execution & load invariant A scales once per row block sweep
    gemmini_flush(0);
    gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
    gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      // 3. Prepare weight scale factors for the column block (variant to j0)
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }

      // 4. Load variant B scales
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // 5. Load inputs and compute
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      gemmini_config_ld(MATMUL_N * sizeof(elem_t));
      for (int j = 0; j < tiles; j++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                                b_base + (k * tiles + j) * DIM, DIM, DIM);
        }
      }

      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);

      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      if (mrows == BLK && ncols == BLK) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK][j0 * BLK / BF16_PER_WORD],
                             SPAD_DEST * 16, BLK * BLK);
      } else {
        for (int r = 0; r < mrows; r++) {
          gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                               SPAD_DEST * 16 + r * BLK, ncols);
        }
      }
    }
  }
  gemmini_fence();
}
```
