An elegant and highly effective optimization strategy for this kernel is **Loop Hoisting of Invariant Configurations and Scale Factor Staging**. 

### Analysis of Inefficiencies in the Baseline
1. **Redundant Hardware Reconfiguration:** `gemmini_extended3_config_ex` and `gemmini_config_st` are invoked inside the nested loops over `i0` and `j0`. Since the data formats, strides, and transpose settings are completely invariant across all tiles, these calls introduce unnecessary instruction issue overhead on every single block iteration.
2. **Redundant CPU and DMA Scale Loading:** The baseline stages both activation scales (`A_s`) and weight scales (`B_s`) via `memcpy` and loads them to the accelerator via `gemmini_mx_load_scales` inside the innermost loop `j0`. However, the activation scales (`A_s`) depend solely on the outer row-block index `i0` and are completely invariant to the column-block index `j0`. Re-copying and re-loading `A_s` for every column block `j0` causes massive CPU overhead and redundant DRAM-to-accelerator DMA transfers.

### Optimization Plan
We will hoist the invariant operations to their respective outer levels of the loop hierarchy while strictly maintaining the required programming model sequence:
1. **Hoist Global Configurations:** Move `gemmini_extended3_config_ex` and `gemmini_config_st` completely outside of all loops.
2. **Hoist Activation Scale Factor Loading:** Move the `memcpy` staging of `A_s` and its corresponding dequantization scale load (`gemmini_mx_load_scales` with `sel=0`) out of the inner `j0` loop into the outer `i0` loop. This reduces the number of CPU copies and scale dequantization DMA operations for A by a factor of `BLOCKS_N`.
3. **Preserve Sequence and Correctness:** The execution flow will remain `config_ex` $\rightarrow$ `load_scales` (both A and B) $\rightarrow$ `mvin` $\rightarrow$ `config_mvout` $\rightarrow$ `compute` $\rightarrow$ `read_smem` $\rightarrow$ `fence`, ensuring correct execution on the Spike simulator.

### Optimized C Code

```c
#include <stdint.h>
#include <string.h>
#include "include/gemmini_testutils.h"
#include "include/matmul_data_mx_lut_hw.h"

// AUTO-GENERATED outer-tiled MX matmul optimized solution.
void solution(void) {
  // Hoist invariant global configurations completely outside all loops
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
  gemmini_config_st(BLK_OUTC * sizeof(out_t));

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    // Partial last M block: compute only the real rows, pad the rest.
    int mrows = REAL_M - i0 * BLK; 
    if (mrows > BLK) mrows = BLK; 
    if (mrows <= 0) continue;

    // Hoist row-wise activation scales staging and loading out of the j0 loop
    for (int g = 0; g < MATMUL_K / 32; g++) {
      memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
    }
    gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last N block: compute only the real cols, pad the rest.
      int ncols = REAL_N - j0 * BLK; 
      if (ncols > BLK) ncols = BLK; 
      if (ncols <= 0) continue;

      // Stage and load column-wise weight scales (B) for the current j0 block
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      gemmini_flush(0);

      // MVIN A tiles directly from strided DRAM
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      // MVIN B tiles directly from strided DRAM
      gemmini_config_ld(MATMUL_N * sizeof(elem_t));
      for (int j = 0; j < tiles; j++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                                b_base + (k * tiles + j) * DIM, DIM, DIM);
        }
      }

      // Configure requantizer bounds
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);

      // Fused hardware loop computation
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Readout results from shared memory
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
```
