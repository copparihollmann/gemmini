### Optimization Plan

The chosen strategy is **Strategy 1: Cache reused data in local memory instead of reloading from main memory**.

#### Inefficiency Analysis
In the baseline implementation, the activation matrix $A$ tiles are loaded from DRAM into the scratchpad using `gemmini_extended_mvin` inside the inner loop (`j0` loop). However, because the outer loop iterates over $i0$ (M-blocks) and the inner loop iterates over $j0$ (N-blocks), the activation data for the current block $i0$ is completely invariant with respect to $j0$. 

By reloading $A$ inside the $j0$ loop, the program performs redundant DRAM reads, which introduces severe memory bandwidth bottlenecks and drastically increases execution latency.

#### Optimization Details
1. **Hoist $A$ Tile Loading**: We will move the $A$ matrix `gemmini_config_ld` and the nested loops containing `gemmini_extended_mvin` for $A$ completely outside the inner $j0$ loop.
2. **Scratchpad Layout Safety**: The scratchpad utilizes $a\_base = 0$ for $A$ tiles and $b\_base$ (measured from the top of the scratchpad downward) for $B$ tiles. Hoisting the load of $A$ keeps the activation tiles cached in the scratchpad range $[0, \text{tiles} \times \text{tiles\_K} \times \text{DIM})$ across all iterations of the $j0$ loop. Since $B$ tiles are written to the separate range $[b\_base, 8192)$, they will not overwrite or corrupt the cached $A$ tiles.
3. **Correctness & Constraints**: All scale loading sequences and hardware compute parameters remain valid and strictly adhere to the required execution sequence.

### Optimized Code

```c
#include <stdint.h>
#include <string.h>
#include "include/gemmini_testutils.h"
#include "include/matmul_data_mx_lut_hw.h"

// AUTO-GENERATED outer-tiled MX matmul optimized solution.
void solution(void) {
  // Hoist invariant global configurations completely outside all loops
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    // Partial last M block: compute only the real rows, pad the rest.
    int mrows = REAL_M - i0 * BLK; 
    if (mrows > BLK) mrows = BLK; 
    if (mrows <= 0) continue;

    // Hoist row-wise activation scales staging and loading out of the j0 loop
    for (int g = 0; g < MATMUL_K / 32; g++) {
      memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
    }
    gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);

    int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
    uint32_t a_base = 0;

    // MVIN A tiles directly from strided DRAM - Hoisted out of the j0 loop
    // This caches activation tiles in the scratchpad for all N-blocks
    gemmini_config_ld(MATMUL_K * sizeof(elem_t));
    for (int i = 0; i < tiles; i++) {
      for (int k = 0; k < tiles_K; k++) {
        gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                              a_base + (i * tiles_K + k) * DIM, DIM, DIM);
      }
    }

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last N block: compute only the real cols, pad the rest.
      int ncols = REAL_N - j0 * BLK; 
      if (ncols > BLK) ncols = BLK; 
      if (ncols <= 0) continue;

      // Stage and load column-wise weight scales (B) for the current j0 block
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      gemmini_flush(0);

      // MVIN B tiles directly from strided DRAM
      gemmini_config_ld(MATMUL_N * sizeof(elem_t));
      for (int j = 0; j < tiles; j++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                                b_base + (k * tiles + j) * DIM, DIM, DIM);
        }
      }

      // Configure output store stride (this was incorrectly hoisted in the proposed optimization)
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      
      // Configure requantizer bounds with correct parameters
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);

      // Fused hardware loop computation
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Readout results from shared memory
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
```
