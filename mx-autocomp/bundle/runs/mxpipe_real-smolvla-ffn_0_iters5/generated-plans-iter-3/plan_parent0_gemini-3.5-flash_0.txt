### Method Explanation: Caching Reused Data in Local Memory (Strategy 3)

The original code suffers from severe data movement inefficiencies: for every column block of $B$, the entire matrix $A$ is re-read from DRAM and re-packed. Since $A$ ($50 \times 512$ bytes) is small enough to fit completely in the $128\text{ KB}$ scratchpad ($2048$ rows out of $8192$), we can cache it in the scratchpad once at the beginning of the function and reuse it across all compute steps. 

To achieve this:
1. **Cache Matrix $A$**: We load the entire $A$ matrix ($64 \times 512$ padded) into the scratchpad at `a_base = 0` (occupying rows $0$ to $2048$) at the very beginning of `solution()`.
2. **Optimize Scale Loading**: Because we process the entire $M$ dimension at once, we completely bypass host-side `memcpy` re-packing for $A$'s scale factors. We stream the entire contiguous `A_scales_row` buffer into the activation scale memory in one single DMA command.
3. **Double-Buffered Scratchpad Layout**: We split $B$ into column blocks of size $64$. Each block of $B$ occupies rows $6144$ to $8192$ (at `b_base = 6144`), which avoids any overlap with the cached $A$ matrix (rows $0$ to $2048$).
4. **Enforce Accumulator Constraints**: In accordance with **Rule 13**, the total rows of $C$ in the accumulator must satisfy $\text{tiles}_I \times \text{tiles}_J \times \text{DIM} \le 256$. With $\text{tiles}_I = 4$ and $\text{DIM} = 16$, the maximum allowable column block size is $64$ ($\text{tiles}_J = 4$), which yields exactly $4 \times 4 \times 16 = 256$ accumulator rows.

### Optimized Code

```c
#include <stdint.h>
#include <string.h>
#include "include/gemmini_testutils.h"

// Define compile-time constants for shape & parameters
#define REAL_M 50
#define REAL_N 256
#define MATMUL_K 512

#define MATMUL_M 64  // Padded to multiple of DIM
#define MATMUL_N 256

#define DIM 16
#define BF16_PER_WORD 4
#define OUT_COLS (MATMUL_N / BF16_PER_WORD)

typedef uint8_t  elem_t;
typedef uint64_t out_t;

// Optimized solution implementing Strategy 3
void solution(void) {
  // 1. Flush and configure GEMMINI for WS FP8/BF16 mode
  gemmini_flush(0);
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 
                              1, 1, 0, 0, false, 
                              0, 0, 3, 0); // FP8 act/wgt, BF16 out, uselut=0

  // 2. Load the entire activation scale-factor buffer once
  gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);

  // 3. Cache the entire A matrix into the scratchpad
  uint32_t a_base = 0;
  int tiles_I = MATMUL_M / DIM;  // 4 tiles
  int tiles_K = MATMUL_K / DIM;  // 32 tiles

  gemmini_config_ld(MATMUL_K * sizeof(elem_t));
  for (int i = 0; i < tiles_I; i++) {
    for (int k = 0; k < tiles_K; k++) {
      elem_t *dram_ptr = ((elem_t*)A_in) + (i * DIM) * MATMUL_K + k * DIM;
      uint32_t sp_addr = a_base + (i * tiles_K + k) * DIM;
      gemmini_extended_mvin((void*)dram_ptr, sp_addr, DIM, DIM);
    }
  }

  // 4. Stream B blocks of size N = 64 (satisfying accumulator limits)
  int BLK_N = 64;
  int tiles_J_block = BLK_N / DIM; // 4 tiles
  uint32_t b_base = BANK_NUM * BANK_ROWS - tiles_K * tiles_J_block * DIM; // 8192 - 32 * 4 * 16 = 6144
  int SPAD_DEST = 128;

  static uint8_t B_scales_block[16 * 64]; // 16 scale groups along K, 64 columns
  uint32_t scale_factors[512] __attribute__((aligned(32))) = {0};

  gemmini_config_st((BLK_N / BF16_PER_WORD) * sizeof(out_t));

  for (int j0 = 0; j0 < MATMUL_N / BLK_N; j0++) {
    // Pack B scales for current block
    for (int g = 0; g < 16; g++) {
      memcpy(&B_scales_block[g * 64], &B_scales_col[g][j0 * 64], 64);
    }

    // Load packed scales for the current block of B
    gemmini_mx_load_scales((uint64_t)B_scales_block, sizeof(B_scales_block), 1);

    // Stream the current block of B into scratchpad
    gemmini_config_ld(MATMUL_N * sizeof(elem_t));
    for (int j = 0; j < tiles_J_block; j++) {
      for (int k = 0; k < tiles_K; k++) {
        elem_t *dram_ptr = ((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK_N + j * DIM);
        uint32_t sp_addr = b_base + (j * tiles_K + k) * DIM;
        gemmini_extended_mvin((void*)dram_ptr, sp_addr, DIM, DIM);
      }
    }

    // Requantizer configuration
    gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J_block, tiles_K, 0, 0, 1);

    // Issue the one-shot scratchpad base marker
    ROCC_INSTRUCTION_RS1_RS2(XCUSTOM_ACC, a_base, BANK_NUM * BANK_ROWS, k_LOOP_WS_CONFIG_SPAD_AB);

    // Compute via weight-stationary systolic loop
    // pad_i = 14 (since REAL_M = 50, MATMUL_M = 64), pad_j = 0, pad_k = 0
    gemmini_loop_ws_spad(tiles_I, tiles_J_block, tiles_K, 
                         14, 0, 0, 
                         a_base, BANK_NUM * BANK_ROWS, 0, 
                         SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

    // Drain BF16-packed results directly from Shared Memory (SMEM) to destination DRAM
    for (int r = 0; r < REAL_M; r++) {
      gemmini_mx_read_smem(&C_hw[r][(j0 * BLK_N) / BF16_PER_WORD],
                           SPAD_DEST * 16 + r * BLK_N, BLK_N);
    }
    gemmini_fence();
  }
}
```
