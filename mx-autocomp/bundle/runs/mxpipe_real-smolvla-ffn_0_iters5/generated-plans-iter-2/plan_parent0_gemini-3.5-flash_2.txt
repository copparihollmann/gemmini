### Optimization Plan

To optimize the execution time and reduce the latency of the provided MX-Gemmini kernel, we will apply **Strategy 1: simplify or remove unnecessary code**. 

Our analysis of the baseline code reveals three main inefficiencies that can be resolved:
1. **Redundant Loading of Activation (A) Tiles**: In the original code, the matrix A tiles are loaded inside the innermost loop `j0`. However, the values of the A tiles depend only on the outer loop index `i0` (since they represent the row block of activations). We can hoist the `gemmini_config_ld` and the nested loops that execute the `gemmini_extended_mvin` of A completely out of the `j0` loop and place them in the `i0` loop. Since the Gemmini scratchpad is stateful and has more than enough space to hold both A and B tiles concurrently without overlapping (`a_base` starts at `0`, and `b_base` is at the top of the scratchpad), A tiles can be loaded once and safely reused across all iterations of the `j0` loop.
2. **Redundant Storing Configuration**: The store stride configuration `gemmini_config_st(BLK_OUTC * sizeof(out_t))` is called during every single iteration of the `j0` loop. Because this stride is invariant, we can hoist it completely outside of all loops right next to `gemmini_extended3_config_ex`.
3. **Pipeline Stalls from Flushes**: The baseline code calls `gemmini_flush(0)` on every iteration of the inner loop, which forces the host to wait for the pipeline to drain completely. Since we manage scratchpad addresses explicitly and avoid overlapping A and B, this flush is redundant and can be removed.

#include <stdint.h>
#include <string.h>
#include "include/gemmini_testutils.h"
#include "include/matmul_data_mx_lut_hw.h"

// AUTO-GENERATED outer-tiled MX matmul optimized solution.
void solution(void) {
  // Hoist invariant global configurations completely outside all loops
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
  gemmini_config_st(BLK_OUTC * sizeof(out_t));

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    // Partial last M block: compute only the real rows, pad the rest.
    int mrows = REAL_M - i0 * BLK; 
    if (mrows > BLK) mrows = BLK; 
    if (mrows <= 0) continue;

    // Stage and load row-wise activation scales (A) for the current i0 block
    for (int g = 0; g < MATMUL_K / 32; g++) {
      memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
    }
    gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);

    int tiles = BLK / DIM;
    int tiles_K = MATMUL_K / DIM;
    uint32_t a_base = 0;

    // MVIN A tiles directly from strided DRAM (hoisted out of the j0 loop)
    gemmini_config_ld(MATMUL_K * sizeof(elem_t));
    for (int i = 0; i < tiles; i++) {
      for (int k = 0; k < tiles_K; k++) {
        gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                              a_base + (i * tiles_K + k) * DIM, DIM, DIM);
      }
    }

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last N block: compute only the real cols, pad the rest.
      int ncols = REAL_N - j0 * BLK; 
      if (ncols > BLK) ncols = BLK; 
      if (ncols <= 0) continue;

      // Stage and load column-wise weight scales (B) for the current j0 block
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // MVIN B tiles directly from strided DRAM
      gemmini_config_ld(MATMUL_N * sizeof(elem_t));
      for (int j = 0; j < tiles; j++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                                b_base + (k * tiles + j) * DIM, DIM, DIM);
        }
      }

      // Configure requantizer bounds with correct parameters
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);

      // Fused hardware loop computation
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Readout results from shared memory
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
