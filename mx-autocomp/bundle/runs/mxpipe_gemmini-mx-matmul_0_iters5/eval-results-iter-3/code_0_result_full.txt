**The key insight:** The hardware provides **three independent mvin ports**: `gemmini_extended_mvin` (port 0, for A), `gemmini_extended_mvin2` (port 1, for B), and `gemmini_extended_mvin3` (port 2, for D/bias). Currently the code uses only `gemmini_block_mvin` (port 0) for both A and B, requiring a `gemmini_config_ld` reconfiguration between them. **Specific change:**

1. Configure port 0 (id=0) with A's stride: `gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), SCALE_IDENTITY, false, 0)`
2. Configure port 1 (id=1) with B's stride: `gemmini_extended3_config_ld(MATMUL_N * sizeof(elem_t), SCALE_IDENTITY, false, 1)`
