### Optimization Plan

1. **Loop Restructuring (Phase Separation)**:
   Instead of alternating between the $S1$ computation (Part 1) and $O$ computation (Part 3) within each head iteration, we restructure the program into three distinct phases:
   - **Phase 1**: Compute $S1 = Q \times K^T$ for all heads $h \in [0, H-1]$.
   - **Phase 2**: Perform the float-free integer Softmax on the host CPU for all heads.
   - **Phase 3**: Compute $O = P \times V$ for all heads $h \in [0, H-1]$.

2. **GQA Scale and Weight Reuse (Strategies 1 & 7)**:
   By grouping all $S1$ computations together (Phase 1) and all $O$ computations together (Phase 3), the key $K^T$ and value $V$ matrices (and their respective scales) remain invariant for consecutive Query heads that share the same Key-Value head ($kv$).

3. **Double-Buffered Scale Lookahead**:
