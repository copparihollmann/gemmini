An elegant and highly effective optimization plan to improve the execution time of the matrix multiplication kernel is to apply **Strategy 1: Offline pre-transposition of B matrix**.

### Inefficiency Analysis
In the original code, the B matrix is loaded from DRAM using a stride of `MATMUL_N` (256 bytes) along its K-reduction dimension. Because the reduction loop iterates over `k` (the vertical dimension of B), consecutive rows of B are separated by `MATMUL_N` bytes in DRAM. This strided layout prevents the DMA engine from executing contiguous burst reads, severely bottlenecking data-movement bandwidth.

### Optimization Plan
To eliminate this stride bottleneck and maximize DMA load throughput:
1. **Host-Side Pre-transposition**: We will allocate a static buffer `B_transposed` of shape `MATMUL_N` x `MATMUL_K` and perform a one-time transposition of the B matrix on the host CPU prior to entering the main computation loops.
2. **Contiguous DRAM Layout**: In `B_transposed`, the K-reduction dimension becomes the contiguous inner dimension (stride of 1). When we load a tile from `B_transposed`, we will stream fully contiguous elements from DRAM.
3. **Hardware-Assisted Transposed Compute**:
   - We configure `gemmini_extended3_config_ex` with `B_transpose = 1` so that the weight-stationary systolic array knows B's layout in the scratchpad is transposed.
   - We update the scratchpad mapping of B tiles to use the transposed layout: `b_base + (j * tiles_K + k) * DIM`.
   - We set the `B_transpose` parameter to `true` in `gemmini_loop_ws_spad`.

This change keeps the compute and memory synchronization identical, but accelerates the DMA loads of B to use high-bandwidth contiguous burst-reads.

### Optimized Code

```c
// AUTO-GENERATED outer-tiled MX matmul baseline (256x256x512).
void solution(void) {
  // Pre-format scale factor matrices to eliminate CPU-side staging in the hot loop
  static uint8_t A_scales_perf[BLOCKS_M][MATMUL_K / 32][BLK];
  static uint8_t B_scales_perf[BLOCKS_N][MATMUL_K / 32][BLK];

  // Offline pre-transposition of B matrix
  static elem_t B_transposed[MATMUL_N][MATMUL_K];
  for (int k = 0; k < MATMUL_K; k++) {
    for (int j = 0; j < MATMUL_N; j++) {
      B_transposed[j][k] = ((elem_t*)B_in)[k * MATMUL_N + j];
    }
  }

  // One-time pre-formatting before main loops start
  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      int mrows = REAL_M - i0 * BLK;
      if (mrows > BLK) mrows = BLK;
      if (mrows <= 0) continue;
      
      // Only copy actual data, handle partial blocks correctly
      for (int i = 0; i < mrows; i++) {
        A_scales_perf[i0][g][i] = A_scales_row[g][i0 * BLK + i];
      }
      // Pad with zeros for partial blocks if needed
      for (int i = mrows; i < BLK; i++) {
        A_scales_perf[i0][g][i] = 0;
      }
    }
  }

  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      int ncols = REAL_N - j0 * BLK;
      if (ncols > BLK) ncols = BLK;
      if (ncols <= 0) continue;
      
      // Only copy actual data, handle partial blocks correctly
      for (int j = 0; j < ncols; j++) {
        B_scales_perf[j0][g][j] = B_scales_col[g][j0 * BLK + j];
      }
      // Pad with zeros for partial blocks if needed
      for (int j = ncols; j < BLK; j++) {
        B_scales_perf[j0][g][j] = 0;
      }
    }
  }

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    int mrows = REAL_M - i0 * BLK; 
    if (mrows > BLK) mrows = BLK; 
    if (mrows <= 0) continue;

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last M/N block: compute only the real rows/cols, pad the rest.
      int ncols = REAL_N - j0 * BLK; 
      if (ncols > BLK) ncols = BLK; 
      if (ncols <= 0) continue;

      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // PROF accel
      gemmini_flush(0);
      gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 1, false, 0, 0, 3, 0);

      // Direct DMA stream from pre-formatted scale matrices in DRAM
      gemmini_mx_load_scales((uint64_t)&A_scales_perf[i0][0][0], A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)&B_scales_perf[j0][0][0], B_S_BYTES, 1);

      gemmini_config_ld(MATMUL_K * sizeof(elem_t));      // A rows: stride K (full block-aligned tiles)
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      gemmini_config_ld(MATMUL_K * sizeof(elem_t));      // B_transposed rows: stride K (fully contiguous in DRAM!)
      for (int j = 0; j < tiles; j++) {                  
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin((void*)(((elem_t*)B_transposed) + (j0 * BLK + j * DIM) * MATMUL_K + k * DIM),
                                b_base + (j * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, true, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Accelerator-centric readout: per-row hardware DMA from smem straight into the
      // bf16-packed row-major output (block-internal smem row stride is BLK).
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
```
