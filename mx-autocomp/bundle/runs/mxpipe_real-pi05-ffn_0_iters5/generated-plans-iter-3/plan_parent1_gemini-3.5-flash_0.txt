An elegant and highly effective optimization strategy to reduce execution latency is **Scratchpad-Resident Input Hoisting and Scale Factor Amortization**.

### Explanation of the Strategy

In the baseline implementation, the inner loop over column blocks (`j0`) reloads the row block of matrix `A` (`A_in`) and its corresponding row scale factors (`A_scales_row`) on every single iteration. 

Since `A` is completely independent of the column dimension index `j0`, we can optimize this by performing the following steps:
1. **Hoist Scale Factor Loading**: We copy `A_s` from `A_scales_row` and call `gemmini_mx_load_scales` for the row scales **once** in the outer loop (`i0`), rather than repeatedly inside the `j0` loop.
2. **Hoist Scratchpad Loading of Matrix A**: We load the tiles of `A_in` into the lower part of the scratchpad (`a_base`) only once in the outer `i0` loop. Since the systolic array does not modify scratchpad inputs during weight-stationary execution, `A` remains perfectly preserved across all iterations of the `j0` loop.
3. **No Overlap Risk**: The total capacity of the Gemmini scratchpad is 8192 rows. At `BLK = 64`, matrix `A` occupies only `tiles_I * tiles_K * DIM = 4 * 32 * 16 = 2048` rows, and matrix `B` occupies another 2048 rows at the top of the scratchpad. This leaves ample safety margin, meaning both operands can reside on-chip simultaneously without any risk of memory overlap or thrashing.

By applying this strategy, we eliminate `(BLOCKS_N - 1) * BLOCKS_M` redundant DRAM transfers of matrix `A` and `(BLOCKS_N - 1) * BLOCKS_M` redundant host-side copy/load steps for row scale factors, yielding a massive performance speedup.

### Rewritten Optimized Code

```c
#include <stdint.h>
#include <string.h>
#include "include/gemmini_testutils.h"

// Assuming external symbols are defined elsewhere as in the baseline:
// BLK, REAL_M, REAL_N, MATMUL_K, DIM, BANK_NUM, BANK_ROWS, BF16_PER_WORD, BLK_OUTC
// elem_t, out_t, A_s, B_s, A_scales_row, B_scales_col, A_in, B_in, C_hw, scale_factors

void solution(void) {
  // Hoist invariant Gemmini configuration outside of all loops to prevent redundant command dispatch
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    // Partial last M block: compute only the real rows, pad the rest.
    int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;

    int tiles = BLK / DIM;
    int tiles_K = MATMUL_K / DIM;
    uint32_t a_base = 0;
    uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
    int SPAD_DEST = 128;

    // PROF cpu_stage
    // Stage activation scale factors once per row block (hoisted from inner loop)
    for (int g = 0; g < MATMUL_K / 32; g++) {
      memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
    }
    
    // Load activation scale factors to Gemmini hardware scale memory (hoisted from inner loop)
    gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);

    // Load A tiles into the scratchpad once per row block (hoisted from inner loop)
    gemmini_config_ld(MATMUL_K * sizeof(elem_t)); // A rows: stride K (full block-aligned tiles)
    for (int i = 0; i < tiles; i++) {
      for (int k = 0; k < tiles_K; k++) {
        gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                              a_base + (i * tiles_K + k) * DIM, DIM, DIM);
      }
    }

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last N block: compute only the real cols, pad the rest.
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;

      // Stage weight scale factors for the current column block
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }

      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // PROF accel
      gemmini_flush(0);
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      gemmini_config_ld(MATMUL_N * sizeof(elem_t));      // B rows: stride N
      for (int j = 0; j < tiles; j++)                    // B[k][j0*BLK+j] -> slot (k*tiles + j)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                                b_base + (k * tiles + j) * DIM, DIM, DIM);

      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Accelerator-centric readout: per-row hardware DMA from smem straight into the
      // bf16-packed row-major output (block-internal smem row stride is BLK).
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
```
