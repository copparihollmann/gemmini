An elegant and highly effective optimization strategy that is different from the listed strategies is **Stationary Operand Caching via Loop-Interchange Scratchpad Reuse**.

### How the Strategy Works

In the baseline implementation, the outer loops iterate over $I$ (using `i0` for M-tiles) and then $J$ (using `j0` for N-tiles). Within the innermost loop, both the activation tiles ($A$) and weight tiles ($B$) are streamed from off-chip DRAM into the scratchpad. This means both $A$ and $B$ are loaded $BLOCKS\_M \times BLOCKS\_N$ times.

However, the $A$ tiles and $A$ scale factors only depend on `i0` (the row block index) and $K$ (which is fully reduced inside the hardware loop). Since the Gemmini scratchpad is 256KB, we can fit a complete block of $A$ (32KB for a $64 \times 512$ block) and $B$ simultaneously without any memory address overlap:
* $A$ tiles occupy rows `0` to `2047` (`a_base = 0`).
* $B$ tiles occupy rows `6144` to `8191` (`b_base = 6144`).

By hoisting the loading of $A$ tiles (`gemmini_extended_mvin` for $A$) and $A$ scale factors (`gemmini_mx_load_scales` with `sel=0`) out of the inner `j0` loop and placing them directly in the outer `i0` loop, we keep the $A$ operands stationary in the scratchpad. 

### Why This Improves Performance

1. **DRAM Transfer Volume Reduction:** The $A$ matrix blocks are transferred from DRAM to the scratchpad only $BLOCKS\_M$ times instead of $BLOCKS\_M \times BLOCKS\_N$ times. For a $4 \times 4$ block grid, this yields a **4× reduction in the DRAM bandwidth** required for activations.
2. **Scale Load Overhead Elimination:** Similarly, the activation scale factors are loaded only $BLOCKS\_M$ times, bypassing redundant DRAM accesses.
3. **Temporal Instruction Sequence Compliance:** The execution order for any matmul path remains fully compliant with the hardware programming model: `gemmini_extended3_config_ex` is run first, followed by scale loads, tile loads, quantization config, computation, and readout.

// AUTO-GENERATED outer-tiled MX matmul optimized via Stationary Operand Caching.
void solution(void) {
  // Pre-format scale factor matrices to eliminate CPU-side staging in the hot loop
  static uint8_t A_scales_perf[BLOCKS_M][MATMUL_K / 32][BLK];
  static uint8_t B_scales_perf[BLOCKS_N][MATMUL_K / 32][BLK];

  // One-time pre-formatting before main loops start
  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      int mrows = REAL_M - i0 * BLK;
      if (mrows > BLK) mrows = BLK;
      if (mrows <= 0) continue;
      
      // Only copy actual data, handle partial blocks correctly
      for (int i = 0; i < mrows; i++) {
        A_scales_perf[i0][g][i] = A_scales_row[g][i0 * BLK + i];
      }
      // Pad with zeros for partial blocks if needed
      for (int i = mrows; i < BLK; i++) {
        A_scales_perf[i0][g][i] = 0;
      }
    }
  }

  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      int ncols = REAL_N - j0 * BLK;
      if (ncols > BLK) ncols = BLK;
      if (ncols <= 0) continue;
      
      // Only copy actual data, handle partial blocks correctly
      for (int j = 0; j < ncols; j++) {
        B_scales_perf[j0][g][j] = B_scales_col[g][j0 * BLK + j];
      }
      // Pad with zeros for partial blocks if needed
      for (int j = ncols; j < BLK; j++) {
        B_scales_perf[j0][g][j] = 0;
      }
    }
  }

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    int mrows = REAL_M - i0 * BLK; 
    if (mrows > BLK) mrows = BLK; 
    if (mrows <= 0) continue;

    int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
    uint32_t a_base = 0;

    // Configure execution once per row block
    gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

    // Load stationary A scale factors once per row block
    gemmini_mx_load_scales((uint64_t)&A_scales_perf[i0][0][0], A_S_BYTES, 0);

    // Keep A tiles stationary in the lower half of the scratchpad
    gemmini_config_ld(MATMUL_K * sizeof(elem_t)); // A rows: stride K
    for (int i = 0; i < tiles; i++) {
      for (int k = 0; k < tiles_K; k += 2) {
        gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                              a_base + (i * tiles_K + k) * DIM, 2 * DIM, DIM);
      }
    }

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int ncols = REAL_N - j0 * BLK; 
      if (ncols > BLK) ncols = BLK; 
      if (ncols <= 0) continue;

      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // Flush to synchronize state
      gemmini_flush(0);

      // Load dynamic B scale factors
      gemmini_mx_load_scales((uint64_t)&B_scales_perf[j0][0][0], B_S_BYTES, 1);

      // Load dynamic B tiles into the upper half of the scratchpad
      gemmini_config_ld(MATMUL_N * sizeof(elem_t)); // B rows: stride N
      for (int k = 0; k < tiles_K; k++) {
        for (int j = 0; j < tiles; j += 2) {
          gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                                b_base + (k * tiles + j) * DIM, 2 * DIM, DIM);
        }
      }

      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      
      // Perform computation utilizing the stationary A tiles and new B tiles
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Drain results to DRAM
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
