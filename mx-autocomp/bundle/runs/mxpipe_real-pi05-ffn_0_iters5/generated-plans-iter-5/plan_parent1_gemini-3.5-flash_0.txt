An elegant and highly effective optimization plan to improve the execution time of the matrix multiplication kernel on the MX-Gemmini target.

### Optimization Plan

Our goal is to maximize data movement efficiency, eliminate redundant instructions, and leverage the hardware's concurrent DMA ports. We will implement the following optimizations under **Strategy 1 ("Other methods not listed here")**:

1. **Maximize MVIN Batching (4-Tile Block Loads)**:
   The baseline code batches 2 tiles at a time (`cols = 2 * DIM`). Since `MAX_BLOCK_LEN = 4`, the hardware supports loading up to 4 contiguous tiles along the row direction in a single `mvin` command. We will increase the block size parameter `cols` to `4 * DIM` (64 bytes) and adjust the loops to step by `4`.
   * For **A**: Batch 4 tiles along the $K$ dimension (`k += 4`). This cuts the number of A-loading MVIN instructions in half (from 64 to 32).
   * For **B**: Batch 4 tiles along the $N$ (or $J$) dimension. Since `tiles = 4`, we can load all 4 columns for a given row in a single instruction (`cols = 4 * DIM`), entirely eliminating the inner loop over `j` and cutting B-loading MVINs in half (from 64 to 32).

2. **Parallelize DMA Streams via `mvin2`**:
   The hardware features independent DMA engines for A and B. Instead of loading both operands through the same default port (`gemmini_extended_mvin`), we will route Matrix B's loads through `gemmini_extended_mvin2`. This allows the accelerator to overlap and pipeline the loading of A and B operands.

3. **Hoist A-Scale Loads and Reconfiguration**:
   * The A-matrix scale factors (`A_scales_perf[i0]`) depend solely on the outer loop index `i0`. Currently, they are redundantly reloaded `BLOCKS_N` times inside the `j0` loop. We will hoist `gemmini_mx_load_scales` for A outside of the `j0` loop.
   * `gemmini_extended3_config_ex` has identical parameters across all blocks. We will hoist it to the very start of the function to avoid redundant configuration overhead.

### Optimized Code

```c
#include <stdint.h>
#include <string.h>
#include "include/gemmini_testutils.h"

// Assuming the following definitions are provided by the environment/headers:
// #define DIM 16
// #define MATMUL_M 256
// #define MATMUL_N 256
// #define MATMUL_K 512
// #define BLK 64
// #define BLOCKS_M (REAL_M / BLK)
// #define BLOCKS_N (REAL_N / BLK)
// #define BF16_PER_WORD 4
// typedef uint8_t elem_t;
// typedef uint64_t out_t;

void solution(void) {
  // Pre-format scale factor matrices to eliminate CPU-side staging in the hot loop
  static uint8_t A_scales_perf[BLOCKS_M][MATMUL_K / 32][BLK];
  static uint8_t B_scales_perf[BLOCKS_N][MATMUL_K / 32][BLK];

  // One-time pre-formatting before main loops start
  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      int mrows = REAL_M - i0 * BLK;
      if (mrows > BLK) mrows = BLK;
      if (mrows <= 0) continue;
      
      // Only copy actual data, handle partial blocks correctly
      for (int i = 0; i < mrows; i++) {
        A_scales_perf[i0][g][i] = A_scales_row[g][i0 * BLK + i];
      }
      // Pad with zeros for partial blocks if needed
      for (int i = mrows; i < BLK; i++) {
        A_scales_perf[i0][g][i] = 0;
      }
    }
  }

  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      int ncols = REAL_N - j0 * BLK;
      if (ncols > BLK) ncols = BLK;
      if (ncols <= 0) continue;
      
      // Only copy actual data, handle partial blocks correctly
      for (int j = 0; j < ncols; j++) {
        B_scales_perf[j0][g][j] = B_scales_col[g][j0 * BLK + j];
      }
      // Pad with zeros for partial blocks if needed
      for (int j = ncols; j < BLK; j++) {
        B_scales_perf[j0][g][j] = 0;
      }
    }
  }

  // Hoist static configuration out of execution loops
  gemmini_flush(0);
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    int mrows = REAL_M - i0 * BLK; 
    if (mrows > BLK) mrows = BLK; 
    if (mrows <= 0) continue;

    // Hoist A scale loads: Loaded once per i0 block instead of for every j0 block
    gemmini_mx_load_scales((uint64_t)&A_scales_perf[i0][0][0], A_S_BYTES, 0);

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Partial last M/N block: compute only the real rows/cols, pad the rest.
      int ncols = REAL_N - j0 * BLK; 
      if (ncols > BLK) ncols = BLK; 
      if (ncols <= 0) continue;

      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // Load B scales
      gemmini_mx_load_scales((uint64_t)&B_scales_perf[j0][0][0], B_S_BYTES, 1);

      // MVIN A: Maximize batching to 4 contiguous tiles along K (cols = 4 * DIM)
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k += 4) {
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, 4 * DIM, DIM);
        }
      }

      // MVIN B: Maximize batching to 4 contiguous tiles (cols = 4 * DIM) and route
      // through MVIN2 for independent port pipeline execution
      gemmini_config_ld(MATMUL_N * sizeof(elem_t));
      for (int k = 0; k < tiles_K; k++) {
        gemmini_extended_mvin2((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK)),
                               b_base + (k * tiles) * DIM, 4 * DIM, DIM);
      }

      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Accelerator-centric readout
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
```
