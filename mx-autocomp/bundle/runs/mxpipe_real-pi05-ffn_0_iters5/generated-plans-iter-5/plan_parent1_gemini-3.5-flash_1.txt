An elegant and highly effective optimization plan to address the inefficiencies in the original code is to **eliminate redundant computations and memory transfers** by restructuring the nested loops and scratchpad residency.

### Optimization Plan: Restructuring Loops and Scratchpad Residency

1. **Swap Outer and Inner Loops**: Swap the loop order to make `j0` (weight matrix blocks) the outer loop and `i0` (activation matrix blocks) the inner loop.
2. **Hoist Matrix B and Scale B Loading**: Since the scratchpad is programmer-managed and has separate non-overlapping regions for $A$ (`[0, 2047]`) and $B$ (`[6144, 8191]`), matrix $B$ and its scales only need to be loaded once per `j0` step. Hoisting the `mvin` of $B$ and `gemmini_mx_load_scales` (for $B$) out of the inner loop into the outer loop reduces DRAM-to-scratchpad transfer volume for $B$ by **4×** (since `BLOCKS_M = 4`).
3. **Hoist Global Configurations**: Hoist static configuration instructions (`gemmini_extended3_config_ex`, `gemmini_config_st`, and `gemmini_mxquant_config_mvout`) completely outside of both loops. Since the formats, strides, and tile boundaries remain constant across all iterations, configuring them once at startup avoids unnecessary pipeline stalls.
4. **Preserve Validated Batching**: Keep the optimized 2-tile batching (`cols = 32`) for both matrix $A$ and matrix $B$ loads to maintain peak memory bandwidth efficiency.

#include <stdint.h>
#include <string.h>
#include "include/gemmini_testutils.h"

// Assuming the following definitions are provided by the environment/headers:
// #define DIM 16
// #define MATMUL_M 256
// #define MATMUL_N 256
// #define MATMUL_K 512
// #define BLK 64
// #define BLOCKS_M (REAL_M / BLK)
// #define BLOCKS_N (REAL_N / BLK)
// #define BF16_PER_WORD 4
// typedef uint8_t elem_t;
// typedef uint64_t out_t;

void solution(void) {
  // Pre-format scale factor matrices to eliminate CPU-side staging in the hot loop
  static uint8_t A_scales_perf[BLOCKS_M][MATMUL_K / 32][BLK];
  static uint8_t B_scales_perf[BLOCKS_N][MATMUL_K / 32][BLK];

  // One-time pre-formatting before main loops start
  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      int mrows = REAL_M - i0 * BLK;
      if (mrows > BLK) mrows = BLK;
      if (mrows <= 0) continue;
      
      // Only copy actual data, handle partial blocks correctly
      for (int i = 0; i < mrows; i++) {
        A_scales_perf[i0][g][i] = A_scales_row[g][i0 * BLK + i];
      }
      // Pad with zeros for partial blocks if needed
      for (int i = mrows; i < BLK; i++) {
        A_scales_perf[i0][g][i] = 0;
      }
    }
  }

  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      int ncols = REAL_N - j0 * BLK;
      if (ncols > BLK) ncols = BLK;
      if (ncols <= 0) continue;
      
      // Only copy actual data, handle partial blocks correctly
      for (int j = 0; j < ncols; j++) {
        B_scales_perf[j0][g][j] = B_scales_col[g][j0 * BLK + j];
      }
      // Pad with zeros for partial blocks if needed
      for (int j = ncols; j < BLK; j++) {
        B_scales_perf[j0][g][j] = 0;
      }
    }
  }

  // Global Accel Init
  gemmini_flush(0);
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

  int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
  uint32_t a_base = 0;
  uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
  int SPAD_DEST = 128;

  // Configure output strides and quantization bounds once globally
  gemmini_config_st(BLK_OUTC * sizeof(out_t));
  gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);

  // Outer loop: iterate over B block columns
  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    int ncols = REAL_N - j0 * BLK; 
    if (ncols > BLK) ncols = BLK; 
    if (ncols <= 0) continue;

    int pad_j = BLK - ncols;

    // Load B scales once per outer block column
    gemmini_mx_load_scales((uint64_t)&B_scales_perf[j0][0][0], B_S_BYTES, 1);

    // MVIN B: Statically load and retain B in the top partition of scratchpad
    gemmini_config_ld(MATMUL_N * sizeof(elem_t));      // B rows: stride N
    for (int k = 0; k < tiles_K; k++) {
      for (int j = 0; j < tiles; j += 2) {
        gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                              b_base + (k * tiles + j) * DIM, 2 * DIM, DIM);
      }
    }

    // Inner loop: iterate over A block rows
    for (int i0 = 0; i0 < BLOCKS_M; i0++) {
      int mrows = REAL_M - i0 * BLK; 
      if (mrows > BLK) mrows = BLK; 
      if (mrows <= 0) continue;

      int pad_i = BLK - mrows;

      // Load A scales per iteration
      gemmini_mx_load_scales((uint64_t)&A_scales_perf[i0][0][0], A_S_BYTES, 0);

      // MVIN A: Load A into the bottom partition of scratchpad
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));      // A rows: stride K
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k += 2) {
          gemmini_extended_mvin((void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, 2 * DIM, DIM);
        }
      }

      // Execute Compute
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Output Readout directly from smem
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
      gemmini_fence();
    }
  }
}
