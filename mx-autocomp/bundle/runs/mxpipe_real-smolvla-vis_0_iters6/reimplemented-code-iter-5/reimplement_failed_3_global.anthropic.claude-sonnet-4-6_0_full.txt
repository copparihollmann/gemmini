Looking at the failing code, I need to identify the bug. The key issue is in how `gemmini_mx_load_scales` is called and the scale memory layout.

From the documentation: "Scale format: e8m0 (8-bit exponent only, pure power-of-two); one scale per MX block along K" and "DRAM layout: `scale_dram + m * N_blocks + bi` (row-major, block-indexed)".

The `gemmini_mx_load_scales` loads a contiguous byte stream. The hardware expects all scale codes for the tile to be loaded in a specific layout. Looking at the workflow example:
```c
gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);
```

The scales are loaded as a single contiguous block, not per-group. The array `A_scales_row[GK][M]` has dimensions `[K/32][M]`. For the tile at `i0*BLK`, we need scales for all K-groups contiguously, but calling per-group with `BLK` bytes each is wrong - the strides between groups are `MATMUL_M` bytes apart in memory, but we're loading non-contiguous memory as if it were contiguous.

Also, `BLK_OUTC` is likely `BLK` for output column count. The `gemmini_config_st` stride needs to be `REAL_N` (full output width), not `BLK_OUTC`.

The read smem offset is also suspicious - `r * BLK` should be `r * tiles * DIM` = `r * BLK` but in units matching the smem addressing.

Let me also check: `smem_off_bf16` for row `r` should be `SPAD_DEST * 16 + r * BLK` where BLK is number of BF16 elements per row in the tile.

The main fix: scales must be loaded as a single contiguous call per buffer, matching the full scale array layout.

```c
void solution(void) {
  int tiles   = BLK / DIM;
  int tiles_K = MATMUL_K / DIM;

  uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
  uint32_t a_base = 0;
  int SPAD_DEST = 0;

  // Step 1: Configure execution once (format fields are stateless until changed).
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY,
                              1, 1, 0, 0, false, 0, 0, 3, 0);

  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    int ncols = REAL_N - j0 * BLK;
    if (ncols > BLK) ncols = BLK;
    if (ncols <= 0) continue;

    // Mvin B tiles once per j0 block (weight-stationary: B reused across i0).
    gemmini_config_ld(MATMUL_N * sizeof(elem_t));
    for (int k = 0; k < tiles_K; k++) {
      for (int j = 0; j < tiles; j++) {
        gemmini_extended_mvin2(
          (void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
          b_base + (j * tiles_K + k) * DIM, DIM, DIM);
      }
    }

    for (int i0 = 0; i0 < BLOCKS_M; i0++) {
      int mrows = REAL_M - i0 * BLK;
      if (mrows > BLK) mrows = BLK;
      if (mrows <= 0) continue;

      int pad_i = BLK - mrows;
      int pad_j = BLK - ncols;

      // Step 2: Load A scales - all GK groups for this i0 row block.
      // A_scales_row[GK][MATMUL_M]: load each K-group row segment separately.
      int GK = MATMUL_K / 32;
      for (int g = 0; g < GK; g++) {
        gemmini_mx_load_scales(
          (uint64_t)(&A_scales_row[g][i0 * BLK]),
          (size_t)(BLK),
          0);
      }

      // Step 3: Load B scales - all GK groups for this j0 col block.
      for (int g = 0; g < GK; g++) {
        gemmini_mx_load_scales(
          (uint64_t)(&B_scales_col[g][j0 * BLK]),
          (size_t)(BLK),
          1);
      }

      // Step 4: Mvin A tiles for this i0 block.
      gemmini_config_ld(MATMUL_K * sizeof(elem_t));
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin(
            (void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
            a_base + (i * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      // Step 5: Configure requantized mvout.
      gemmini_config_st(REAL_N * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors,
                                   tiles, tiles, tiles_K, 0, 0, 1);

      // Step 6: Execute fused hardware matmul.
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0,
                           a_base, BANK_NUM * BANK_ROWS, 0, SPAD_DEST,
                           false, false, false, false, false,
                           NO_ACTIVATION, 0, 0, false, 0x38);

      // Step 7: Drain BF16 results from mx_smem to DRAM, row by row.
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(
          (void*)(&C_hw[i0 * BLK + r][j0 * BLK]),
          SPAD_DEST * 16 + r * BLK,
          ncols);
      }

      // Step 8: Fence after all mx_read_smem calls.
      gemmini_fence();
    }
  }
}
```
