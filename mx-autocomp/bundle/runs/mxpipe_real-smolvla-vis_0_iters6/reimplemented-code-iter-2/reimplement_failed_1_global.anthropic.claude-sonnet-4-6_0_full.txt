Looking at the failing code, I need to identify the issues:

1. **B matrix mvin uses wrong port** - B should use `gemmini_extended_mvin2` (mvin2 port), not `gemmini_extended_mvin` (mvin port). Using mvin for both A and B may cause conflicts.

2. **Scale loading sel convention** - Rule 11 says sel=0 for A scales, sel=1 for B scales. The code has this correct already.

3. **B matrix DRAM layout** - B is stored as K×N (row-major), so stride should be `MATMUL_N * sizeof(elem_t)`. The mvin for B looks correct.

4. **The `gemmini_config_ld` id parameter** - mvin and mvin2 are separate ports with separate config. Need `gemmini_extended3_config_ld` with `id=1` for mvin2 (B tiles).

5. **`gemmini_flush` inside the loop** - This is expensive and may not be needed for every tile.

6. **B mvin should use mvin2** - The B tiles need to go through the mvin2 port, configured separately with id=1.

7. **Scale buffer sizes** - `A_S_BYTES` and `B_S_BYTES` need to match the actual sub-block scales being loaded, not the full matrix scales.

The key fix: A tiles should use `gemmini_extended_mvin` (id=0) and B tiles should use `gemmini_extended_mvin2` (id=1), each configured with their own `gemmini_extended3_config_ld(..., id)`.

void solution(void) {
  int tiles_K = MATMUL_K / DIM;
  int tiles = BLK / DIM;
  uint32_t a_base = 0;
  uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
  int SPAD_DEST = 128;

  // Flush once before everything
  gemmini_flush(0);

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int mrows = REAL_M - i0 * BLK; if (mrows > BLK) mrows = BLK; if (mrows <= 0) continue;
      int ncols = REAL_N - j0 * BLK; if (ncols > BLK) ncols = BLK; if (ncols <= 0) continue;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // Gather sub-block scales for A (rows) and B (cols)
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }

      // Step 1: Configure execution (FP8 E4M3 inputs, BF16 output)
      gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY,
          1, 1, 0, 0, false, 0, 0, 3, 0);

      // Step 2: Load scale factors - sel=0 for A (activation), sel=1 for B (weight)
      gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      // Step 4: MVIN A tiles via mvin port (id=0)
      gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 0);
      for (int i = 0; i < tiles; i++)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin(
              (void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
              a_base + (i * tiles_K + k) * DIM, DIM, DIM);

      // Step 4: MVIN B tiles via mvin2 port (id=1)
      gemmini_extended3_config_ld(MATMUL_N * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 1);
      for (int j = 0; j < tiles; j++)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin2(
              (void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
              b_base + (j * tiles_K + k) * DIM, DIM, DIM);

      // Step 5: Configure output stride and requantizer
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors,
          tiles, tiles, tiles_K,
          0, 0, 1);

      // Step 6: Compute weight-stationary tiled matmul
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0,
          a_base, BANK_NUM * BANK_ROWS, 0, SPAD_DEST,
          false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Step 7: Drain BF16 results from mx_smem to DRAM
      for (int r = 0; r < mrows; r++)
        gemmini_mx_read_smem(
            &C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
            SPAD_DEST * 16 + r * BLK, ncols);

      gemmini_fence();
    }
  }
}
