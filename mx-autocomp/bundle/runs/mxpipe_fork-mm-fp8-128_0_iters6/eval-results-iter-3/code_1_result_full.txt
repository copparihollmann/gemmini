Looking at the original code, I notice that `gemmini_mxquant_config_mvout` is called with `lut_update_granularity = tiles_J`, which is already an optimization. However, the key inefficiency is in how B tiles are loaded.

Currently, B tiles are loaded once for all J tiles, and A tiles are loaded once for all I tiles. The `gemmini_loop_ws_spad` hardware loop then computes over all I×J×K tiles. This is actually the correct structure for a single call.

Looking more carefully at the problem: the feedback says "Scratchpad utilization is 0KB out of 256KB" and "Accumulator utilization is 0KB out of 64KB." This suggests the matrix dimensions (MATMUL_M, MATMUL_N, MATMUL_K) are small enough that everything fits in the scratchpad already, but the hardware loop is being issued once. The latency of 217 cycles is quite low.

The key opportunity I see is **strategy 10: minimize `gemmini_fence` calls**. The original code has:
1. `gemmini_fence()` after `gemmini_loop_ws_spad`
2. Another `gemmini_fence()` (with a `gemmini_poll_until_ready()` between on non-SPIKE)
3. `gemmini_mx_read_smem` 
4. Final `gemmini_fence()`

The double fence (lines with `gemmini_fence()` before `gemmini_mx_read_smem`) is redundant — two consecutive fences with only a non-SPIKE poll between them adds unnecessary synchronization overhead.

**Plan: Remove the redundant `gemmini_fence()` call before `gemmini_mx_read_smem`.**

The sequence after `gemmini_loop_ws_spad`:
```c
gemmini_fence();          // ← first fence (waits for loop to complete)
#ifndef SPIKE_SIM
gemmini_poll_until_ready();
#endif
gemmini_fence();          // ← second fence (redundant on SPIKE_SIM path)

gemmini_mx_read_smem(...);
gemmini_fence();          // ← required fence before host reads output
```

On the SPIKE_SIM path (which we're optimizing for), both fences before `gemmini_mx_read_smem` stall execution. The `gemmini_loop_ws_spad` instruction is already dispatched to the accelerator; a single fence is sufficient to ensure it completes before we issue `gemmini_mx_read_smem`. The second fence adds a full barrier stall with no benefit.
