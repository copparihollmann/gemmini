## Analysis

The original code for a 32×32×32 fp8 matmul (tiles_I=2, tiles_J=2, tiles_K=2) has two mvin loops:

```c
for (int i = 0; i < tiles_I; i++)      // 2 iterations
  for (int k = 0; k < tiles_K; k++)    // 2 iterations → 4 mvin calls for A
    gemmini_extended_mvin(...);

for (int j = 0; j < tiles_J; j++)      // 2 iterations
  for (int k = 0; k < tiles_K; k++)    // 2 iterations → 4 mvin calls for B
    gemmini_extended_mvin(...);
```

**Strategy 12**: For this small fixed-size problem (tiles_I=tiles_J=tiles_K=2), fully unroll the mvin loops at compile time to eliminate loop overhead and enable static address computation.

## Plan

Since `tiles_I = MATMUL_M/DIM = 32/16 = 2`, `tiles_J = MATMUL_N/DIM = 32/16 = 2`, and `tiles_K = MATMUL_K/DIM = 32/16 = 2`, all loop bounds are compile-time constants. The loop control overhead (counter increments, comparisons, branches) and dynamic address computations can all be eliminated by fully unrolling the 4 mvin calls for A and 4 mvin calls for B into 8 explicit `gemmini_extended_mvin` calls with statically computed DRAM pointers and scratchpad addresses.

Each address becomes a constant expression:
- A tile (i,k): `dram = A_in + (i*DIM*MATMUL_K + k*DIM)`, `spad = a_base + (i*tiles_K + k)*DIM`
- B tile (j,k): `dram = B_in + (j*DIM*MATMUL_K + k*DIM)`, `spad = b_base + (j*tiles_K + k)*DIM`

With all values known at compile time, the compiler can constant-fold every address expression, removing all loop overhead from the hot path.

## Rewritten Code

```c
void solution(void) {
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
  gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
  gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);

  gemmini_config_ld(MATMUL_K * sizeof(elem_t));

  // Fully unrolled A mvin: tiles_I=2, tiles_K=2 → 4 calls
  // (i=0, k=0): spad = a_base + 0*DIM
  gemmini_extended_mvin((void*)(((elem_t*)A_in) + 0 * DIM * MATMUL_K + 0 * DIM),
                        a_base + 0 * DIM, DIM, DIM);
  // (i=0, k=1): spad = a_base + 1*DIM
  gemmini_extended_mvin((void*)(((elem_t*)A_in) + 0 * DIM * MATMUL_K + 1 * DIM),
                        a_base + 1 * DIM, DIM, DIM);
  // (i=1, k=0): spad = a_base + 2*DIM
  gemmini_extended_mvin((void*)(((elem_t*)A_in) + 1 * DIM * MATMUL_K + 0 * DIM),
                        a_base + 2 * DIM, DIM, DIM);
  // (i=1, k=1): spad = a_base + 3*DIM
  gemmini_extended_mvin((void*)(((elem_t*)A_in) + 1 * DIM * MATMUL_K + 1 * DIM),
                        a_base + 3 * DIM, DIM, DIM);

  // Fully unrolled B mvin: tiles_J=2, tiles_K=2 → 4 calls
  // (j=0, k=0): spad = b_base + 0*DIM
  gemmini_extended_mvin((void*)(((elem_t*)B_in) + 0 * DIM * MATMUL_K + 0 * DIM),
                        b_base + 0 * DIM, DIM, DIM);
  // (j=0, k=1): spad = b_base + 1*DIM
  gemmini_extended_mvin((void*)(((elem_t*)B_in) + 0 * DIM * MATMUL_K + 1 * DIM),
                        b_base + 1 * DIM, DIM, DIM);
  // (j=1, k=0): spad = b_base + 2*DIM
  gemmini_extended_mvin((void*)(((elem_t*)B_in) + 1 * DIM * MATMUL_K + 0 * DIM),
                        b_base + 2 * DIM, DIM, DIM);
  // (j=1, k=1): spad = b_base + 3*DIM
  gemmini_extended_mvin((void*)(((elem_t*)B_in) + 1 * DIM * MATMUL_K + 1 * DIM),
                        b_base + 3 * DIM, DIM, DIM);

  gemmini_config_st(OUT_COLS * sizeof(out_t));
  gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, 1);
  gemmini_loop_ws_spad(tiles_I, tiles_J, tiles_K, 0, 0, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                       SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
  gemmini_mx_read_smem(&C_hw[0][0], SPAD_DEST * 16, MATMUL_M * MATMUL_N);
  gemmini_fence();
}
```
