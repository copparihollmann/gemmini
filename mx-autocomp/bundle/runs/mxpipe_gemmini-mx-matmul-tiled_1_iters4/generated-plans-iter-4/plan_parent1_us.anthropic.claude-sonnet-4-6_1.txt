## Analysis

Looking at the original code, the outer loops are:
```
for i0 in BLOCKS_M:
  for j0 in BLOCKS_N:
    ... load A_blk (BLK x K rows of A)
    ... load B_blk (BLK x K rows of B)
    ... mvin A tiles
    ... mvin B tiles (same port as A: mvin)
    ... compute
```

**Key inefficiency**: A tiles and B tiles are both loaded using `gemmini_extended_mvin` (the same port, `k_MVIN`). The hardware has **three independent mvin ports**: `mvin` (k_MVIN), `mvin2` (k_MVIN2), and `mvin3` (k_MVIN3). By using separate ports for A and B, the DMA loads can proceed in parallel, overlapping the two transfers instead of serializing them.

**Strategy 6**: Use `mvin2` for B tiles while using `mvin` for A tiles.

## Plan

Change B tile loads from `gemmini_extended_mvin` to `gemmini_extended_mvin2`, and issue a separate `gemmini_config_ld` for the B stride using `gemmini_extended3_config_ld(..., id=1)` (id=1 configures the stride for port mvin2). This allows A and B DMA transfers to proceed simultaneously.

Specifically:
1. Before the A mvin loop, configure port 0 (mvin): `gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 0)` — this sets id=0's stride to `MATMUL_K`.
2. Before the B mvin loop, configure port 1 (mvin2): `gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 1)` — this sets id=1's stride to `MATMUL_K`.
3. Change the B tile loop from `gemmini_extended_mvin(...)` to `gemmini_extended_mvin2(...)`.

The interleaved issuing of mvin and mvin2 commands allows the two DMA engines to work concurrently, reducing the total tile-load latency.

## Rewritten Code

```c
void solution(void) {
  gemmini_flush(0);
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      // Stage A/B blocks and scales
      for (int r = 0; r < BLK; r++)
        memcpy(&A_blk[r][0], &A_in[i0 * BLK + r][0], MATMUL_K);
      for (int r = 0; r < BLK; r++)
        memcpy(&B_blk[r][0], &B_in[j0 * BLK + r][0], MATMUL_K);
      for (int g = 0; g < MATMUL_K / 32; g++) {
        memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);
      }

      int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      int SPAD_DEST = 128;

      gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      // Configure port 0 (mvin) for A tiles: stride = MATMUL_K bytes per row
      gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 0);
      // Configure port 1 (mvin2) for B tiles: stride = MATMUL_K bytes per row
      gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 1);

      // Issue A and B mvin commands interleaved so both DMA ports are active simultaneously
      for (int i = 0; i < tiles; i++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin(
            (void*)(((elem_t*)A_blk) + i * DIM * MATMUL_K + k * DIM),
            a_base + (i * tiles_K + k) * DIM, DIM, DIM);
        }
      }
      for (int j = 0; j < tiles; j++) {
        for (int k = 0; k < tiles_K; k++) {
          gemmini_extended_mvin2(
            (void*)(((elem_t*)B_blk) + j * DIM * MATMUL_K + k * DIM),
            b_base + (j * tiles_K + k) * DIM, DIM, DIM);
        }
      }

      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, 0, 0, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
      gemmini_mx_read_smem(&C_blk[0][0], SPAD_DEST * 16, BLK * BLK);
      gemmini_fence();

      for (int r = 0; r < BLK; r++)
        for (int c = 0; c < BLK; c++) {
          uint16_t b = (uint16_t)((C_blk[r][c / 4] >> ((c % 4) * 16)) & 0xFFFF);
          C_acc[i0 * BLK + r][j0 * BLK + c] = bf16f(b);
        }
    }
  }
}
```
