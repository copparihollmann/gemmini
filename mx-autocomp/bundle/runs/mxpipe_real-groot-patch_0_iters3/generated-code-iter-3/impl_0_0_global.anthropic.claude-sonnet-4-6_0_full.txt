Looking at the plan, I need to:

1. Hoist `gemmini_flush` and `gemmini_extended3_config_ex` outside all loops (call once)
2. Hoist A scale `memcpy` and `gemmini_mx_load_scales(A)` outside the `j0` loop (once per `i0`)
3. Hoist A tile MVIN outside the `j0` loop (once per `i0`)
4. Keep B scale `memcpy`, `gemmini_mx_load_scales(B)`, B tile MVIN, compute, and readout inside `j0`
5. Follow the programming model sequence strictly: `config_ex` → `load_scales(A)` → `load_scales(B)` → mvin tiles → `mxquant_config_mvout` → `loop_ws_spad` → `read_smem` → `fence`

Key constraint: The sequence requires both A and B scales loaded before each `loop_ws_spad`. A scales persist in hardware (not overwritten between `j0` iterations since only B is reloaded), so this is valid. I must still ensure A scales are loaded before each `loop_ws_spad` — since they're loaded once per `i0` before the `j0` loop, and B scales are reloaded each `j0` without touching A scale memory, A scales remain valid throughout the `j0` loop.

```c
void solution(void) {
  int tiles   = BLK / DIM;
  int tiles_K = MATMUL_K / DIM;
  uint32_t a_base   = 0;
  uint32_t b_base   = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
  int      SPAD_DEST = 128;

  // Hoist one-time setup outside all loops.
  gemmini_flush(0);
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY,
                               1, 1, 0, 0, false, 0, 0, 3, 0);

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    int mrows = REAL_M - i0 * BLK;
    if (mrows > BLK) mrows = BLK;
    if (mrows <= 0)  continue;

    // --- Stage A scales once per i0 (A scales do not depend on j0) ---
    for (int g = 0; g < MATMUL_K / 32; g++)
      memcpy(&A_s[g][0], &A_scales_row[g][i0 * BLK], BLK);

    // Load A scales into hardware once per i0; they persist for all j0.
    // (sel=0 → mx_scale_a_mem, per rule 11)
    gemmini_mx_load_scales((uint64_t)A_s, A_S_BYTES, 0);

    // --- MVIN A tiles once per i0 (A tiles do not depend on j0) ---
    gemmini_config_ld(MATMUL_K * sizeof(elem_t));   // A row stride = K
    for (int i = 0; i < tiles; i++)
      for (int k = 0; k < tiles_K; k++)
        gemmini_extended_mvin(
          (void*)(((elem_t*)A_in) + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
          a_base + (i * tiles_K + k) * DIM,
          DIM, DIM);

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int ncols = REAL_N - j0 * BLK;
      if (ncols > BLK) ncols = BLK;
      if (ncols <= 0)  continue;

      int pad_i = BLK - mrows;
      int pad_j = BLK - ncols;

      // --- Stage and load B scales (depend on j0) ---
      for (int g = 0; g < MATMUL_K / 32; g++)
        memcpy(&B_s[g][0], &B_scales_col[g][j0 * BLK], BLK);

      // sel=1 → mx_scale_b_mem (rule 11); A scales already in hw, not touched.
      gemmini_mx_load_scales((uint64_t)B_s, B_S_BYTES, 1);

      // --- MVIN B tiles (depend on j0) ---
      gemmini_config_ld(MATMUL_N * sizeof(elem_t));   // B row stride = N
      for (int j = 0; j < tiles; j++)
        for (int k = 0; k < tiles_K; k++)
          gemmini_extended_mvin2(
            (void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
            b_base + (k * tiles + j) * DIM,
            DIM, DIM);

      // --- Configure output / requantizer ---
      gemmini_config_st(BLK_OUTC * sizeof(out_t));
      // i_bound=tiles, j_bound=tiles, k_bound=tiles_K must match loop_ws_spad (rule 12)
      gemmini_mxquant_config_mvout((uint64_t)scale_factors,
                                   tiles, tiles, tiles_K,
                                   /*scale_act_sel*/0, /*scale_w_sel*/0,
                                   /*lut_update_granularity*/1);

      // --- Compute (funct-24 marker is one-shot; macro re-issues it, rule 14) ---
      gemmini_loop_ws_spad(tiles, tiles, tiles_K,
                           pad_i, pad_j, 0,
                           a_base, BANK_NUM * BANK_ROWS, 0, SPAD_DEST,
                           false, false,
                           false, false, false,
                           NO_ACTIVATION, 0, 0, false, 0x38);

      // --- Drain BF16 results from mx_smem to DRAM ---
      for (int r = 0; r < mrows; r++)
        gemmini_mx_read_smem(
          &C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
          SPAD_DEST * 16 + r * BLK,
          ncols);

      gemmini_fence();
    } // j0
  } // i0
}
```
