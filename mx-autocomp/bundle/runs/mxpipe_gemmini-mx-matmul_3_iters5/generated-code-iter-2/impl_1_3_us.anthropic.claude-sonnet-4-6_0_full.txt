1. **Mvin batching**: Use `MAX_BLOCK_LEN=4` to batch up to 4 consecutive tiles per mvin command, reducing instruction count
2. **Port separation**: Use `mvin` for A and `mvin2` for B to enable parallel DMA loads
3. **Stride configuration**: Set up strides correctly for batched loads
4. **B tile layout**: The B tiles in the scratchpad use `b_base + (k * tiles_J + j) * DIM` indexing - this matches the hardware's expected layout

For the 128×128×256 problem:
- `tiles_I = 8`, `tiles_J = 8`, `tiles_K = 16`
- `a_base = 0`, `b_base = BANK_NUM*BANK_ROWS - tiles_K*tiles_J*DIM = 8192 - 16*8*16 = 8192 - 2048 = 6144`
- A needs `8*16*16 = 2048` rows, B needs `16*8*16 = 2048` rows — fits within scratchpad

With `MAX_BLOCK_LEN=4`, we can batch 4 consecutive K-tiles at once for both A and B loading, reducing mvin instructions by 4×.

void solution(void) {
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
  gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
  gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);

  // Load A tiles using mvin port, batching up to MAX_BLOCK_LEN=4 consecutive k-tiles
  gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 0);
  for (int i = 0; i < tiles_I; i++) {
    for (int k = 0; k < tiles_K; k += MAX_BLOCK_LEN) {
      int batch = (k + MAX_BLOCK_LEN <= tiles_K) ? MAX_BLOCK_LEN : (tiles_K - k);
      gemmini_extended_mvin(
        (void*)(((elem_t*)A_in) + i * DIM * MATMUL_K + k * DIM),
        a_base + (i * tiles_K + k) * DIM,
        batch * DIM, DIM);
    }
  }

  // Load B tiles using mvin2 port, batching up to MAX_BLOCK_LEN=4 consecutive k-tiles per j
  gemmini_extended3_config_ld(MATMUL_N * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 1);
  for (int j = 0; j < tiles_J; j++) {
    for (int k = 0; k < tiles_K; k += MAX_BLOCK_LEN) {
      int batch = (k + MAX_BLOCK_LEN <= tiles_K) ? MAX_BLOCK_LEN : (tiles_K - k);
      gemmini_extended_mvin2(
        (void*)(((elem_t*)B_in) + k * DIM * MATMUL_N + j * DIM),
        b_base + (k * tiles_J + j) * DIM,
        DIM, batch * DIM);
    }
  }

  gemmini_config_st(OUT_COLS * sizeof(out_t));
  gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, tiles_K);
  gemmini_loop_ws_spad(tiles_I, tiles_J, tiles_K, 0, 0, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                       SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
  gemmini_mx_read_smem(&C_hw[0][0], SPAD_DEST * 16, MATMUL_M * MATMUL_N);
  gemmini_fence();
}
