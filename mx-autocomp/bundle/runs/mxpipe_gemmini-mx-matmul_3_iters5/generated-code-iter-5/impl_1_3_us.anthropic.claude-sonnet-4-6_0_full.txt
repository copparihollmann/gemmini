Looking at the original code, the issue seems to be related to the B tile layout in the scratchpad. Let me analyze the problem carefully.

The B matrix layout requires tiles at `b_base + (j*tiles_K + k)*DIM`, but the original code uses `b_base + (k*tiles_J + j)*DIM`. The B base is `BANK_NUM*BANK_ROWS - tiles_K*tiles_J*DIM`, and the `gemmini_loop_ws_spad` passes `BANK_NUM*BANK_ROWS` as the B end address.

Looking at the B tile indexing: the architecture doc says B layout is `b_base + (j*tiles_K + k)*DIM`, but the original loads with `(k*tiles_J + j)*DIM`. These are equivalent only if tiles_J == tiles_K. The correct layout for weight-stationary must match what `gemmini_loop_ws_spad` expects.

Also, the A mvin is using `DIM * batch` cols but should use `DIM` cols per tile row (rows=DIM, cols=DIM per tile). For batched loads, cols should be `DIM` and rows should be `DIM * batch` or we use the block mvin convention properly.

Let me rewrite with correct B indexing (`j*tiles_K + k`) and proper mvin parameters:

```c
void solution(void) {
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
  gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
  gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);

  // Configure mvin port 0 (A) with stride = K cols (bytes per row)
  gemmini_extended3_config_ld(MATMUL_K * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 0);

  // Load A tiles: a_base + (i*tiles_K + k)*DIM
  // Batch consecutive k tiles (up to MAX_BLOCK_LEN=4) per mvin
  for (int i = 0; i < tiles_I; i++) {
    for (int k = 0; k < tiles_K; k += MAX_BLOCK_LEN) {
      int batch = (tiles_K - k < MAX_BLOCK_LEN) ? (tiles_K - k) : MAX_BLOCK_LEN;
      elem_t *dram_ptr = ((elem_t*)A_in) + i * DIM * MATMUL_K + k * DIM;
      uint32_t sp_addr = a_base + (i * tiles_K + k) * DIM;
      gemmini_extended_mvin((void*)dram_ptr, sp_addr, DIM, DIM * batch);
    }
  }

  // Configure mvin port 1 (B) with stride = N cols (bytes per row)
  gemmini_extended3_config_ld(MATMUL_N * sizeof(elem_t), MVIN_SCALE_IDENTITY, false, 1);

  // Load B tiles: b_base + (j*tiles_K + k)*DIM
  // Weight-stationary layout: for each j, iterate over k
  // Batch consecutive k tiles (up to MAX_BLOCK_LEN=4) per mvin
  for (int j = 0; j < tiles_J; j++) {
    for (int k = 0; k < tiles_K; k += MAX_BLOCK_LEN) {
      int batch = (tiles_K - k < MAX_BLOCK_LEN) ? (tiles_K - k) : MAX_BLOCK_LEN;
      elem_t *dram_ptr = ((elem_t*)B_in) + k * DIM * MATMUL_N + j * DIM;
      uint32_t sp_addr = b_base + (j * tiles_K + k) * DIM;
      gemmini_extended_mvin2((void*)dram_ptr, sp_addr, DIM, DIM * batch);
    }
  }

  gemmini_config_st(OUT_COLS * sizeof(out_t));
  gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, tiles_K);

  gemmini_loop_ws_spad(tiles_I, tiles_J, tiles_K, 0, 0, 0,
                       a_base, BANK_NUM * BANK_ROWS, 0,
                       SPAD_DEST, false, false, false, false, false,
                       NO_ACTIVATION, 0, 0, false, 0x38);

  gemmini_mx_read_smem(&C_hw[0][0], SPAD_DEST * 16, MATMUL_M * MATMUL_N);
  gemmini_fence();
}
```
