An elegant and highly effective optimization plan for Phase 1 is to apply **Strategy 2: pack A and B tiles contiguously in scratchpad to maximize `gemmini_loop_ws_spad` fused loop coverage**.

### Inefficiency in the Baseline Code
The baseline kernel uses a conservative block size `bb` of at most `2` when issuing DMA `mvin` commands to load the $Q$, $K^T$, $P$, and $V$ matrices. This means it only loads up to 2 tiles along the contiguous dimension per instruction. Since the Gemmini hardware supports a `MAX_BLOCK_LEN` of `4` tiles (64 bytes/elements per row) for the scratchpad, the baseline code is performing twice as many DMA configuration and transfer instructions as necessary. This introduces substantial instruction-issue and control-flow overhead on the host CPU.

### Optimization Plan
We will maximize scratchpad packing and minimize DMA instruction overhead by upgrading the tiling/blocking factors `bb` to the hardware limit of `4` tiles (`4 * DIM` elements) for both matmul stages.

1. **First Matmul ($Q \times K^T$)**:
   - For $Q$ ($128 \times 64$, `tiles_K = 4`): We can load all 4 tiles along the $K$ dimension in a single contiguous block of `bb = 4`. This completely eliminates the inner loop over $k$ for loading $Q$, reducing the $Q$ loading phase from 16 to 8 `mvin` calls.
   - For $K^T$ ($64 \times 128$, `tiles_J = 8`): We will increase the block size for loading columns from 2 to 4. The inner loop over $j$ will now run only twice (using `bb = 4` each time), reducing the $K^T$ loading phase from 16 to 8 `mvin` calls.

2. **Second Matmul ($P \times V$)**:
   - For $P$ ($128 \times 128$, `tiles_K = 8`): We will increase the block size from 2 to 4. The inner loop over $k$ will now step by 4 (running twice per row of tiles instead of 4 times), reducing $P$ loading from 32 to 16 `mvin` calls.
   - For $V$ ($128 \times 64$, `tiles_J = 4`): Since `tiles_J = 4`, we can load the entire row block in a single `bb = 4` command. This completely eliminates the inner loop over $j$ for loading $V$, reducing the $V$ loading phase from 16 to 8 `mvin` calls.

### Optimized Code

```c
// Optimized MX attention kernel (S=128, D=64) using Strategy 2.
void solution(void) {
  // ---- 1) S1 = Q @ K^T on Gemmini (bf16 out) ----
  {
    int tiles_I = ATT_S / DIM, tiles_J = ATT_S / DIM, tiles_K = ATT_D / DIM;
    uint32_t a_base = 0;
    uint32_t b_base = BANK_NUM * BANK_ROWS - tiles_K * tiles_J * DIM;
    gemmini_flush(0);
    gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
    gemmini_mx_load_scales((uint64_t)&Q_scales_row, sizeof(Q_scales_row), 0);
    gemmini_mx_load_scales((uint64_t)&KT_scales_col, sizeof(KT_scales_col), 1);
    
    // Load Q tiles: pack 4 tiles along K contiguously (bb = 4)
    gemmini_config_ld(ATT_D * sizeof(elem_t));
    for (int i = 0; i < tiles_I; i++) {
      gemmini_extended_mvin((void*)(((elem_t*)Q_in) + i * DIM * ATT_D),
                            a_base + (i * tiles_K) * DIM, 4 * DIM, DIM);
    }
    
    // Load KT tiles: pack 4 tiles along J contiguously (bb = 4)
    gemmini_config_ld(ATT_S * sizeof(elem_t));
    for (int k = 0; k < tiles_K; k++) {
      for (int j = 0; j < tiles_J; j += 4) {
        int bb = (tiles_J - j < 4) ? (tiles_J - j) : 4;
        gemmini_extended_mvin((void*)(((elem_t*)KT_in) + (k * DIM) * ATT_S + j * DIM),
                              b_base + (k * tiles_J + j) * DIM, bb * DIM, DIM);
      }
    }
    
    gemmini_config_st(S_OUT_COLS * sizeof(out_t));
    gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, 1);
    gemmini_loop_ws_spad(tiles_I, tiles_J, tiles_K, 0, 0, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                         SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
    gemmini_mx_read_smem(&S1_hw[0][0], SPAD_DEST * 16, ATT_S * ATT_S);
    gemmini_fence();
  }

  // ---- 2) FLOAT-FREE integer softmax + fp8 requant (I-BERT iexp; host has no FPU) ----
  for (int i = 0; i < ATT_S; i++) {
    int64_t q[ATT_S];
    int64_t mq = -((int64_t)1 << 62);
    for (int j = 0; j < ATT_S; j += 4) {
      uint64_t w = S1_hw[i][j / 4];
      for (int l = 0; l < 4; l++) {
#if ATT_CAUSAL
        if (j + l > i) { q[j + l] = -((int64_t)1 << 62); continue; }
#endif
        int64_t qq = mx_ibf16_to_q((uint16_t)((w >> (l * 16)) & 0xFFFF));
        q[j + l] = qq; if (qq > mq) mq = qq;
      }
    }
    int64_t p[ATT_S];
    int64_t sm = 0;
    int64_t gmax_arr[GROUPS_S];
    for (int g = 0; g < GROUPS_S; g++) {
      int64_t gmax = 0;
      for (int j = g * 32; j < (g + 1) * 32; j++) { int64_t pv = mx_iexp(q[j] - mq); p[j] = pv; sm += pv; if (pv > gmax) gmax = pv; }
      gmax_arr[g] = gmax;
    }
    int ls = mx_ilog2((uint64_t)sm);
    uint64_t inv_sm = (((uint64_t)1 << (ls + MX_FRAC)) + ((uint64_t)sm >> 1)) / (uint64_t)sm;
    for (int g = 0; g < GROUPS_S; g++) {
      int64_t gmax = gmax_arr[g];
      if (gmax == 0) { P_scales[g][i] = 0; for (int j = g * 32; j < (g + 1) * 32; j++) P_q[i][j] = 0; continue; }
      int e = mx_ilog2((uint64_t)gmax) - ls - MX_P_TARGET_LOG2;
      P_scales[g][i] = (uint8_t)(e + 127);
      for (int j = g * 32; j < (g + 1) * 32; j++) P_q[i][j] = mx_ienc_fp8(p[j], inv_sm, ls, e);
    }
  }

  // ---- 3) O = P @ V on Gemmini (bf16 out) ----
  {
    int tiles_I = ATT_S / DIM, tiles_J = ATT_D / DIM, tiles_K = ATT_S / DIM;
    uint32_t a_base = 0;
    uint32_t b_base = BANK_NUM * BANK_ROWS - tiles_K * tiles_J * DIM;
    gemmini_flush(0);
    gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
    gemmini_mx_load_scales((uint64_t)&P_scales, sizeof(P_scales), 0);
    gemmini_mx_load_scales((uint64_t)&V_scales_col, sizeof(V_scales_col), 1);
    
    // Load P tiles: pack 4 tiles along K contiguously (bb = 4)
    gemmini_config_ld(ATT_S * sizeof(elem_t));
    for (int i = 0; i < tiles_I; i++) {
      for (int k = 0; k < tiles_K; k += 4) {
        int bb = (tiles_K - k < 4) ? (tiles_K - k) : 4;
        gemmini_extended_mvin((void*)(((elem_t*)P_q) + i * DIM * ATT_S + k * DIM),
                              a_base + (i * tiles_K + k) * DIM, bb * DIM, DIM);
      }
    }
    
    // Load V tiles: pack 4 tiles along J contiguously (bb = 4)
    gemmini_config_ld(ATT_D * sizeof(elem_t));
    for (int k = 0; k < tiles_K; k++) {
      gemmini_extended_mvin((void*)(((elem_t*)V_in) + (k * DIM) * ATT_D),
                            b_base + (k * tiles_J) * DIM, 4 * DIM, DIM);
    }
    
    gemmini_config_st(D_OUT_COLS * sizeof(out_t));
    gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, 1);
    gemmini_loop_ws_spad(tiles_I, tiles_J, tiles_K, 0, 0, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                         SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
    gemmini_mx_read_smem(&O_hw[0][0], SPAD_DEST * 16, ATT_S * ATT_D);
    gemmini_fence();
  }
}
```
