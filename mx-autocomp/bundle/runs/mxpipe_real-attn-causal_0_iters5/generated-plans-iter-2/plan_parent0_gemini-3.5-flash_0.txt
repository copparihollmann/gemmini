# Optimization Plan

To improve the execution time of the baseline attention kernel, we will apply **Strategy 1: Cache reused data in local memory instead of reloading from main memory**. Specifically, we will optimize the staging of memory blocks in the local scratchpad (SRAM) by maximizing the DMA transfer sizes to utilize the hardware's peak capabilities.

### Inefficiencies in Baseline Code
1. **Under-utilization of DMA Block Size:** The baseline code transfers tiles with a block size of at most 2 (`bb = 2`). The MX-Gemmini hardware scratchpad supports a maximum block length of 4 (`MAX_BLOCK_LEN = 4` or up to 64 bytes per row). Transferring smaller blocks increases RISC-V host loop overhead, command-issue latency, and overall DMA synchronization overhead.
2. **Redundant Inner Loops:** Because of the conservative block size of 2, the baseline code requires nested loops to load the $Q$, $K^T$, $P$, and $V$ matrices. For dimensions that are multiples of 4, we can completely unroll or coalesce the inner loop iterations, significantly reducing control flow overhead on the host.

### Optimization Steps
1. **Coalesce $Q$ and $V$ DRAM Transfers:** Since $Q$ and $V$ have intermediate dimension size $D = 64$ (`tiles_K = 4` for $Q$ and `tiles_J = 4` for $V$), we can load the entire block span in a single DMA transfer (`bb = 4`). This completely flattens the inner loop for these transfers.
2. **Tile $K^T$ and $P$ with Maximum Block Length (`bb = 4`):** For $K^T$ and $P$, which span the dimension $S = 128$ (`tiles_J = 8` for $K^T$ and `tiles_K = 8` for $P$), we will transfer data using a step size of 4. This cuts the number of required `mvin` commands and associated loop iterations in half.
3. **Preserve Precise Sequencing and Semantic Equivalence:** All computation logic, including the host-side float-free integer softmax and quantization operations, is kept bit-exact to satisfy numerical constraints.

# Optimized Code

```c
// Optimized MX attention kernel (S=128, D=64).
void solution(void) {
  // ---- 1) S1 = Q @ K^T on Gemmini (bf16 out) ----
  {
    int tiles_I = ATT_S / DIM, tiles_J = ATT_S / DIM, tiles_K = ATT_D / DIM;
    uint32_t a_base = 0;
    uint32_t b_base = BANK_NUM * BANK_ROWS - tiles_K * tiles_J * DIM;
    gemmini_flush(0);
    gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
    gemmini_mx_load_scales((uint64_t)&Q_scales_row, sizeof(Q_scales_row), 0);
    gemmini_mx_load_scales((uint64_t)&KT_scales_col, sizeof(KT_scales_col), 1);
    
    // MVIN A: Load entire K-dimension for Q at once (tiles_K = 4)
    gemmini_config_ld(ATT_D * sizeof(elem_t));
    for (int i = 0; i < tiles_I; i++) {
        gemmini_extended_mvin((void*)(((elem_t*)Q_in) + i * DIM * ATT_D),
                              a_base + (i * tiles_K) * DIM, tiles_K * DIM, DIM);
    }
    
    // MVIN B: Load KT in blocks of 4 (reducing inner loop iterations by half)
    gemmini_config_ld(ATT_S * sizeof(elem_t));
    for (int k = 0; k < tiles_K; k++) {
      for (int j = 0; j < tiles_J; j += 4) {
        int bb = (tiles_J - j < 4) ? (tiles_J - j) : 4;
        gemmini_extended_mvin((void*)(((elem_t*)KT_in) + (k * DIM) * ATT_S + j * DIM),
                              b_base + (k * tiles_J + j) * DIM, bb * DIM, DIM);
      }
    }
    
    gemmini_config_st(S_OUT_COLS * sizeof(out_t));
    gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, 1);
    gemmini_loop_ws_spad(tiles_I, tiles_J, tiles_K, 0, 0, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                         SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
    gemmini_mx_read_smem(&S1_hw[0][0], SPAD_DEST * 16, ATT_S * ATT_S);
    gemmini_fence();
  }

  // ---- 2) FLOAT-FREE integer softmax + fp8 requant (I-BERT iexp; host has no FPU) ----
  for (int i = 0; i < ATT_S; i++) {
    int64_t q[ATT_S];
    int64_t mq = -((int64_t)1 << 62);
    for (int j = 0; j < ATT_S; j += 4) {                       // unpack 4 bf16/word -> Q(1/1024) int + max
      uint64_t w = S1_hw[i][j / 4];
      for (int l = 0; l < 4; l++) {
#if ATT_CAUSAL
        if (j + l > i) { q[j + l] = -((int64_t)1 << 62); continue; }   // causal: future col -> iexp()=0
#endif
        int64_t qq = mx_ibf16_to_q((uint16_t)((w >> (l * 16)) & 0xFFFF));
        q[j + l] = qq; if (qq > mq) mq = qq;
      }
    }
    int64_t p[ATT_S];
    int64_t sm = 0;
    int64_t gmax_arr[GROUPS_S];                                // fused group-max: capture per-group max IN the iexp pass
    for (int g = 0; g < GROUPS_S; g++) {                       // (group-nested, register-scalar gmax) -> removes the
      int64_t gmax = 0;                                        // separate 16384-elem max scan. Output bit-identical.
      for (int j = g * 32; j < (g + 1) * 32; j++) { int64_t pv = mx_iexp(q[j] - mq); p[j] = pv; sm += pv; if (pv > gmax) gmax = pv; }
      gmax_arr[g] = gmax;
    }
    int ls = mx_ilog2((uint64_t)sm);
    uint64_t inv_sm = (((uint64_t)1 << (ls + MX_FRAC)) + ((uint64_t)sm >> 1)) / (uint64_t)sm;   // one rounded reciprocal/row
    for (int g = 0; g < GROUPS_S; g++) {
      int64_t gmax = gmax_arr[g];
      if (gmax == 0) { P_scales[g][i] = 0; for (int j = g * 32; j < (g + 1) * 32; j++) P_q[i][j] = 0; continue; }
      // group e8m0 scale so the group-max lands at ~2^MX_P_TARGET_LOG2 (moderate; avoids e4 overflow)
      int e = mx_ilog2((uint64_t)gmax) - ls - MX_P_TARGET_LOG2;
      P_scales[g][i] = (uint8_t)(e + 127);
      for (int j = g * 32; j < (g + 1) * 32; j++) P_q[i][j] = mx_ienc_fp8(p[j], inv_sm, ls, e);
    }
  }

  // ---- 3) O = P @ V on Gemmini (bf16 out) ----
  {
    int tiles_I = ATT_S / DIM, tiles_J = ATT_D / DIM, tiles_K = ATT_S / DIM;
    uint32_t a_base = 0;
    uint32_t b_base = BANK_NUM * BANK_ROWS - tiles_K * tiles_J * DIM;
    gemmini_flush(0);
    gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
    gemmini_mx_load_scales((uint64_t)&P_scales, sizeof(P_scales), 0);
    gemmini_mx_load_scales((uint64_t)&V_scales_col, sizeof(V_scales_col), 1);
    
    // MVIN A: Load P_q in blocks of 4 (reducing inner loop iterations by half)
    gemmini_config_ld(ATT_S * sizeof(elem_t));
    for (int i = 0; i < tiles_I; i++) {
      for (int k = 0; k < tiles_K; k += 4) {
        int bb = (tiles_K - k < 4) ? (tiles_K - k) : 4;
        gemmini_extended_mvin((void*)(((elem_t*)P_q) + i * DIM * ATT_S + k * DIM),
                              a_base + (i * tiles_K + k) * DIM, bb * DIM, DIM);
      }
    }
    
    // MVIN B: Load entire J-dimension for V at once (tiles_J = 4)
    gemmini_config_ld(ATT_D * sizeof(elem_t));
    for (int k = 0; k < tiles_K; k++) {
        gemmini_extended_mvin((void*)(((elem_t*)V_in) + (k * DIM) * ATT_D),
                              b_base + (k * tiles_J) * DIM, tiles_J * DIM, DIM);
    }
    
    gemmini_config_st(D_OUT_COLS * sizeof(out_t));
    gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, 1);
    gemmini_loop_ws_spad(tiles_I, tiles_J, tiles_K, 0, 0, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                         SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
    gemmini_mx_read_smem(&O_hw[0][0], SPAD_DEST * 16, ATT_S * ATT_D);
    gemmini_fence();
  }
}
```
