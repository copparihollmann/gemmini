An elegant way to optimize this MX-Gemmini kernel is to apply **Strategy 11: Accumulator Double-Buffer Sizing**. 

### Inefficiency in the Original Code
In the original program, the active output workspace size of the hardware loop is `ti * tj * DIM = 4 * 4 * 16 = 256` accumulator rows. This utilizes 100% of the accumulator capacity (`ACC_ROWS = 256`), which forces the hardware to run in single-buffer mode. Consequently, the systolic array must stall and wait for the requantizer to fully drain the accumulated results to the shared memory before starting the next computation.

### Optimization Plan
To enable hardware-level accumulator double-buffering, we will size the active output workspace to be at or below 128 rows (half of the total capacity). 

1. **Split the `I` Dimension**: We will split `ti` (which is 4) into 2 blocks of `block_ti = 2`. This reduces each `gemmini_loop_ws_spad` workspace size to `2 * 4 * 16 = 128` rows.
2. **Double-Buffered Accumulator Layout**: 
   - Block 0 will compute the first half of the rows, writing to the upper half of the accumulator partition (`SPAD_DEST = 128`).
   - Block 1 will compute the second half, writing to the lower half of the accumulator partition (`SPAD_DEST = 0`).
3. **Overlapped Execution**: The hardware will now automatically overlap the draining of Block 0 results from the accumulator with the systolic array computation of Block 1.
4. **Preserve Scratchpad and Scale Factors**: All A and B tiles will still be pre-loaded into the scratchpad at once to avoid redundant data movement. We will adjust the scale-factor pointers and shared memory read destinations to correctly place the split outputs back into the contiguous `C_hw` matrix.
5. **Optimize LUT Granularity**: Raise `lut_update_granularity` to 16 (`tk`) since the requantization LUT is invariant across the reduction.

Here is the fully optimized implementation:

```c
#include <stdint.h>
#include <string.h>
#include "include/gemmini_testutils.h"

// AUTO-GENERATED optimized MX matmul kernel (128x128x256, fp6:e3m2).
void solution(void) {
  {
    int ti = MATMUL_M / DIM / 2, tj = MATMUL_N / DIM / 2, tk = MATMUL_K / DIM;
    uint32_t ab = 0;
    uint32_t bb = BANK_NUM * BANK_ROWS - tk * tj * DIM;
    
    // Split ti into 2 blocks of 2 to trigger Accumulator Double-Buffering
    int block_ti = 2;
    
    gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 1, 1, 3, 1);
    gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
    gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);
    gemmini_config_st(OUT_COLS * sizeof(out_t));
    
    gemmini_mx_load_lut((uint64_t)B_lut_p, 1, 0);
    gemmini_mx_load_lut((uint64_t)A_lut_p, 1, 1);
    
    // Batch MVIN for A: Load 2 tiles (32 columns) at once
    gemmini_config_ld(MATMUL_K * sizeof(elem_t));
    for (int i = 0; i < ti; i++) {
      for (int k = 0; k < tk; k += 2) {
        gemmini_extended_mvin((void*)(((elem_t*)A_in_hw) + i*DIM*MATMUL_K + k*DIM), ab + (i*tk + k)*DIM, 2 * DIM, DIM);
      }
    }
    
    // Batch MVIN for B: Load 2 tiles (32 columns) at once
    gemmini_config_ld(MATMUL_N * sizeof(elem_t) / 2);
    for (int k = 0; k < tk; k++) {
      for (int j = 0; j < tj; j += 2) {
        gemmini_extended_mvin((void*)(((elem_t*)B_in) + k*DIM*(MATMUL_N/2) + j*DIM), bb + (k*tj + j)*DIM, 2 * DIM, DIM);
      }
    }
    
    uint8_t *sf_ptr = (uint8_t*)scale_factors;
    
    // Block 0: First 2 tiles of I (uses accumulator rows 128-255)
    gemmini_mxquant_config_mvout((uint64_t)sf_ptr, block_ti, tj, tk, 0, 0, 16);
    gemmini_loop_ws_spad(block_ti, tj, tk, 0, 0, 0, ab, BANK_NUM * BANK_ROWS, 0, 128, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
    
    // Block 1: Second 2 tiles of I (uses accumulator rows 0-127)
    gemmini_mxquant_config_mvout((uint64_t)(sf_ptr + 512), block_ti, tj, tk, 0, 0, 16);
    gemmini_loop_ws_spad(block_ti, tj, tk, 0, 0, 0, ab + 2 * tk * DIM, BANK_NUM * BANK_ROWS, 0, 0, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
    
    // Read split results from shared memory
    uint16_t *C_ptr = (uint16_t*)&C_hw[0][0];
    gemmini_mx_read_smem(C_ptr, 128 * 16, 64 * MATMUL_N);
    gemmini_mx_read_smem(C_ptr + 64 * MATMUL_N, 0 * 16, 64 * MATMUL_N);
    
    gemmini_fence();
  }
}
```
