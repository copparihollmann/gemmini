### Optimization Plan

We will apply **Strategy 1: Simplify or remove unnecessary code** to optimize the host CPU loop overhead. 

#### Analysis of Inefficiencies
In the baseline code, the nested loops that perform scratchpad `mvin` operations for both matrices $A$ and $B$ perform expensive pointer arithmetic and index calculations in their innermost scopes:
* For matrix $A$: `(((elem_t*)A_in_hw) + i*DIM*MATMUL_K + k*DIM)` and `ab + (i*tk + k)*DIM`
* For matrix $B$: `(((elem_t*)B_in) + k*DIM*(MATMUL_N/2) + j*DIM)` and `bb + (k*tj + j)*DIM`

These expressions require multiple multiplications and additions per iteration. Because the scratchpad addresses and DRAM pointers progress sequentially within the inner loop, we can apply **strength reduction**. By replacing these expressions with simple pointer and address increments in the inner loop, we eliminate redundant math, allowing the host CPU to generate and dispatch RoCC instructions to the Gemmini accelerator much faster.

### Optimized Code

// Optimized MX matmul kernel (128x128x256, fp6:e3m2).
void solution(void) {
  {
    int ti = MATMUL_M / DIM / 2, tj = MATMUL_N / DIM / 2, tk = MATMUL_K / DIM;
    uint32_t ab = 0;
    uint32_t bb = BANK_NUM * BANK_ROWS - tk * tj * DIM;
    int SDST = 128;
    
    gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 1, 1, 3, 1);
    gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
    gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);
    
    gemmini_config_st(OUT_COLS * sizeof(out_t));
    gemmini_mxquant_config_mvout((uint64_t)scale_factors, ti, tj, tk, 0, 0, 9);
    
    gemmini_mx_load_lut((uint64_t)B_lut_p, 1, 0);
    gemmini_mx_load_lut((uint64_t)A_lut_p, 1, 1);
    
    // Optimized MVIN A with strength-reduced address generation
    gemmini_config_ld(MATMUL_K * sizeof(elem_t));
    for (int i = 0; i < ti; i++) {
      elem_t *a_ptr = ((elem_t*)A_in_hw) + i * DIM * MATMUL_K;
      uint32_t sp_addr = ab + i * tk * DIM;
      for (int k = 0; k < tk; k++) {
        gemmini_extended_mvin((void*)a_ptr, sp_addr, DIM, DIM);
        a_ptr += DIM;
        sp_addr += DIM;
      }
    }
    
    // Optimized MVIN B with strength-reduced address generation
    gemmini_config_ld(MATMUL_N * sizeof(elem_t) / 2);
    for (int k = 0; k < tk; k++) {
      elem_t *b_ptr = ((elem_t*)B_in) + k * DIM * (MATMUL_N / 2);
      uint32_t sp_addr = bb + k * tj * DIM;
      for (int j = 0; j < tj; j++) {
        gemmini_extended_mvin((void*)b_ptr, sp_addr, DIM, DIM);
        b_ptr += DIM;
        sp_addr += DIM;
      }
    }
    
    gemmini_loop_ws_spad(ti, tj, tk, 0, 0, 0, ab, BANK_NUM * BANK_ROWS, 0, SDST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
    gemmini_mx_read_smem(&C_hw[0][0], SDST * 16, MATMUL_M * MATMUL_N);
    gemmini_fence();
  }
}
