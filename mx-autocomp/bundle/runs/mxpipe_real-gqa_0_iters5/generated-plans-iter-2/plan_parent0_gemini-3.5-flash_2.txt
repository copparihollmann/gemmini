### Optimization Strategy: Asynchronous Head Pipelining (Host-Accelerator Overlap)

In the baseline implementation, the host CPU and the Gemmini accelerator execute in a strictly synchronous, sequential fashion for each head $h$. Specifically, the host CPU remains idle waiting for the $S1 = Q \times K^T$ matrix multiplication to finish on Gemmini, after which Gemmini sits idle while the host CPU performs the integer softmax computation on the CPU. Finally, the CPU waits again for Gemmini to finish the $O = P \times V$ computation before moving to the next head.

To eliminate this idle time, we can apply **Asynchronous Head Pipelining**. Since the input data ($Q$, $K$) for head $h+1$ does not depend on the computation of head $h$, Gemmini can execute the $S1$ matmul of head $h+1$ in the background while the host CPU is busy computing the softmax of head $h$. Similarly, the $O$ matmul of head $h$ can be launched asynchronously and overlap with the next head's operations.

To make this pipeline correct and data-race-free, we double-buffer the intermediate scratch buffers (`S1_hw`, `P_q`, and `P_scales`) across even/odd head indices (`h % 2`). This prevents Gemmini from overwriting the results of the next head's $S1$ or previous head's $O$ while the CPU is concurrently reading or writing them.

---

### Detailed Plan

1. **Double-Buffer Intermediate Buffers**: 
   Define static double-buffered arrays for the intermediate outputs to allow concurrent CPU and Gemmini access without data corruption:
   * `S1_hw_buf[2][ATT_S][ATT_S / 4]`
   * `P_q_buf[2][ATT_S][ATT_S]`
   * `P_scales_buf[2][GROUPS_S][ATT_S]`

2. **Pre-Pipeline Head 0**:
   Before entering the main head loop, issue the Gemmini commands for $S1$ of head 0 writing to `S1_hw_buf[0]` and perform a synchronization fence (`gemmini_fence()`). This ensures the CPU has its initial inputs ready.

3. **Pipelined Loop Execution**:
   For each head $h \in [0, \text{ATT\_H} - 1]$:
   * **Asynchronously pre-launch S1 for head $h+1$** (if $h+1 < \text{ATT\_H}$) pointing to `S1_hw_buf[(h+1) % 2]`. This runs in the background.
   * **Compute Softmax on CPU** for head $h$ in parallel, reading from `S1_hw_buf[h % 2]` and writing to `P_q_buf[h % 2]`.
   * **Synchronize**: Issue a `gemmini_fence()`. This ensures that $S1$ for head $h+1$ (launched in the first step) and any pending $O$ from head $h-1$ are fully completed.
   * **Asynchronously launch O for head $h$** pointing to `P_q_buf[h % 2]` and `O_hw[h]`. Do not issue a fence immediately.

4. **Final Synchronization**:
   After the loop terminates, issue a final `gemmini_fence()` to guarantee that the asynchronous $O$ matmul of the last head finishes writing its results to DRAM.

---

### Optimized Code

```c
#include <stdint.h>
#include <string.h>
#include "include/gemmini_testutils.h"

// Assuming the baseline definitions are present:
// DIM, ATT_H, ATT_HKV, ATT_S, ATT_D, GROUPS_S, S_OUT_COLS, D_OUT_COLS, QSS_BYTES, VSS_BYTES, etc.

void solution(void) {
  // Double buffers to eliminate data races during pipelining
  static out_t S1_hw_buf[2][ATT_S][ATT_S / 4];
  static elem_t P_q_buf[2][ATT_S][ATT_S];
  static uint8_t P_scales_buf[2][GROUPS_S][ATT_S];

  // Helper lambda/block to launch S1 asynchronously
  #define LAUNCH_S1(h_idx, buf_idx) { \
    int kv_idx = (h_idx) / (ATT_H / ATT_HKV); \
    const elem_t *Q_in = Qs[h_idx];  const uint8_t *Q_sc = Qss[h_idx]; \
    const elem_t *KT_in = KTs[kv_idx]; const uint8_t *KT_sc = KTss[kv_idx]; \
    int tiles_I = ATT_S / DIM, tiles_J = ATT_S / DIM, tiles_K = ATT_D / DIM; \
    uint32_t a_base = 0; \
    uint32_t b_base = BANK_NUM * BANK_ROWS - tiles_K * tiles_J * DIM; \
    gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0); \
    gemmini_mx_load_scales((uint64_t)Q_sc, QSS_BYTES, 0); \
    gemmini_mx_load_scales((uint64_t)KT_sc, QSS_BYTES, 1); \
    gemmini_config_ld(ATT_D * sizeof(elem_t)); \
    for (int i = 0; i < tiles_I; i++) \
      for (int k = 0; k < tiles_K; k += 2) { \
        int bb = (tiles_K - k < 2) ? (tiles_K - k) : 2; \
        gemmini_extended_mvin((void*)(((elem_t*)Q_in) + i * DIM * ATT_D + k * DIM), \
                              a_base + (i * tiles_K + k) * DIM, bb * DIM, DIM); \
      } \
    gemmini_config_ld(ATT_S * sizeof(elem_t)); \
    for (int k = 0; k < tiles_K; k++) \
      for (int j = 0; j < tiles_J; j += 2) { \
        int bb = (tiles_J - j < 2) ? (tiles_J - j) : 2; \
        gemmini_extended_mvin((void*)(((elem_t*)KT_in) + (k * DIM) * ATT_S + j * DIM), \
                              b_base + (k * tiles_J + j) * DIM, bb * DIM, DIM); \
      } \
    gemmini_config_st(S_OUT_COLS * sizeof(out_t)); \
    gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, 1); \
    gemmini_loop_ws_spad(tiles_I, tiles_J, tiles_K, 0, 0, 0, a_base, BANK_NUM * BANK_ROWS, 0, \
                         SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38); \
    gemmini_mx_read_smem(&S1_hw_buf[buf_idx][0][0], SPAD_DEST * 16, ATT_S * ATT_S); \
  }

  // Helper lambda/block to launch O asynchronously
  #define LAUNCH_O(h_idx, buf_idx) { \
    int kv_idx = (h_idx) / (ATT_H / ATT_HKV); \
    const elem_t *V_in = Vs[kv_idx];  const uint8_t *V_sc = Vss[kv_idx]; \
    int tiles_I = ATT_S / DIM, tiles_J = ATT_D / DIM, tiles_K = ATT_S / DIM; \
    uint32_t a_base = 0; \
    uint32_t b_base = BANK_NUM * BANK_ROWS - tiles_K * tiles_J * DIM; \
    gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0); \
    gemmini_mx_load_scales((uint64_t)&P_scales_buf[buf_idx], sizeof(P_scales_buf[buf_idx]), 0); \
    gemmini_mx_load_scales((uint64_t)V_sc, VSS_BYTES, 1); \
    gemmini_config_ld(ATT_S * sizeof(elem_t)); \
    for (int i = 0; i < tiles_I; i++) \
      for (int k = 0; k < tiles_K; k += 2) { \
        int bb = (tiles_K - k < 2) ? (tiles_K - k) : 2; \
        gemmini_extended_mvin((void*)(((elem_t*)P_q_buf[buf_idx]) + i * DIM * ATT_S + k * DIM), \
                              a_base + (i * tiles_K + k) * DIM, bb * DIM, DIM); \
      } \
    gemmini_config_ld(ATT_D * sizeof(elem_t)); \
    for (int k = 0; k < tiles_K; k++) \
      for (int j = 0; j < tiles_J; j += 2) { \
        int bb = (tiles_J - j < 2) ? (tiles_J - j) : 2; \
        gemmini_extended_mvin((void*)(((elem_t*)V_in) + (k * DIM) * ATT_D + j * DIM), \
                              b_base + (k * tiles_J + j) * DIM, bb * DIM, DIM); \
      } \
    gemmini_config_st(D_OUT_COLS * sizeof(out_t)); \
    gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, 1); \
    gemmini_loop_ws_spad(tiles_I, tiles_J, tiles_K, 0, 0, 0, a_base, BANK_NUM * BANK_ROWS, 0, \
                         SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38); \
    gemmini_mx_read_smem(&O_hw[h_idx][0][0], SPAD_DEST * 16, ATT_S * ATT_D); \
  }

  // ---- Pre-pipeline Head 0 ----
  gemmini_flush(0);
  LAUNCH_S1(0, 0);
  gemmini_fence(); // Ensure S1 of head 0 is fully loaded for the first softmax pass

  for (int h = 0; h < ATT_H; h++) {
    int cur_buf = h % 2;
    int next_buf = (h + 1) % 2;

    // 1. Overlap: Launch next S1 on Gemmini while CPU is busy computing current Softmax
    if (h + 1 < ATT_H) {
      LAUNCH_S1(h + 1, next_buf);
    }

    // 2. Compute integer softmax on CPU (Float-Free)
    for (int i = 0; i < ATT_S; i++) {
      int64_t q[ATT_S];
      int64_t mq = -((int64_t)1 << 62);
      for (int j = 0; j < ATT_S; j += 4) {
        uint64_t w = S1_hw_buf[cur_buf][i][j / 4];
        for (int l = 0; l < 4; l++) {
#if ATT_CAUSAL
          if (j + l > i) { q[j + l] = -((int64_t)1 << 62); continue; }
#endif
          int64_t qq = mx_ibf16_to_q((uint16_t)((w >> (l * 16)) & 0xFFFF));
          q[j + l] = qq; if (qq > mq) mq = qq;
        }
      }
      int64_t p[ATT_S];
      int64_t sm = 0;
      int64_t gmax_arr[GROUPS_S];
      for (int g = 0; g < GROUPS_S; g++) {
        int64_t gmax = 0;
        for (int j = g * 32; j < (g + 1) * 32; j++) {
          int64_t pv = mx_iexp(q[j] - mq);
          p[j] = pv;
          sm += pv;
          if (pv > gmax) gmax = pv;
        }
        gmax_arr[g] = gmax;
      }
      int ls = mx_ilog2((uint64_t)sm);
      uint64_t inv_sm = (((uint64_t)1 << (ls + MX_FRAC)) + ((uint64_t)sm >> 1)) / (uint64_t)sm;
      for (int g = 0; g < GROUPS_S; g++) {
        int64_t gmax = gmax_arr[g];
        if (gmax == 0) {
          P_scales_buf[cur_buf][g][i] = 0;
          for (int j = g * 32; j < (g + 1) * 32; j++) P_q_buf[cur_buf][i][j] = 0;
          continue;
        }
        int e = mx_ilog2((uint64_t)gmax) - ls - MX_P_TARGET_LOG2;
        P_scales_buf[cur_buf][g][i] = (uint8_t)(e + 127);
        for (int j = g * 32; j < (g + 1) * 32; j++) {
          P_q_buf[cur_buf][i][j] = mx_ienc_fp8(p[j], inv_sm, ls, e);
        }
      }
    }

    // 3. Synchronize: Wait for the next S1 and the previous O to finish executing
    gemmini_fence();

    // 4. Launch current head's O matmul asynchronously
    LAUNCH_O(h, cur_buf);
  }

  // Final synchronization to ensure the last head's O finishes writing to DRAM
  gemmini_fence();

  #undef LAUNCH_S1
  #undef LAUNCH_O
}
```
