### Optimization Plan: Eliminate Redundant Computation (Strategy 1)

#### Analysis of Inefficiencies
1. **Redundant Configurations**: 
   - `gemmini_flush(0)` and `gemmini_extended3_config_ex` are called inside the head loop `ATT_H` times (and twice per head). Since the configuration is static and identical across all heads and both matmuls, calling them repeatedly is redundant.
   - `gemmini_config_ld` and `gemmini_config_st` are re-issued constantly with the exact same stride values (`ATT_D * sizeof(elem_t) = 64` and `S_OUT_COLS * sizeof(out_t) = 128` respectively, because `ATT_S == ATT_D == 64` and `S_OUT_COLS == D_OUT_COLS == 16`). These can be set once at the start.

2. **Redundant Scale Factor Loads**:
   - The key-transpose scales (`KT_sc`) and value scales (`V_sc`) only depend on `kv = h / (ATT_H / ATT_HKV)`. Since `ATT_H = 4` and `ATT_HKV = 2`, `kv` only changes when `h` transitions from `1` to `2`. 
   - Loading these scale factors on every iteration of `h` via `gemmini_mx_load_scales` causes unnecessary host-to-accelerator DRAM streaming overhead. Since scale factor registers persist in Gemmini's internal scale memory until overwritten, we can track the active `kv` and load them only when `kv` changes.

#### Proposed Changes
- Move `gemmini_flush(0)`, `gemmini_extended3_config_ex`, `gemmini_config_ld`, and `gemmini_config_st` to the very beginning of the `solution` function.
- Introduce a tracking variable `last_kv` (initialized to `-1`) to conditionally load `KT_sc` and `V_sc` only when a new KV head is encountered.

---

### Optimized Code

```c
// AUTO-GENERATED optimized MHA kernel (S=64, D=64, H=4, H_kv=2, causal=0, fp8:e4m3).
void solution(void) {
  // ---- 1) Global One-Time Gemmini Configuration ----
  gemmini_flush(0);
  
  // Both matmuls use identical Weight-Stationary, BF16 output, non-LUT configurations
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
  
  // Since ATT_S == ATT_D == 64, the load stride is always 64 bytes
  gemmini_config_ld(64); 
  
  // Since S_OUT_COLS == D_OUT_COLS == 16, the store stride is always 16 * 8 = 128 bytes
  gemmini_config_st(16 * sizeof(out_t));

  int last_kv = -1;

  for (int h = 0; h < ATT_H; h++) {
    int kv = h / (ATT_H / ATT_HKV);
    const elem_t *Q_in = Qs[h];  const uint8_t *Q_sc = Qss[h];
    const elem_t *KT_in = KTs[kv]; const uint8_t *KT_sc = KTss[kv];
    const elem_t *V_in = Vs[kv];  const uint8_t *V_sc = Vss[kv];

    // Track KV changes to avoid redundant scale factor loads
    bool kv_changed = (kv != last_kv);
    if (kv_changed) {
      last_kv = kv;
    }

    // ---- 1) S1 = Q @ K^T on Gemmini (bf16 out) ----
    {
      int tiles_I = ATT_S / DIM, tiles_J = ATT_S / DIM, tiles_K = ATT_D / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles_K * tiles_J * DIM;

      // Load Q scale factors (changes per head)
      gemmini_mx_load_scales((uint64_t)Q_sc, QSS_BYTES, 0);
      
      // Load KT scale factors only if kv head changed
      if (kv_changed) {
        gemmini_mx_load_scales((uint64_t)KT_sc, QSS_BYTES, 1);
      }

      for (int i = 0; i < tiles_I; i++) {
        for (int k = 0; k < tiles_K; k += 2) { 
          int bb = (tiles_K - k < 2) ? (tiles_K - k) : 2;
          gemmini_extended_mvin((void*)(((elem_t*)Q_in) + i * DIM * ATT_D + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, bb * DIM, DIM); 
        }
      }

      for (int k = 0; k < tiles_K; k++) {
        for (int j = 0; j < tiles_J; j += 2) { 
          int bb = (tiles_J - j < 2) ? (tiles_J - j) : 2;
          gemmini_extended_mvin((void*)(((elem_t*)KT_in) + (k * DIM) * ATT_S + j * DIM),
                                b_base + (k * tiles_J + j) * DIM, bb * DIM, DIM); 
        }
      }

      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles_I, tiles_J, tiles_K, 0, 0, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
      gemmini_mx_read_smem(&S1_hw[0][0], SPAD_DEST * 16, ATT_S * ATT_S);
      gemmini_fence();
    }

    // ---- 2) FLOAT-FREE integer softmax + fp8 requant (I-BERT iexp; host has no FPU) ----
    for (int i = 0; i < ATT_S; i++) {
      int64_t q[ATT_S];
      int64_t mq = -((int64_t)1 << 62);
      for (int j = 0; j < ATT_S; j += 4) {                       // unpack 4 bf16/word -> Q(1/1024) int + max
        uint64_t w = S1_hw[i][j / 4];
        for (int l = 0; l < 4; l++) {
#if ATT_CAUSAL
          if (j + l > i) { q[j + l] = -((int64_t)1 << 62); continue; }   // causal: future col -> iexp()=0
#endif
          int64_t qq = mx_ibf16_to_q((uint16_t)((w >> (l * 16)) & 0xFFFF));
          q[j + l] = qq; if (qq > mq) mq = qq;
        }
      }
      int64_t p[ATT_S];
      int64_t sm = 0;
      int64_t gmax_arr[GROUPS_S];                                // fused group-max: capture per-group max IN the iexp pass
      for (int g = 0; g < GROUPS_S; g++) {                       // (group-nested, register-scalar gmax) -> removes the
        int64_t gmax = 0;                                        // separate 16384-elem max scan. Output bit-identical.
        for (int j = g * 32; j < (g + 1) * 32; j++) { int64_t pv = mx_iexp(q[j] - mq); p[j] = pv; sm += pv; if (pv > gmax) gmax = pv; }
        gmax_arr[g] = gmax;
      }
      int ls = mx_ilog2((uint64_t)sm);
      uint64_t inv_sm = (((uint64_t)1 << (ls + MX_FRAC)) + ((uint64_t)sm >> 1)) / (uint64_t)sm;   // one rounded reciprocal/row
      for (int g = 0; g < GROUPS_S; g++) {
        int64_t gmax = gmax_arr[g];
        if (gmax == 0) { P_scales[g][i] = 0; for (int j = g * 32; j < (g + 1) * 32; j++) P_q[i][j] = 0; continue; }
        // group e8m0 scale so the group-max lands at ~2^MX_P_TARGET_LOG2 (moderate; avoids e4 overflow)
        int e = mx_ilog2((uint64_t)gmax) - ls - MX_P_TARGET_LOG2;
        P_scales[g][i] = (uint8_t)(e + 127);
        for (int j = g * 32; j < (g + 1) * 32; j++) P_q[i][j] = mx_ienc_fp8(p[j], inv_sm, ls, e);
      }
    }

    // ---- 3) O = P @ V on Gemmini (bf16 out) ----
    {
      int tiles_I = ATT_S / DIM, tiles_J = ATT_D / DIM, tiles_K = ATT_S / DIM;
      uint32_t a_base = 0;
      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles_K * tiles_J * DIM;

      // Load P scale factors (re-calculated per head during softmax)
      gemmini_mx_load_scales((uint64_t)&P_scales, sizeof(P_scales), 0);
      
      // Load V scale factors only if kv head changed
      if (kv_changed) {
        gemmini_mx_load_scales((uint64_t)V_sc, VSS_BYTES, 1);
      }

      for (int i = 0; i < tiles_I; i++) {
        for (int k = 0; k < tiles_K; k += 2) { 
          int bb = (tiles_K - k < 2) ? (tiles_K - k) : 2;
          gemmini_extended_mvin((void*)(((elem_t*)P_q) + i * DIM * ATT_S + k * DIM),
                                a_base + (i * tiles_K + k) * DIM, bb * DIM, DIM); 
        }
      }

      for (int k = 0; k < tiles_K; k++) {
        for (int j = 0; j < tiles_J; j += 2) { 
          int bb = (tiles_J - j < 2) ? (tiles_J - j) : 2;
          gemmini_extended_mvin((void*)(((elem_t*)V_in) + (k * DIM) * ATT_D + j * DIM),
                                b_base + (k * tiles_J + j) * DIM, bb * DIM, DIM); 
        }
      }

      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles_I, tiles_J, tiles_K, 0, 0, 1);
      gemmini_loop_ws_spad(tiles_I, tiles_J, tiles_K, 0, 0, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
      gemmini_mx_read_smem(&O_hw[h][0][0], SPAD_DEST * 16, ATT_S * ATT_D);
      gemmini_fence();
    }
  }
}
```
