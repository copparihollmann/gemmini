### Strategy: High-Throughput DMA Batching, Config Amortization, and Cache-Line Alignment

1. **Maximized DMA Batching (`MAX_BLOCK_LEN = 4`)**:
   In the original code, the tiles of $Q$, $K^T$, $P$, and $V$ are loaded using a batching factor of `bb = 2` (i.e., loading 2 contiguous tiles of size `16x16` at a time). Since each element `elem_t` is `uint8_t` (1 byte), loading 2 tiles of width `DIM` corresponds to `2 * 16 = 32` bytes.

2. **Reconfiguration Amortization**:
   Both the first matmul ($S_1 = Q @ K^T$) and the second matmul ($O = P @ V$) share the **identical execution configuration**:

3. **Cache-Aligned Softmax Buffers**:
