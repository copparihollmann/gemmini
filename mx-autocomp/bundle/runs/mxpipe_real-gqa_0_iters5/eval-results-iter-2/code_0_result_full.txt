### Optimization Plan: Loop Reordering and Scratchpad Caching

Since there are no loop-carried dependencies between different attention heads, we can reorder the execution to group heads sharing the same `kv` index. This allows us to load the key and value matrices into the scratchpad **exactly once per `kv` group**, rather than once per head $h$.

   elem_t P_q_h[ATT_H][ATT_S][ATT_S];
   uint8_t P_scales_h[ATT_H][GROUPS_S][ATT_S];
