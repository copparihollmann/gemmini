An elegant and highly effective optimization plan to apply **Strategy 2 (Scratchpad Key/Value Tile Reuse Across Heads)**.

### Analysis of the Inefficiency
In the baseline multi-head attention (MHA) loop, $H = 4$ and $H_{kv} = 2$. This means every group of $\frac{H}{H_{kv}} = 2$ heads shares the exact same Key ($K^T$) and Value ($V$) matrices. 

Currently, the baseline code re-loads $K^T$ and $V$ from DRAM into the scratchpad at every head iteration $h$, completely wasting DRAM bandwidth and incurring unnecessary DMA latencies. 

### Optimization Plan: Key/Value Scratchpad Partitioning & Reuse
Since the Gemmini scratchpad is 8192 rows (128 KB) and our active workspace is incredibly small, we can keep both $K^T$ and $V$ resident in the high-address region of the scratchpad simultaneously.

1. **Calculate Matrix Tile Footprints:**
   - Both $K^T$ and $V$ tile dimensions are $4 \times 4$ tiles ($tiles\_K \times tiles\_J$).
   - Total scratchpad rows per matrix = $4 \times 4 \times 16 = 256$ rows.

2. **Partition the High-Address Scratchpad Region:**
   - To prevent $V$ from overwriting $K^T$, we assign them distinct, non-overlapping base addresses at the top of the scratchpad:
     - **$K^T$ Base ($b\_base\_KT$):** Starts at `BANK_NUM * BANK_ROWS - 256` = `7936`. Its end boundary is `8192`.
     - **$V$ Base ($b\_base\_V$):** Starts at `b_base_KT - 256` = `7680`. Its end boundary is `7936`.
     - **$Q$ / $P$ Base ($a\_base$):** Remains at `0` (utilizes rows `[0, 255]`). No overlap exists since `255 < 7680`.

3. **Conditional DMA Loading:**
   - Define a head-group divisor `g_kv = ATT_H / ATT_HKV` (which is `2`).
   - Identify the first head of each group: `int first_of_group = (h % g_kv == 0);`.
   - Wrap the $K^T$ and $V$ `mvin` loops in `if (first_of_group)` checks. If `first_of_group` is false, completely skip the DMA transfer. The compute phase will reuse the existing $K^T$ and $V$ tiles already residing in the scratchpad from the previous iteration.

4. **Adjust Compute Loop Parameters:**
   - Update the B-end scratchpad address passed to `gemmini_loop_ws_spad`:
     - For the $S1 = Q @ K^T$ matmul, use `BANK_NUM * BANK_ROWS` (8192).
     - For the $O = P @ V$ matmul, use `b_base_KT` (7936).
