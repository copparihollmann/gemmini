An elegant and highly effective way to optimize this MX-Gemmini kernel is to **overlap data movement and compute** using a **double-buffered tiling strategy along the $I$ dimension**. 

### Analysis of Inefficiencies in Baseline
1. **Accumulator Overflow Risk**: The baseline attempts to execute the entire $32 \times 256 \times 256$ matrix multiplication in a single hardware loop invocation. This requires $tiles_I \times tiles_J \times \text{DIM} = 2 \times 16 \times 16 = 512$ rows of accumulator storage, which exceeds the physical accumulator limit of $256$ rows.
2. **Sequential Execution**: The baseline loads all tiles of $A$ and $B$ sequentially before initiating the compute block, leaving the systolic array completely idle during the load phase and the DMA engine idle during the compute phase.

### Optimization Plan
We will tile the $I$ dimension into $2$ blocks of size $1$ (16 rows each).
1. **Reuse $B$ globally**: Since $B$ is identical across both blocks of $I$, we load the entire $B$ matrix into the high-address scratchpad region (`b_base = 4096`) once at the beginning.
2. **Double-buffer $A$**: 
   - Block 0 of $A$ (256 rows) is loaded into `a_base_0 = 0`.
   - Block 1 of $A$ (256 rows) is loaded into `a_base_1 = 256`.
3. **Overlapped Compute & Load**: 
   - Start computing Block 0 on the systolic array.
   - Immediately issue the DMA load commands for Block 1 of $A$ to the scratchpad. Because Gemmini has independent DMA and compute controllers, the hardware will overlap the load of Block 1 with the compute of Block 0.
4. **Requantizer Update**: Update the scale factor pointer for Block 1 to point to the second row of scales (`scale_factors + 16`) before launching the compute for Block 1.
5. **Asynchronous Read**: Output results to distinct areas in `mx_smem` (`SPAD_DEST_0` and `SPAD_DEST_1`), trigger asynchronous readback to DRAM, and finalize with a single `gemmini_fence()`.

---

### Optimized Code

```c
// Optimized MX matmul kernel (32x256x256, fp8:e4m3).
void solution(void) {
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
  gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
  gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);

  const uint32_t a_base_0 = a_base;
  const uint32_t a_base_1 = a_base + 1 * tiles_K * DIM; // 256 rows offset
  const uint32_t b_base = BANK_NUM * BANK_ROWS - tiles_K * tiles_J * DIM; // 4096
  const uint32_t SPAD_DEST_0 = SPAD_DEST;
  const uint32_t SPAD_DEST_1 = SPAD_DEST + 1 * tiles_J * DIM; // 256 rows offset

  // 1. Load B once into the top of the scratchpad (weight-stationary reuse)
  gemmini_config_ld(MATMUL_N * sizeof(elem_t));
  for (int j = 0; j < tiles_J; j++) {
    for (int k = 0; k < tiles_K; k++) {
      gemmini_extended_mvin((void*)(((elem_t*)B_in) + (k * DIM) * MATMUL_N + j * DIM),
                            b_base + (k * tiles_J + j) * DIM, DIM, DIM);
    }
  }

  // 2. Load A block 0
  gemmini_config_ld(MATMUL_K * sizeof(elem_t));
  for (int k = 0; k < tiles_K; k++) {
    gemmini_extended_mvin((void*)(((elem_t*)A_in) + 0 * DIM * MATMUL_K + k * DIM),
                          a_base_0 + k * DIM, DIM, DIM);
  }

  // 3. Compute Block 0 (Using tiles_I = 1, fitting within 256 accumulator rows)
  gemmini_config_st(OUT_COLS * sizeof(out_t));
  gemmini_mxquant_config_mvout((uint64_t)scale_factors, 1, tiles_J, tiles_K, 0, 0, 1);
  gemmini_loop_ws_spad(1, tiles_J, tiles_K, 0, PAD_J, PAD_K, a_base_0, BANK_NUM * BANK_ROWS, 0,
                       SPAD_DEST_0, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

  // 4. Overlap: Load A block 1 while Block 0 is computing
  gemmini_config_ld(MATMUL_K * sizeof(elem_t));
  for (int k = 0; k < tiles_K; k++) {
    gemmini_extended_mvin((void*)(((elem_t*)A_in) + 1 * DIM * MATMUL_K + k * DIM),
                          a_base_1 + k * DIM, DIM, DIM);
  }

  // 5. Compute Block 1 (Applying any remaining PAD_I to the final block)
  gemmini_config_st(OUT_COLS * sizeof(out_t));
  gemmini_mxquant_config_mvout((uint64_t)(scale_factors + 1 * tiles_J), 1, tiles_J, tiles_K, 0, 0, 1);
  gemmini_loop_ws_spad(1, tiles_J, tiles_K, PAD_I, PAD_J, PAD_K, a_base_1, BANK_NUM * BANK_ROWS, 0,
                       SPAD_DEST_1, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

  // 6. Asynchronous drain from Shared Memory to DRAM
  int rows_0 = REAL_M < 16 ? REAL_M : 16;
  if (rows_0 > 0) {
    gemmini_mx_read_smem(&C_hw[0][0], SPAD_DEST_0 * 16, rows_0 * MATMUL_N);
  }

  int rows_1 = REAL_M > 16 ? REAL_M - 16 : 0;
  if (rows_1 > 0) {
    gemmini_mx_read_smem(&C_hw[16][0], SPAD_DEST_1 * 16, rows_1 * MATMUL_N);
  }

  // 7. Single synchronized fence barrier
  gemmini_fence();
}
```
