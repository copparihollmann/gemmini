An elegant and highly effective optimization strategy for this phase is **Double-Buffering the Shared Memory (SMEM) Output Buffer combined with Pipeline Stiction Elimination (Fence Relocation & Hoisting)**.

### Performance Optimization Plan

1. **Elimination of Synchronous Pipeline Stalls (`gemmini_flush` and `gemmini_fence` removal):**
   In the baseline kernel, `gemmini_flush(0)` and `gemmini_fence()` are executed inside the innermost loop (`j0`). 
   - `gemmini_flush(0)` forces the systolic array controller to flush all state and wait for the pipeline to empty, erasing any preloaded inputs.
   - `gemmini_fence()` forces the CPU to block until the DMA engine finishes transferring the current tile's output from the shared memory (`mx_smem`) to DRAM. 
   Removing `gemmini_flush` entirely and moving the `gemmini_fence` out of the inner loop allows the Gemmini DMA engine to overlap the DRAM write-back with the systolic array's execution of the next tile.

2. **Shared Memory Double-Buffering:**
   Simply removing the fence would create a write-after-read hazard if iteration `j0 + 1`'s computation overwrites `SPAD_DEST` in SMEM before iteration `j0`'s `gemmini_mx_read_smem` completes. To solve this, we double-buffer `SPAD_DEST` using two alternating locations: `SPAD_DEST_0 = 128` (offset 2048 words) and `SPAD_DEST_1 = 384` (offset 6144 words). 
   This safely isolates the compute output of the current iteration from the background DMA drain of the previous iteration. We place a single synchronization fence at the end of the `i0` loop block to ensure all rows are fully drained before switching the stationary `A` operand.

3. **Global Configuration Hoisting:**
   `gemmini_extended3_config_ex` and `gemmini_config_st` only need to be configured once. We hoist them entirely out of the nested loops to eliminate instruction-dispatch overhead.

4. **Pointer Aliasing Restrictions:**
   We declare `const elem_t * const __restrict__` pointers for the matrix inputs `A_in` and `B_in` to allow the compiler to aggressively optimize memory loads and keep pointer addresses in registers.

### Optimized Code

```c
// AUTO-GENERATED outer-tiled MX matmul optimized via SMEM Double-Buffering.
void solution(void) {
  // Pre-format scale factor matrices to eliminate CPU-side staging in the hot loop
  static uint8_t A_scales_perf[BLOCKS_M][MATMUL_K / 32][BLK];
  static uint8_t B_scales_perf[BLOCKS_N][MATMUL_K / 32][BLK];

  // Restrict pointers to enable aggressive compiler optimizations
  const elem_t * const __restrict__ A_ptr = (const elem_t *)A_in;
  const elem_t * const __restrict__ B_ptr = (const elem_t *)B_in;

  // One-time pre-formatting before main loops start
  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      int mrows = REAL_M - i0 * BLK;
      if (mrows > BLK) mrows = BLK;
      if (mrows <= 0) continue;
      
      // Only copy actual data, handle partial blocks correctly
      for (int i = 0; i < mrows; i++) {
        A_scales_perf[i0][g][i] = A_scales_row[g][i0 * BLK + i];
      }
      // Pad with zeros for partial blocks if needed
      for (int i = mrows; i < BLK; i++) {
        A_scales_perf[i0][g][i] = 0;
      }
    }
  }

  for (int j0 = 0; j0 < BLOCKS_N; j0++) {
    for (int g = 0; g < MATMUL_K / 32; g++) {
      int ncols = REAL_N - j0 * BLK;
      if (ncols > BLK) ncols = BLK;
      if (ncols <= 0) continue;
      
      // Only copy actual data, handle partial blocks correctly
      for (int j = 0; j < ncols; j++) {
        B_scales_perf[j0][g][j] = B_scales_col[g][j0 * BLK + j];
      }
      // Pad with zeros for partial blocks if needed
      for (int j = ncols; j < BLK; j++) {
        B_scales_perf[j0][g][j] = 0;
      }
    }
  }

  // Hoist static configurations completely out of execution loops
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 0, 0, 3, 0);
  gemmini_config_st(BLK_OUTC * sizeof(out_t));

  for (int i0 = 0; i0 < BLOCKS_M; i0++) {
    int mrows = REAL_M - i0 * BLK; 
    if (mrows > BLK) mrows = BLK; 
    if (mrows <= 0) continue;

    int tiles = BLK / DIM, tiles_K = MATMUL_K / DIM;
    uint32_t a_base = 0;

    // Load stationary A scale factors once per row block
    gemmini_mx_load_scales((uint64_t)&A_scales_perf[i0][0][0], A_S_BYTES, 0);

    // Keep A tiles stationary in the lower half of the scratchpad
    gemmini_config_ld(MATMUL_K * sizeof(elem_t)); // A rows: stride K
    for (int i = 0; i < tiles; i++) {
      for (int k = 0; k < tiles_K; k += 2) {
        gemmini_extended_mvin((void*)(A_ptr + (i0 * BLK + i * DIM) * MATMUL_K + k * DIM),
                              a_base + (i * tiles_K + k) * DIM, 2 * DIM, DIM);
      }
    }

    for (int j0 = 0; j0 < BLOCKS_N; j0++) {
      int ncols = REAL_N - j0 * BLK; 
      if (ncols > BLK) ncols = BLK; 
      if (ncols <= 0) continue;

      uint32_t b_base = BANK_NUM * BANK_ROWS - tiles * tiles_K * DIM;
      
      // Ping-pong buffer selection for the SMEM write/read space
      int SPAD_DEST = (j0 % 2 == 0) ? 128 : 384;
      int pad_i = BLK - mrows, pad_j = BLK - ncols;

      // Load dynamic B scale factors
      gemmini_mx_load_scales((uint64_t)&B_scales_perf[j0][0][0], B_S_BYTES, 1);

      // Load dynamic B tiles into the upper half of the scratchpad
      gemmini_config_ld(MATMUL_N * sizeof(elem_t)); // B rows: stride N
      for (int k = 0; k < tiles_K; k++) {
        for (int j = 0; j < tiles; j += 2) {
          gemmini_extended_mvin((void*)(B_ptr + (k * DIM) * MATMUL_N + (j0 * BLK + j * DIM)),
                                b_base + (k * tiles + j) * DIM, 2 * DIM, DIM);
        }
      }

      gemmini_mxquant_config_mvout((uint64_t)scale_factors, tiles, tiles, tiles_K, 0, 0, 1);
      
      // Perform computation utilizing the stationary A tiles and new B tiles
      gemmini_loop_ws_spad(tiles, tiles, tiles_K, pad_i, pad_j, 0, a_base, BANK_NUM * BANK_ROWS, 0,
                           SPAD_DEST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

      // Drain results to DRAM in the background
      for (int r = 0; r < mrows; r++) {
        gemmini_mx_read_smem(&C_hw[i0 * BLK + r][(j0 * BLK) / BF16_PER_WORD],
                             SPAD_DEST * 16 + r * BLK, ncols);
      }
    }
    // Synchronize and wait for background DMA stores to finish before switching the stationary A-tile
    gemmini_fence();
  }
}
```
