An elegant and highly effective way to optimize the performance of the $128 \times 128 \times 256$ matrix multiplication kernel is to choose **Strategy 1: overlap data movement and compute** using a double-buffered 1D tiling pipeline along the $N$ dimension.

### Optimization Plan

1. **Optimal 1D Partitioning Along $N$**:
   Since the accumulator size is limited to $256$ rows, we can partition the global $128 \times 128 \times 256$ matmul into 4 blocks of size $128 \times 32 \times 256$.
   - **Tiling Dimensions per Block**: `ti = 8` (128 rows), `tj = 2` (32 columns), `tk = 16` (256 columns).
   - **Accumulator Space**: Each block consumes exactly $16 \times 16 = 256$ rows, maximizing accumulator utilization without overflowing.

2. **DRAM Bandwidth Optimization (Static A Matrix)**:
   Since we partition strictly along the $N$ dimension, the $A$ matrix ($128 \times 256$) is completely invariant across the 4 blocks. We can load the entire $A$ matrix into the scratchpad at base address `0` exactly **once** at the beginning of the function, eliminating $75\%$ of the $A$ memory traffic.

3. **Double-Buffering $B$**:
   - **$B$ Tile size per block**: $512$ rows ($2 \times 16 \times 16$).
   - We allocate two non-overlapping buffers at the top of the scratchpad:
     - **Buffer 0**: Ends at row $8192$ (occupies `[7680, 8192)`).
     - **Buffer 1**: Ends at row $7680$ (occupies `[7168, 7680)`).
   - Neither buffer overlaps with the static $A$ matrix stored in `[0, 2048)`.

4. **Pipelining Sequence**:
   - Pre-load $A$ into the scratchpad, and load $B$ for block 0.
   - For each block `j_block`:
     - Issue the compute instruction (`gemmini_loop_ws_spad`) for the current block.
     - While compute runs in the background, issue the `gemmini_extended_mvin` instructions to load the next $B$ block into the alternate buffer.
     - Read the compute results to a contiguous local DRAM buffer (`temp_C`) using `gemmini_mx_read_smem`.
     - Call `gemmini_fence()` to synchronize.
     - Use the CPU to copy `temp_C` to the strided final output `C_hw` slice.

#include <stdint.h>
#include <string.h>
#include "include/gemmini_testutils.h"

// Load the entire static A matrix to scratchpad
static inline void load_A_all(uint32_t ab_start) {
  int ti = 8;
  int tk = 16;
  gemmini_config_ld(MATMUL_K * sizeof(elem_t));
  for (int i = 0; i < ti; i++) {
    for (int k = 0; k < tk; k += 2) {
      elem_t *dram_ptr = ((elem_t*)A_in_hw) + i * DIM * MATMUL_K + k * DIM;
      gemmini_extended_mvin((void*)dram_ptr, ab_start + (i * tk + k) * DIM, 2 * DIM, DIM);
    }
  }
}

// Load a slice of B matrix corresponding to the current block
static inline void load_B_block(int j_block, uint32_t bb_start) {
  int tj = 2;
  int tk = 16;
  gemmini_config_ld(MATMUL_N * sizeof(elem_t) / 2);
  for (int k = 0; k < tk; k++) {
    for (int j = 0; j < tj; j += 2) {
      elem_t *dram_ptr = ((elem_t*)B_in) + k * DIM * (MATMUL_N / 2) + (j_block * tj + j) * DIM;
      gemmini_extended_mvin((void*)dram_ptr, bb_start + (k * tj + j) * DIM, 2 * DIM, DIM);
    }
  }
}

// AUTO-GENERATED optimized MX matmul kernel (128x128x256, fp6:e3m2).
void solution(void) {
  int ti = 8;
  int tj = 2;
  int tk = 16;
  int SDST = 128;

  // 1. Configure MX weight-stationary mode and load scales/LUTs
  gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 1, 1, 3, 1);
  gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
  gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);
  gemmini_config_st(OUT_COLS * sizeof(out_t));
  gemmini_mxquant_config_mvout((uint64_t)scale_factors, ti, tj, tk, 0, 0, 9);
  gemmini_mx_load_lut((uint64_t)B_lut_p, 1, 0);
  gemmini_mx_load_lut((uint64_t)A_lut_p, 1, 1);

  // 2. Cold start loads
  load_A_all(0);         // Load static A once
  load_B_block(0, 7680); // Load B block 0 to Buffer 0

  // Contiguous DRAM buffer for block output
  static out_t temp_C[128][8];

  // 3. Pipelined loop over the N dimension
  for (int j_block = 0; j_block < 4; j_block++) {
    uint32_t bb_cur = (j_block % 2 == 0) ? 8192 : 7680;

    // Compute current block in hardware
    gemmini_loop_ws_spad(ti, tj, tk, 0, 0, 0, 0, bb_cur, 0, SDST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);

    // Overlap: Pre-load the next B block
    if (j_block < 3) {
      uint32_t bb_next_start = (j_block % 2 == 0) ? 7168 : 7680;
      load_B_block(j_block + 1, bb_next_start);
    }

    // Read outputs to local contiguous buffer
    gemmini_mx_read_smem(&temp_C[0][0], SDST * 16, 4096);
    gemmini_fence();

    // CPU copies contiguous results to strided DRAM output
    for (int i = 0; i < 128; i++) {
      for (int j = 0; j < 8; j++) {
        C_hw[i][j_block * 8 + j] = temp_C[i][j];
      }
    }
  }
}
