An elegant and effective way to optimize the baseline code is to apply **Strategy 5: batch the mvin with block_mvin**.

### Method Explanation
In the baseline code, each $16 \times 16$ tile of inputs `A` and `B` is transferred individually from DRAM to the scratchpad using `gemmini_extended_mvin` with `cols = DIM` (16). This results in a high volume of individual DMA commands, introducing instruction-issue bottlenecks.

Because the tiles of `A` are contiguous in memory along the $K$ dimension and the tiles of `B` are contiguous along the $N$ dimension, we can load 2 tiles horizontally at once by setting `cols = 2 * DIM` (32) and stepping our loops by 2. This effectively cuts the number of MVIN instructions in half and leverages longer, more efficient sequential DRAM burst transfers.

### Optimized Code

```c
// AUTO-GENERATED optimized MX matmul kernel (128x128x256, fp6:e3m2).
void solution(void) {
  {
    int ti = MATMUL_M / DIM / 2, tj = MATMUL_N / DIM / 2, tk = MATMUL_K / DIM;
    uint32_t ab = 0;
    uint32_t bb = BANK_NUM * BANK_ROWS - tk * tj * DIM;
    int SDST = 128;
    
    // Configure execution format and strides
    gemmini_extended3_config_ex(WEIGHT_STATIONARY, 0, 0, ACC_SCALE_IDENTITY, 1, 1, 0, 0, false, 1, 1, 3, 1);
    
    // Load scales
    gemmini_mx_load_scales((uint64_t)&A_scales_row, sizeof(A_scales_row), 0);
    gemmini_mx_load_scales((uint64_t)&B_scales_col, sizeof(B_scales_col), 1);
    
    // Configure store and requantization bounds
    gemmini_config_st(OUT_COLS * sizeof(out_t));
    gemmini_mxquant_config_mvout((uint64_t)scale_factors, ti, tj, tk, 0, 0, 9);
    
    // Load LUTs
    gemmini_mx_load_lut((uint64_t)B_lut_p, 1, 0);
    gemmini_mx_load_lut((uint64_t)A_lut_p, 1, 1);
    
    // Batched MVIN A (batch size = 2 DIM-tiles)
    gemmini_config_ld(MATMUL_K * sizeof(elem_t));
    for (int i = 0; i < ti; i++) {
      for (int k = 0; k < tk; k += 2) {
        gemmini_extended_mvin((void*)(((elem_t*)A_in_hw) + i * DIM * MATMUL_K + k * DIM), 
                              ab + (i * tk + k) * DIM, 
                              2 * DIM, 
                              DIM);
      }
    }
    
    // Batched MVIN B (batch size = 2 DIM-tiles)
    gemmini_config_ld(MATMUL_N * sizeof(elem_t) / 2);
    for (int k = 0; k < tk; k++) {
      for (int j = 0; j < tj; j += 2) {
        gemmini_extended_mvin((void*)(((elem_t*)B_in) + k * DIM * (MATMUL_N / 2) + j * DIM), 
                              bb + (k * tj + j) * DIM, 
                              2 * DIM, 
                              DIM);
      }
    }
    
    // Compute WS matmul
    gemmini_loop_ws_spad(ti, tj, tk, 0, 0, 0, ab, BANK_NUM * BANK_ROWS, 0, SDST, false, false, false, false, false, NO_ACTIVATION, 0, 0, false, 0x38);
    
    // Read and sync
    gemmini_mx_read_smem(&C_hw[0][0], SDST * 16, MATMUL_M * MATMUL_N);
    gemmini_fence();
  }
}
```
